## M7.1 问题陈述

### 黎曼 ζ 函数

\\[ \\zeta(s) = \\sum_{n=1}^{\\infty} \\frac{1}{n^s}, \\quad \\mathrm{Re}(s) > 1 \\]

通过**解析延拓**，\\(\\zeta(s)\\) 可延拓到 \\(\\mathbb{C} \\setminus \\{1\\}\\)（\\(s=1\\) 是单极点）。

### 零点

- **平凡零点**：\\(s = -2, -4, -6, \\ldots\\)（负偶数）
- **非平凡零点**：在**临界带** \\(0 < \\mathrm{Re}(s) < 1\\) 内

### 黎曼猜想（1859）

**所有非平凡零点都在临界线 \\(\\mathrm{Re}(s) = 1/2\\) 上。**

\\[ \\zeta(\\rho) = 0, \\; 0 < \\mathrm{Re}(\\rho) < 1 \\implies \\mathrm{Re}(\\rho) = \\frac{1}{2} \\]

```python
# 黎曼猜想的可视化理解
# 复平面：横轴 Re(s)，纵轴 Im(s)
#
#   Im
#    ↑
#    |     ×  ×  ×  ×  ×     ← 非平凡零点
#    |     ×  ×  ×  ×  ×        猜想：都在 Re = 1/2 这条线上
#    |-----×--×--×--×--×----→ Re
#    |     0  1/2  1
#    |
#   平凡零点：-2, -4, -6, ...（负实轴上）
#
# 已验证：前 10^13 个零点都在临界线上！
# 但验证 ≠ 证明（有无穷多个零点）

print("黎曼猜想：所有非平凡零点的实部都是 1/2")
print("已验证前 10 万亿个零点，无反例")
print("但数学需要证明，不是验证")
```

## M7.2 为什么重要？—— 素数定理的误差项

### 素数定理

\\[ \\pi(x) = \\#\\{p \\leq x : p \\text{ 素数}\\} \\sim \\frac{x}{\\log x} = \\mathrm{Li}(x) \\]

### 黎曼猜想 ⟺ 最优误差项

**定理**（von Koch, 1901）：黎曼猜想成立 ⟺
\\[ \\pi(x) = \\mathrm{Li}(x) + O(\\sqrt{x} \\log x) \\]

**von Mangoldt 显式公式**：
\\[ \\psi(x) = x - \\sum_{\\rho} \\frac{x^\\rho}{\\rho} - \\log(2\\pi) - \\frac{1}{2}\\log(1-x^{-2}) \\]

其中求和遍历**所有**非平凡零点 \\(\\rho\\)。

- 如果 \\(\\mathrm{Re}(\\rho) = 1/2\\)，则 \\(|x^\\rho| = x^{1/2}\\)，误差 \\(O(\\sqrt{x})\\)
- 如果有零点偏离临界线，误差更大

**所以**：黎曼猜想 = **素数分布的最精确规律**。

## M7.4 Python：计算 ζ 零点

```python
import mpmath
mpmath.mp.dps = 30

def find_zeta_zeros(n_zeros=5):
    """找 ζ(s) 的前 n 个非平凡零点"""
    zeros = []
    # 已知第一个零点虚部约 14.1347
    # 用 findroot 从近似值出发
    guesses = [14.13, 21.02, 25.01, 30.42, 32.93]
    for g in guesses[:n_zeros]:
        try:
            root = mpmath.findroot(
                lambda s: mpmath.zeta(s),
                0.5 + g*1j,
                tol=1e-14, maxsteps=100
            )
            zeros.append(complex(root))
        except Exception as e:
            print(f"找零点 {g} 失败：{e}")
    return zeros

print("计算 ζ(s) 的非平凡零点（验证实部 = 1/2）：")
zeros = find_zeta_zeros(5)
for i, z in enumerate(zeros, 1):
    print(f"  ρ_{i} = {z.real:.10f} + {z.imag:.6f}i")
    assert abs(z.real - 0.5) < 1e-8, "实部偏离 1/2！"
print("✓ 前 5 个零点实部都是 1/2")

# 可视化：零点在临界线上的分布
def zeta_critical_line():
    """
    沿临界线 s = 1/2 + it，画 |ζ(s)|
    零点对应 |ζ| = 0 的点
    """
    import numpy as np
    ts = np.linspace(0, 50, 2000)
    vals = [abs(complex(mpmath.zeta(0.5 + t*1j))) for t in ts]
    # 找极小值点（零点）
    print("\n在 t ∈ [0, 50] 内，|ζ(1/2+it)| 的极小值点即为零点虚部")
    print("预期：14.13, 21.02, 25.01, 30.42, 32.93, 37.58, 40.91, 43.33, 48.00, 49.77")

zeta_critical_line()
```

## M7.5 破解尝试路径

### 路径 1：谱解释（Hilbert-Pólya 猜想）

**思路**：如果零点是某个**自伴算子**的本征值，则本征值必为实数。

**Hilbert-Pólya 猜想**（传闻，未发表）：
存在自伴算子 \\(H\\)，其本征值为 \\(\\gamma_n\\)，其中 \\(1/2 + i\\gamma_n\\) 是 ζ 零点。

**尝试**：
- **Berry-Keating**：\\(H = xp\\)（位置×动量），与量子混沌相关
- **Connes**：用非交换几何构造"谱实现"
  - Connes 构造了**迹公式**，其谱与零点相关
  - 但尚未找到真正的自伴算子
- **量子混沌**：零点间距分布符合 GUE（高斯酉系综）——Montgomery-Odlyzko 定律
  - 暗示零点来自某个"量子系统"的能级

**关键突破点**：找到真正的 Hilbert-Pólya 算子。

**需要的工具**：量子混沌、非交换几何的突破。

```python
# Montgomery-Odlyzko 定律：零点间距 ~ GUE
# 这是"谱解释"最强的数值证据
def gue_evidence():
    """
    零点归一化间距的分布 ≈ GUE 本征值间距分布
    GUE：随机厄米矩阵的本征值统计
    
    如果零点是某个量子系统的能级，
    那么这个系统是"混沌"的（GUE 对应时间反演不对称的混沌系统）
    
    这强烈暗示 Hilbert-Pólya 算子存在，
    且对应的经典系统是混沌的！
    """
    print("零点间距 ~ GUE：谱解释的最强证据")
    print("Berry 猜想：H = xp 对应的经典系统是混沌的")
    print("但 H = xp 不是自伴的（定义域问题）——卡住了 25 年")

gue_evidence()
```

### 路径 2：De Bruijn-Newman 常数

**思路**：定义 \\(\\Lambda\\) 为使得
\\[ H(z, \\lambda) = \\int_0^\\infty e^{\\lambda u^2} \\Phi(u) \\cos(zu) \\, du \\]
的所有零点都是实数的最小 \\(\\lambda\\)。

**定理**：黎曼猜想 ⟺ \\(\\Lambda \\leq 0\\)。

**已知**：\\(\\Lambda \\geq 0\\)（Newman, 1976；实际 \\(\\Lambda \\geq -1.1 \\times 10^{-11}\\)，Polymath 2018）。

**所以**：只需证明 \\(\\Lambda \\leq 0\\)，即把下界从 \\(-10^{-11}\\) 推到 \\(0\\)！

**进展**：
- Rodgers-Tao (2018)：\\(\\Lambda \\geq 0\\)
- Polymath15（2019）：\\(\\Lambda < 0.2\\)
- 距离 \\(\\Lambda \\leq 0\\) 还有一小步，但这一步极难

**关键突破点**：改进 de Bruijn 的微分不等式。

### 路径 3：函数域类比（Weil 猜想已证明！）

**思路**：在**函数域**（有限域上的曲线）上，黎曼猜想的类比**已经证明**！

**Weil 猜想**（Deligne, 1974，菲尔兹奖）：
有限域上代数簇的 ζ 函数零点都在临界线上。

**启示**：
- Deligne 用**代数几何**（étale 上同调）证明了函数域版本
- 数域（\\(\\mathbb{Q}\\)）没有类似的几何工具
- **梦想**：找到 \\(\\mathbb{Q}\\) 的"几何"，模仿 Deligne 的证明

**障碍**：\\(\\mathrm{Spec}\\, \\mathbb{Z}\\) 不是有限型的，Weil 的工具用不上。

**需要的工具**：**算术几何**的革命性突破（如 perfectoid 空间，Scholze 已开辟道路，但还不够）。

```python
# 函数域 vs 数域
def function_field_vs_number_field():
    print("函数域（已解决）：")
    print("  曲线 C / F_q，zeta 函数 Z(C, t)")
    print("  Weil：零点 |t| = q^{-1/2}（临界线上！）")
    print("  工具：étale 上同调，Frobenius 的迹公式")
    print()
    print("数域（开放）：")
    print("  Spec Z，zeta 函数 ζ(s)")
    print("  黎曼：零点 Re(s) = 1/2")
    print("  障碍：没有 Frobenius，没有上同调的几何")
    print()
    print("梦想：找到 Spec Z 的'几何'，复制 Deligne 的证明")
    print("现状：Deninger、Connes 等人尝试中，路还很长")

function_field_vs_number_field()
```

### 路径 4（bonus）：李准则（Li's Criterion）

**思路**：黎曼猜想 ⟺ 一列**显式**的数 \\(\\lambda_n > 0\\)。

\\[ \\lambda_n = \\sum_{\\rho} \\left[1 - \\left(1 - \\frac{1}{\\rho}\\right)^n\\right] \\]

**Li 准则**（1997）：RH 成立 ⟺ 对所有 \\(n \\geq 1\\)，\\(\\lambda_n > 0\\)。

**意义**：把 RH 转化为**不等式**问题，可能更容易？

**现状**：已验证 \\(\\lambda_n > 0\\) 到 \\(n = 10^5\\)，但证明所有 \\(n\\) 仍开放。


### 题 M7.2 思路
显式公式：\\(\\psi(x) = x - \\sum_\\rho x^\\rho/\\rho + \\cdots\\)
- \\(|x^\\rho| = x^{\\mathrm{Re}(\\rho)}\\)
- 若 \\(\\mathrm{Re}(\\rho) = 1/2\\)，则每项 \\(\\sim x^{1/2}\\)，总误差 \\(O(\\sqrt{x}\\log^2 x)\\)
- 若有 \\(\\mathrm{Re}(\\rho) = \\sigma > 1/2\\)，则该项 \\(\\sim x^\\sigma\\)，误差更大
- **零点越接近 \\(1/2\\)，\\(x^{\\mathrm{Re}(\\rho)}\\) 越小，误差越小**
- RH 说**所有**零点都在 \\(1/2\\)，给出最优误差。∎

### 题 M7.3 思路
- **验证是有限的**：\\(10^{13}\\) 再大，也是有限数；零点有无穷多个
- **Skewes 数的教训**：\\(\\pi(x) < \\mathrm{Li}(x)\\) 对 \\(x < 10^{19}\\) 成立，但 Littlewood 证明**必然**有交叉，Skewes 给出上界 \\(10^{10^{10^{34}}}\\)（天文数字）
- 数学史教训：**数值证据可能误导**（Pólya 猜想在 \\(n < 906,150,257\\) 成立，但被 Haselgrove 证明有反例）
- **证明**要求逻辑必然性，不是"试了很多都没错"

### 题 M7.4 思路
**一句话**：如果零点是某个量子混沌系统的能级，那么能级间距服从 GUE 分布——而数值上零点间距**确实**服从 GUE，所以很可能存在这样的量子系统（即 Hilbert-Pólya 算子）。
- GUE = 高斯酉系综，描述**时间反演不对称**的混沌量子系统
- Montgomery（1973）猜想零点对关联符合 GUE
- Odlyzko（1980s）数值验证到 \\(10^7\\) 个零点，吻合得惊人
- 这是 RH 的"物理证据"，但不是证明
