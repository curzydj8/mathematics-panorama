## M1.1 问题陈述

### 定义

- **P**：**多项式时间**内可解的问题类。即存在算法，输入规模为 \\(n\\) 时，运行时间 \\(\\leq n^k\\)（\\(k\\) 为常数）。
- **NP**：**多项式时间**内可**验证**的问题类。即给定一个"证书"（certificate），能在多项式时间内验证它是否正确。

**问题**：\\[ P \\stackrel{?}{=} NP \\]

### 直观理解

| | P | NP |
|---|---|---|
| **找答案** | 容易（多项式时间） | 可能很难（指数时间） |
| **验答案** | 容易 | 容易 |
| **例子** | 排序、最短路径 | 数独、旅行商问题 |

**数独例子**：
- 给你一个填好的数独，验证它是否正确：很快（\\(O(n^2)\\)）
- 给你一个空白数独，让你填出来：可能很慢（指数级搜索）

```python
# P 问题：排序（多项式时间）
def sort_demo(arr):
    """O(n log n) —— P"""
    return sorted(arr)

# NP 问题：子集和（验证容易，找解难）
def verify_subset_sum(numbers, target, subset_indices):
    """验证：O(n) —— 容易"""
    return sum(numbers[i] for i in subset_indices) == target

def find_subset_sum_bruteforce(numbers, target):
    """找解：O(2^n) —— 指数级"""
    n = len(numbers)
    for mask in range(2**n):
        s = sum(numbers[i] for i in range(n) if mask & (1 << i))
        if s == target:
            return [i for i in range(n) if mask & (1 << i)]
    return None

nums = [3, 7, 8, 12, 15, 20, 25]
target = 35
sol = find_subset_sum_bruteforce(nums, target)
print(f"解：{sol} → {[nums[i] for i in sol]}")
print(f"验证：{verify_subset_sum(nums, target, sol)}")
# 当 n=100 时，2^100 次尝试——宇宙毁灭都算不完
```

## M1.2 现状：为什么这么难？

### 已知结果

1. **P ⊆ NP**（显然：能解的一定能验证）
2. **NP 完全问题**：NP 中"最难"的问题。如果任何一个 NP 完全问题有多项式算法，则 P = NP。
   - 第一个 NP 完全问题：SAT（Cook, 1971; Levin, 1973）
   - 已知 3000+ 个 NP 完全问题（旅行商、图着色、背包……）
3. **相对化障碍**（Baker-Gill-Solovay, 1975）：
   存在预言机 A 使 \\(P^A = NP^A\\)，也存在预言机 B 使 \\(P^B \\neq NP^B\\)。
   → **单纯的对角化方法无法解决 P vs NP**

## M1.3 破解尝试路径

### 路径 1：证明 P = NP（构造多项式算法）

**思路**：为某个 NP 完全问题找到多项式算法。

**尝试**：
- **SAT 求解器**：现代 SAT solver（如 Kissat）能解百万变量的实例，但最坏情况仍是指数级
- **近似算法**：旅行商问题有 1.5-近似（Christofides, 1976），但精确解仍无多项式算法
- **参数化复杂性**：固定某个参数后多项式可解，但一般情况仍难

**关键突破点**：需要全新的算法范式，可能来自：
- 量子计算？（但量子也不被认为能解 NP 完全问题）
- 某种"结构定理"：证明 NP 完全问题的实例都有隐藏的多项式结构

**需要的工具**：全新的组合优化理论，或对"计算"本质的重新理解。

```python
# 实验：SAT 求解器的实际表现 vs 理论最坏情况
# 现代 SAT solver 在随机 3-SAT 上的相变现象
import random

def random_3sat(n_vars, n_clauses):
    """生成随机 3-SAT 实例"""
    clauses = []
    for _ in range(n_clauses):
        clause = random.sample(range(1, n_vars+1), 3)
        clause = [v if random.random() < 0.5 else -v for v in clause]
        clauses.append(clause)
    return clauses

# 相变点：clause/variable ≈ 4.26 时最难
# 远离相变点时，SAT solver 很快；相变点附近指数级困难
print("3-SAT 相变点：m/n ≈ 4.26")
print("这说明 NP 完全问题的'难'集中在特定区域")
```

### 路径 2：证明 P ≠ NP（下界证明）

**思路**：证明任何解 SAT 的算法都需要超多项式时间。

**尝试**：
- **电路下界**：证明 SAT 需要超多项式规模的电路
  - 已知：奇偶性（parity）需要指数规模的恒定深度电路（Furst-Saxe-Sipser, 1984）
  - 未知：NP 完全问题需要超多项式**一般**电路
  - **自然证明障碍**（Razborov-Rudich, 1997）：一大类"自然"的下界证明方法不可能成功（除非因子分解很容易）
- **代数方法**：几何复杂性理论（GCT, Mulmuley-Sohoni）
  - 用代数几何和表示论攻击 P vs NP
  - 极其宏大，Mulmuley 估计需要 100 年

**关键突破点**：绕过"自然证明障碍"的新下界技术。

**需要的工具**：
- 更深的代数几何（GCT 需要的表示论目前还不够）
- 或全新的障碍绕行方法

### 路径 3：量子计算与新计算模型

**思路**：如果量子计算机能高效解 NP 完全问题，则在物理世界中"NP 容易"。

**现状**：
- **Shor 算法**（1994）：量子多项式时间分解大整数（属于 NP，但**不是** NP 完全）
- **Grover 算法**：平方级加速（\\(O(\\sqrt{N})\\) vs \\(O(N)\\)），但仍是指数级
- **普遍认为**：BQP（量子多项式）不包含 NP 完全问题

**关键突破点**：发现新的量子算法，或证明量子也做不到。

**需要的工具**：量子复杂性理论的突破。

### 路径 4（ bonus ）：平均情况复杂性

**思路**：也许 P vs NP 的"最坏情况"提法太强。实际中我们关心**平均情况**。

- **Levin 的平均情况理论**：定义 DistNP，研究"平均难"的问题
- 如果平均情况下 P = NP，对实践已足够
- 但这同样是开放问题

### 题 M1.1 思路
**归约**：如果问题 A 能多项式归约到问题 B（\\(A \\leq_p B\\)），且 B 有多项式算法，则 A 也有。
TSP 是 NP 完全的，意味着**所有** NP 问题都能归约到 TSP。
所以 TSP 的多项式算法 ⇒ 所有 NP 问题的多项式算法 ⇒ P = NP。∎
