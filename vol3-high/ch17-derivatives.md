## 17.1 从平均变化率到瞬时变化率

### 平均变化率

函数 \\(y = f(x)\\) 在区间 \\([x_1, x_2]\\) 上的平均变化率：
\\[ \frac{\Delta y}{\Delta x} = \frac{f(x_2) - f(x_1)}{x_2 - x_1} \\]

这是**割线**的斜率。

### 瞬时变化率：极限思想

让 \\(x_2 \to x_1\\)，割线变成**切线**：
\\[ f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h} \\]

这就是**导数**的定义！

**直觉**：汽车仪表盘显示的是瞬时速度（导数），
而"100 公里用了 2 小时"是平均速度。

```python
def derivative_numerical(f, x, h=1e-7):
    """数值导数：用差商逼近"""
    return (f(x + h) - f(x)) / h

import math
# f(x) = x^2 在 x=3 处的导数应为 6
print(f"数值导数: {derivative_numerical(lambda x: x**2, 3):.6f}")
# f(x) = sin(x) 在 x=0 处的导数应为 cos(0)=1
print(f"sin'(0) ≈ {derivative_numerical(math.sin, 0):.6f}")
```

## 17.2 导数的几何意义与物理意义

| 视角 | 导数 \\(f'(x)\\) 表示 |
|---|---|
| 几何 | 曲线 \\(y=f(x)\\) 在点 \\(x\\) 处**切线的斜率** |
| 物理 | 位移函数的导数 = **速度**；速度的导数 = **加速度** |
| 经济 | 成本函数的导数 = **边际成本** |

**切线方程**：
\\[ y - f(x_0) = f'(x_0)(x - x_0) \\]

### 用定义求导：\\(f(x) = x^2\\)

\\[ f'(x) = \lim_{h\to0}\frac{(x+h)^2 - x^2}{h} = \lim_{h\to0}\frac{2xh + h^2}{h} = \lim_{h\to0}(2x + h) = 2x \\] ∎

> 💡 **关键技巧**：分子展开后，\\(h\\) 总能约掉一项，
> 剩下不含 \\(h\\) 的部分取极限。

## 17.3 基本求导法则

### 幂函数法则

\\[ \frac{d}{dx}x^n = nx^{n-1} \\]

### 四则运算法则

\\[ (f+g)' = f' + g' \\]
\\[ (fg)' = f'g + fg' \quad \text{（乘积法则）} \\]
\\[ \left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2} \quad \text{（商法则）} \\]

**乘积法则证明**（经典）：
\\[ (fg)'(x) = \lim_{h\to0}\frac{f(x+h)g(x+h) - f(x)g(x)}{h} \\]
加一项减一项 \\(f(x+h)g(x)\\)：
\\[ = \lim_{h\to0}\left[f(x+h)\frac{g(x+h)-g(x)}{h} + g(x)\frac{f(x+h)-f(x)}{h}\right] \\]
\\[ = f(x)g'(x) + g(x)f'(x) \\] ∎

### 链式法则（复合函数求导）

\\[ \frac{d}{dx}f(g(x)) = f'(g(x)) \cdot g'(x) \\]

**口诀**："外导乘内导"。

例：\\(y = (3x^2+1)^5\\)，
\\[ y' = 5(3x^2+1)^4 \cdot 6x = 30x(3x^2+1)^4 \\]

### 常用导数表

| \\(f(x)\\) | \\(f'(x)\\) |
|---|---|
| \\(C\\)（常数） | 0 |
| \\(x^n\\) | \\(nx^{n-1}\\) |
| \\(\sin x\\) | \\(\cos x\\) |
| \\(\cos x\\) | \\(-\sin x\\) |
| \\(e^x\\) | \\(e^x\\) |
| \\(\ln x\\) | \\(\frac{1}{x}\\) |

> 🌟 **拉马努金角**
> 拉马努金对 \\(e^x\\) 的导数性质着迷。他发现：
> \\[ \frac{d}{dx}e^x = e^x \\]
> 是"唯一导数等于自身的函数"（差常数倍）。
> 他进一步研究了**分数阶导数**——"\\(f\\) 的 1/2 阶导数是什么？"
> 这个问题在当时无人能答，现在是"分数微积分"的前沿领域！
> 拉马努金还给出：
> \\[ \int_0^{\infty} \frac{\sin x}{x} dx = \frac{\pi}{2} \\]
> 这个积分需要精妙的极限技巧，是导数/积分互补的典范。

```python
import sympy as sp
x = sp.Symbol('x')
# 符号求导验证
for f in [x**3, sp.sin(x), sp.exp(x), sp.ln(x), (3*x**2+1)**5]:
    print(f"d/dx[{f}] = {sp.diff(f, x)}")
```

## 17.4 导数的应用：单调性与极值

### 单调性判定

- \\(f'(x) > 0\\) ⟹ \\(f\\) 在该区间**递增**
- \\(f'(x) < 0\\) ⟹ \\(f\\) 在该区间**递减**

### 极值：费马定理

若 \\(f\\) 在 \\(x_0\\) 取极值且可导，则 \\[ f'(x_0) = 0 \\]

**注意**：\\(f'(x_0)=0\\) 是**必要不充分**条件！
反例：\\(f(x) = x^3\\)，\\(f'(0) = 0\\)，但 0 不是极值点（是拐点）。

### 求最值三步法

1. 求 \\(f'(x)\\)，解 \\(f'(x) = 0\\) 得驻点
2. 用二阶导数或单调性判断极大/极小
3. 比较端点值与极值

**例**：求 \\(f(x) = x^3 - 3x\\) 在 \\([-2, 2]\\) 上的最值。
- \\(f'(x) = 3x^2 - 3 = 3(x-1)(x+1)\\)，驻点 \\(x = \pm 1\\)
- \\(f(-2) = -2\\)，\\(f(-1) = 2\\)，\\(f(1) = -2\\)，\\(f(2) = 2\\)
- 最大值 2， 最小值 -2。∎

```python
import numpy as np
def find_extrema(f, df, a, b, n=1000):
    """数值找极值点"""
    xs = np.linspace(a, b, n)
    critical = [x for x in xs[1:-1]
                if df(x-df.__defaults__[0] if False else x-1e-6) * df(x+1e-6) < 0]
    return critical

# f(x) = x^3 - 3x, f'(x) = 3x^2 - 3
f = lambda x: x**3 - 3*x
df = lambda x: 3*x**2 - 3
xs = np.linspace(-2, 2, 10001)
sign_change = [xs[i] for i in range(1, 10000)
               if df(xs[i-1]) * df(xs[i]) < 0]
print(f"驻点近似: {[round(x,3) for x in sign_change]}")  # [-1, 1]
```

## ✅ 习题解答

### 题 17.1 解答
\\[ f'(x) = \lim_{h\to0}\frac{(x+h)^3-x^3}{h} = \lim_{h\to0}\frac{3x^2h+3xh^2+h^3}{h} \\]
\\[ = \lim_{h\to0}(3x^2+3xh+h^2) = 3x^2 \\] ∎

### 题 17.2 解答
\\[ y' = (x^2)'\sin x + x^2(\sin x)' = 2x\sin x + x^2\cos x \\] ∎

### 题 17.3 解答
\\(y = (3x+1)^{1/2}\\)，
\\[ y' = \frac{1}{2}(3x+1)^{-1/2} \cdot 3 = \frac{3}{2\sqrt{3x+1}} \\] ∎

### 题 17.4 解答
\\(f'(x) = 3x^2 - 6x = 3x(x-2)\\)，驻点 \\(x=0, 2\\)。
| 区间 | \\((-\infty,0)\\) | \\((0,2)\\) | \\((2,+\infty)\\) |
|---|---|---|---|
| \\(f'\\) 符号 | + | − | + |
| 单调性 | 递增 | 递减 | 递增 |

极大值 \\(f(0) = 0\\)，极小值 \\(f(2) = -4\\)。∎

### 题 17.5 解答
\\(v(t) = s'(t) = 9.8t\\)，
\\[ v(2) = 19.6 \text{ 米/秒} \\] ∎

> 💡 这就是重力加速度 \\(g = 9.8\\, m/s^2\\) 的来源！

### 题 17.6 解答
**不可导**。

几何：\\(y=|x|\\) 在 0 处是"尖点"，没有唯一的切线。

定义：左导数 \\(\lim_{h\to0^-}\frac{|h|}{h} = -1\\)，
右导数 \\(\lim_{h\to0^+}\frac{|h|}{h} = 1\\)，
左右不等，极限不存在。∎

> 💡 **可导必连续，连续不一定可导**。\\(|x|\\) 是经典反例。
