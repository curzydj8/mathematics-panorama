## 14.1 集合：把东西装进"袋子"

### 什么是集合？

**集合**（Set）是一些**确定的、互不相同的**对象放在一起组成的整体。

记号：\\[ A = \\{1, 2, 3\\} \\]

- \\(1 \in A\\)：1 属于 A（\\(\in\\) 读作"属于"）
- \\(5 \notin A\\)：5 不属于 A

**三要素**：确定性（每个对象要么在要么不在）、互异性（不重复）、无序性（\\(\\{1,2,3\\} = \\{3,2,1\\}\\)）。

### 常见数集

\\[ \mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C} \\]

即：自然数 ⊂ 整数 ⊂ 有理数 ⊂ 实数 ⊂ 复数。

**区间记号**：
- \\([a, b] = \\{x \mid a \le x \le b\\}\\)（闭区间）
- \\((a, b) = \\{x \mid a < x < b\\}\\)（开区间）
- \\([a, b)\\)、\\((a, b]\\)（半开半闭）

### Python：集合操作

```python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print(f"并集 A∪B = {A | B}")       # {1,2,3,4,5,6}
print(f"交集 A∩B = {A & B}")       # {3,4}
print(f"差集 A-B = {A - B}")       # {1,2}
print(f"对称差 = {A ^ B}")         # {1,2,5,6}
print(f"A是B的子集？{A <= B}")     # False
```

## 14.2 集合运算：韦恩图的代数

### 三大运算

设全集为 \\(U\\)，\\(A, B \subseteq U\\)：

| 运算 | 记号 | 定义 |
|---|---|---|
| 并集 | \\(A \cup B\\) | \\(\\{x \mid x \in A \text{ 或 } x \in B\\}\\) |
| 交集 | \\(A \cap B\\) | \\(\\{x \mid x \in A \text{ 且 } x \in B\\}\\) |
| 补集 | \\(\complement_U A\\)（或 \\(A^c\\)） | \\(\\{x \in U \mid x \notin A\\}\\) |

### 德摩根定律（超级重要！）

\\[ \complement_U(A \cup B) = (\complement_U A) \cap (\complement_U B) \\]
\\[ \complement_U(A \cap B) = (\complement_U A) \cup (\complement_U B) \\]

**口诀**："补集穿过括号，并交互换。"

**证明**（第一条）：
\\(x \in \complement_U(A \cup B)\\)
\\(\iff x \notin A \cup B\\)
\\(\iff \neg(x \in A \text{ 或 } x \in B)\\)
\\(\iff x \notin A \text{ 且 } x \notin B\\)（逻辑德摩根）
\\(\iff x \in (\complement_U A) \cap (\complement_U B)\\)。∎

> 💡 **生活实例**："不是（班长或团支书）" = "不是班长**且**不是团支书"。
> 德摩根定律是逻辑电路（与非门、或非门）的理论基础！

### 容斥原理

\\[ |A \cup B| = |A| + |B| - |A \cap B| \\]

三集合版本：
\\[ |A \cup B \cup C| = |A|+|B|+|C| - |A\cap B|-|B\cap C|-|A\cap C| + |A\cap B\cap C| \\]

```python
# 容斥原理验证：1~100中能被2或3整除的数
S = set(range(1, 101))
A = {x for x in S if x % 2 == 0}
B = {x for x in S if x % 3 == 0}
print(f"|A|={len(A)}, |B|={len(B)}, |A∩B|={len(A&B)}")
print(f"|A∪B| = {len(A|B)}, 公式：{len(A)+len(B)-len(A&B)}")
# |A|=50, |B|=33, |A∩B|=16
# |A∪B| = 67, 公式：67 ✓
```

## 14.3 命题与逻辑联结词

### 什么是命题？

**命题**：能判断真假的陈述句。

- "3 是素数" → 真命题 ✓
- "1+1=3" → 假命题 ✗
- "你吃饭了吗？" → 不是命题（疑问句）
- "x > 5" → 不是命题（x 未定，开语句）

### 五大联结词

| 名称 | 符号 | 读法 | 真值表要点 |
|---|---|---|---|
| 非 | \\(\neg p\\) | 非p | 与p相反 |
| 合取 | \\(p \land q\\) | p且q | 全真才真 |
| 析取 | \\(p \lor q\\) | p或q | 全假才假 |
| 蕴含 | \\(p \Rightarrow q\\) | p推出q | 前真后假才假 |
| 等价 | \\(p \Leftrightarrow q\\) | p当且仅当q | 同真同假才真 |

**最容易错的**：\\(p \Rightarrow q\\)（"如果p则q"）。

真值表：
| \\(p\\) | \\(q\\) | \\(p \Rightarrow q\\) |
|---|---|---|
| 真 | 真 | 真 |
| 真 | 假 | **假**（唯一假！） |
| 假 | 真 | 真（"空真"） |
| 假 | 假 | 真（"空真"） |

> 💡 **"空真"的直觉**："如果明天下雨，我就带伞。"
> 如果根本没下雨（p假），无论带没带伞，这句话都不算说谎。
> 只有"下雨了却没带伞"（前真后假），才是食言。

### 逆否命题（证明利器！）

原命题：\\(p \Rightarrow q\\)
- 逆命题：\\(q \Rightarrow p\\)
- 否命题：\\(\neg p \Rightarrow \neg q\\)
- **逆否命题**：\\(\neg q \Rightarrow \neg p\\)

**定理**：原命题与逆否命题**等价**（同真同假）。

\\[ (p \Rightarrow q) \Leftrightarrow (\neg q \Rightarrow \neg p) \\]

**应用**：要证"若 \\(n^2\\) 是偶数，则 \\(n\\) 是偶数"，直接证很难。
证逆否："若 \\(n\\) 是奇数，则 \\(n^2\\) 是奇数"——太容易了！
设 \\(n = 2k+1\\)，则 \\(n^2 = 4k^2+4k+1 = 2(2k^2+2k)+1\\)，是奇数。∎

## 14.4 充分条件、必要条件、充要条件

这是高中数学的"重灾区"，一次讲透：

\\[ p \Rightarrow q \\]

- \\(p\\) 是 \\(q\\) 的**充分条件**："有 p 就够了"（p 能推出 q）
- \\(q\\) 是 \\(p\\) 的**必要条件**："没 q 就不行"（q 是 p 的"必需品"）

**记忆口诀**：箭头指向谁，谁就是必要的。
\\(p \Rightarrow q\\)：q 在箭头尖上，所以 q 必要；p 在箭头尾，所以 p 充分。

| 情况 | 名称 | 例子 |
|---|---|---|
| \\(p \Rightarrow q\\) 且 \\(q \not\Rightarrow p\\) | p 是 q 的充分不必要条件 | "x>2" ⇒ "x>1" |
| \\(q \Rightarrow p\\) 且 \\(p \not\Rightarrow q\\) | p 是 q 的必要不充分条件 | "x>1" 对 "x>2" |
| \\(p \Leftrightarrow q\\) | 充要条件 | "三角形等边" ⇔ "三角形等角" |
| 互不推出 | 既不充分也不必要 | "x>2" 与 "x<0" |

> 🌟 **拉马努金角**
> 拉马努金的笔记本里充满了"\\(p \\Rightarrow q\\)"式的断言——他给出结论（q），
> 却常常省略条件（p）和证明！哈代花了数十年补全这些逻辑链条。
> 例如拉马努金断言：
> \\[ \\sum_{n=1}^{\\infty} \\frac{1}{n^2} = \\frac{\\pi^2}{6} \\]
> 他"知道"这是真的（q），但完整证明（p ⇒ q 的链条）需要欧拉的傅里叶分析。
> **逻辑的严谨性，正是数学与"直觉猜测"的分水岭。**

### Python：真值表生成器

```python
def truth_table():
    """打印 p⇒q 的真值表"""
    print(f"{'p':<8}{'q':<8}{'p⇒q':<8}{'逆否命题':<8}")
    for p in [True, False]:
        for q in [True, False]:
            impl = (not p) or q          # p⇒q 等价于 ¬p∨q
            contra = (not (not q)) or (not p)  # ¬q⇒¬p
            # 简化：¬q⇒¬p 等价于 q∨¬p
            contra_simple = q or (not p)
            print(f"{p!s:<8}{q!s:<8}{impl!s:<8}{contra_simple!s:<8}")
            assert impl == contra_simple, "逆否命题不等价？！"
    print("✓ 原命题与逆否命题永远等价")

truth_table()
```

## ✅ 习题解答

### 题 14.1 解答
\\[ A \cup B = \\{1,2,3,4,5\\} = U \\]
\\[ A \cap B = \\{3\\} \\]
\\[ \complement_U A = \\{2,4\\} \\]

### 题 14.2 解答
\\[ \complement_U(\complement_U A \cup B) \\]
先对括号内用德摩根（反向）：
\\[ = \complement_U(\complement_U A) \cap \complement_U B \\]
\\[ = A \cap \complement_U B = A - B \\]
即"A 中去掉 B 的部分"。∎

### 题 14.3 解答
**原命题是假命题**：\\(x = -2\\) 时 \\(x^2 = 4\\) 但 \\(x \neq 2\\)。
（这是"前真后假"的情况。）

**逆否命题**："如果 \\(x \neq 2\\)，那么 \\(x^2 \neq 4\\)。"
逆否命题也是**假**的（\\(x=-2\\) 是反例）——验证了"原命题与逆否命题同真假"。∎

### 题 14.4 解答
**既不充分也不必要**。

- 不充分：a 是偶数（如 a=2），b 可以是奇数（如 b=3），此时 a+b=5 是奇数。等等——题目说 a+b 是偶数是**前提**！
  
  重新理解：设条件 P："a+b 是偶数"。问"a 是偶数"与"b 是偶数"的关系。
  
- a 偶 ⇒ b 偶？因为 a+b 偶，a 偶 ⟹ b = (a+b) - a = 偶 - 偶 = 偶。✓ 充分！
- b 偶 ⇒ a 偶？同理。✓ 必要！
  
**答案：充要条件**。∎

> 💡 偶+偶=偶，奇+奇=偶。和为偶数 ⟺ 两数同奇偶。

### 题 14.5 解答
设 A = 会唱歌，B = 会跳舞。
\\[ |A \cup B| = |A| + |B| - |A \cap B| = 30 + 25 - 12 = 43 \\]
两样都不会 = \\(50 - 43 = 7\\) 人。∎

### 题 14.6 思路
"\\(p \Rightarrow q\\) 为真"是说**推理关系**成立；"\\(q\\) 为真"是说**结论**成立。
例子：p="2是偶数"，q="哥德巴赫猜想成立"。
\\(p \Rightarrow q\\) 的真假未知（因为 q 未知），但这不影响 p 本身为真。
**逻辑蕴含讨论的是"如果…那么…"的结构，不是结论的真假。**
