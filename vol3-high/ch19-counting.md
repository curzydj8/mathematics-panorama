## 19.1 两个基本原理

### 加法原理（分类）

完成一件事有 \\(n\\) 类方法，第 \\(i\\) 类有 \\(m_i\\) 种：
\\[ \text{总数} = m_1 + m_2 + \cdots + m_n \\]

### 乘法原理（分步）

完成一件事分 \\(n\\) 步，第 \\(i\\) 步有 \\(m_i\\) 种：
\\[ \text{总数} = m_1 \times m_2 \times \cdots \times m_n \\]

**区分关键**：
- "或" → 分类 → 加法
- "且" → 分步 → 乘法

**例**：从甲地到乙地有 3 条路，乙地到丙地有 2 条路，
甲→乙→丙有 \\(3 \times 2 = 6\\) 种走法（分步，乘法）。

```python
# 乘法原理：3件上衣 × 2条裤子 = 6种搭配
shirts = ['红', '蓝', '白']
pants = ['黑', '灰']
combos = [(s, p) for s in shirts for p in pants]
print(f"搭配数: {len(combos)} = {len(shirts)} × {len(pants)}")
for c in combos: print(c)
```

## 19.2 排列与组合

### 排列数 \\(A_n^m\\)（有序）

从 \\(n\\) 个不同元素取 \\(m\\) 个**排成一列**：
\\[ A_n^m = n(n-1)(n-2)\cdots(n-m+1) = \frac{n!}{m!} \\]

### 组合数 \\(C_n^m\\)（无序）

从 \\(n\\) 个不同元素取 \\(m\\) 个（**不排**）：
\\[ C_n^m = \frac{A_n^m}{m!} = \frac{n!}{m!(n-m)!} \\]

**关系**：\\[ A_n^m = C_n^m \cdot m! \\]
（先选 \\(C_n^m\\)，再排 \\(m!\\)。）

### 组合数性质

\\[ C_n^m = C_n^{n-m} \quad \text{（对称性）} \\]
\\[ C_n^m = C_{n-1}^{m} + C_{n-1}^{m-1} \quad \text{（递推，杨辉三角！）} \\]
\\[ C_n^0 + C_n^1 + \cdots + C_n^n = 2^n \\]

**证明** \\(C_n^m = C_{n-1}^m + C_{n-1}^{m-1}\\)：
从 \\(n\\) 个取 \\(m\\) 个，盯住一个特殊元素 \\(x\\)：
- 不取 \\(x\\)：从剩下 \\(n-1\\) 个取 \\(m\\) 个 → \\(C_{n-1}^m\\)
- 取 \\(x\\)：从剩下 \\(n-1\\) 个取 \\(m-1\\) 个 → \\(C_{n-1}^{m-1}\\)
两类相加。∎

```python
import math
def C(n, m):
    if m < 0 or m > n: return 0
    return math.factorial(n) // (math.factorial(m) * math.factorial(n-m))

def A(n, m):
    return math.factorial(n) // math.factorial(n-m)

print(f"A(5,3) = {A(5,3)}")  # 60
print(f"C(5,3) = {C(5,3)}")  # 10
# 验证递推
for n in range(2, 8):
    for m in range(1, n):
        assert C(n,m) == C(n-1,m) + C(n-1,m-1)
print("✓ 杨辉三角递推验证通过")
```

> 🌟 **拉马努金角**
> 拉马努金对组合数有神奇的同余发现。他证明了：
> \\[ C_{2n}^{n} \equiv 0 \pmod{2} \quad (n \geq 1) \\]
> （中心二项式系数恒为偶数——因为 \\(C_{2n}^n = \frac{(2n)!}{(n!)^2}\\) 分子比分母多一个因子 2。）
> 更深刻的是，他研究了**分拆函数** \\(p(n)\\)（把 n 写成正整数和的方法数）：
> \\[ p(5n+4) \equiv 0 \pmod{5} \\]
> \\[ p(7n+5) \equiv 0 \pmod{7} \\]
> \\[ p(11n+6) \equiv 0 \pmod{11} \\]
> 这三个"拉马努金同余式"震惊了整个数论界，
> 至今仍是模形式理论的核心课题！

## 19.3 杨辉三角：数字的金字塔

```
        1
       1 1
      1 2 1
     1 3 3 1
    1 4 6 4 1
   1 5 10 10 5 1
  ...
```

第 \\(n\\) 行（从 0 开始）就是 \\(C_n^0, C_n^1, \ldots, C_n^n\\)。

### 惊人规律

1. **每行和**：\\(\sum_{k=0}^{n} C_n^k = 2^n\\)
2. **对角线**：第 2 条斜线是自然数，第 3 条是三角数
3. **斐波那契**：斜着加得到 \\(1, 1, 2, 3, 5, 8, \ldots\\)
4. **素数行**：第 \\(p\\) 行（\\(p\\) 素数）除两端外全被 \\(p\\) 整除

```python
def yanghui(n):
    """生成杨辉三角前n行"""
    tri = [[1]]
    for i in range(1, n):
        prev = tri[-1]
        row = [1] + [prev[j]+prev[j+1] for j in range(len(prev)-1)] + [1]
        tri.append(row)
    return tri

for row in yanghui(7):
    print(' '.join(f"{x:3d}" for x in row))

# 验证：每行和 = 2^n
for i, row in enumerate(yanghui(8)):
    assert sum(row) == 2**i
print("✓ 每行和为2^n")
```

## 19.4 二项式定理

\\[ (a+b)^n = \sum_{k=0}^{n} C_n^k a^{n-k} b^k \\]

**证明**（组合意义）：
\\((a+b)^n = (a+b)(a+b)\cdots(a+b)\\)（\\(n\\) 个括号），
展开时从每个括号选 \\(a\\) 或 \\(b\\)。
选 \\(k\\) 个 \\(b\\)（\\(n-k\\) 个 \\(a\\)）的方法数是 \\(C_n^k\\)，
对应项 \\(C_n^k a^{n-k}b^k\\)。∎

### 推论

- 令 \\(a=1, b=1\\)：\\(\sum C_n^k = 2^n\\)
- 令 \\(a=1, b=-1\\)：\\(\sum (-1)^k C_n^k = 0\\)
- 令 \\(a=1, b=x\\)：\\((1+x)^n = \sum C_n^k x^k\\)（生成函数！）

```python
def binomial_expand(n):
    """展开 (a+b)^n 的系数"""
    return [C(n, k) for k in range(n+1)]

print(f"(a+b)^4 = {' + '.join(f'{c}a^{4-k}b^{k}' for k, c in enumerate(binomial_expand(4)))}")
# (a+b)^4 = 1a^4b^0 + 4a^3b^1 + 6a^2b^2 + 4a^1b^3 + 1a^0b^4
```

**题 19.6**（思考）为什么 \\(\sum_{k=0}^{n} (-1)^k C_n^k = 0\\)？
从"奇子集与偶子集一样多"的角度解释。

---

## ✅ 习题解答

### 题 19.1 解答
\\[ A_6^3 = 6 \times 5 \times 4 = 120 \\]
\\[ C_6^3 = \frac{120}{3!} = \frac{120}{6} = 20 \\] ∎

### 题 19.2 解答
5 人全排列 \\(= 5! = 120\\) 种。
甲在乙左边 vs 甲在乙右边，对称，各占一半。
\\[ \text{答案} = \frac{120}{2} = 60 \\] ∎

> 💡 **对称性思维**：不直接数"甲左乙"，而是总数除以 2。这是组合数学的常用技巧。

### 题 19.3 解答
\\[ C_n^{n-m} = \frac{n!}{(n-m)!(n-(n-m))!} = \frac{n!}{(n-m)!m!} = C_n^m \\] ∎

组合意义：选 \\(m\\) 个 ⟺ 剩下 \\(n-m\\) 个不选，一一对应。

### 题 19.4 解答
\\[ (x+2)^4 = \sum_{k=0}^{4} C_4^k x^{4-k} 2^k \\]
\\[ = x^4 + 4\cdot x^3\cdot2 + 6\cdot x^2\cdot4 + 4\cdot x\cdot8 + 16 \\]
\\[ = x^4 + 8x^3 + 24x^2 + 32x + 16 \\] ∎

### 题 19.5 解答
系数是 \\(C_n^0, C_n^1, \ldots, C_n^n\\)，呈"中间大两头小"。
- \\(n\\) 偶数：\\(n=2m\\)，最大是 \\(C_{2m}^{m}\\)（中间项）
- \\(n\\) 奇数：\\(n=2m+1\\)，最大是 \\(C_{2m+1}^{m} = C_{2m+1}^{m+1}\\)（中间两项相等并列最大）∎

### 题 19.6 思路
\\((1-1)^n = 0^n = 0\\)（\\(n \geq 1\\)）。
组合意义：\\(n\\) 元集合的**奇子集**（元素个数为奇数）与**偶子集**一样多。
配对方法：固定一个元素 \\(x\\)，子集 \\(S\\) 与 \\(S \triangle \\{x\\}\\)（对称差）配对，
奇偶性恰好相反。这是一个**对合**（involution）！
**这是组合数学中最优美的思想之一：用配对证明相等。**
