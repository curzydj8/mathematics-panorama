## 18.1 坐标系：数与形的桥梁

### 笛卡尔的梦

1637 年，笛卡尔在《几何学》中提出：**用一对数 \\((x, y)\\) 表示平面上的点**。

从此，几何问题可以转化为代数方程！

- 点 → 有序对 \\((x, y)\\)
- 曲线 → 方程 \\(F(x, y) = 0\\)
- 交点 → 联立方程组的解

### 两点间距离

\\[ d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2} \\]

这是勾股定理的直接应用。

### 中点公式

\\[ M\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right) \\]

```python
import math
def distance(p1, p2):
    return math.sqrt((p2[0]-p1[0])**2 + (p2[1]-p1[1])**2)

def midpoint(p1, p2):
    return ((p1[0]+p2[0])/2, (p1[1]+p2[1])/2)

print(distance((1,2), (4,6)))  # 5.0
print(midpoint((1,2), (4,6)))  # (2.5, 4.0)
```

## 18.2 直线：最简单的方程

### 四种形式

| 形式 | 方程 | 适用 |
|---|---|---|
| 点斜式 | \\(y - y_0 = k(x - x_0)\\) | 已知点+斜率 |
| 斜截式 | \\(y = kx + b\\) | 斜率+截距 |
| 两点式 | \\(\frac{y-y_1}{y_2-y_1} = \frac{x-x_1}{x_2-x_1}\\) | 已知两点 |
| 一般式 | \\(Ax + By + C = 0\\) | 万能（\\(A,B\\)不同时为0） |

**斜率**：\\[ k = \frac{y_2-y_1}{x_2-x_1} = \tan\theta \\]
（\\(\theta\\) 是倾斜角，即直线与 x 轴正方向的夹角）

### 位置关系

- 平行：\\(k_1 = k_2\\)（且 \\(b_1 \neq b_2\\)）
- 垂直：\\(k_1 \cdot k_2 = -1\\)

**点到直线距离**：
\\[ d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}} \\]

**证明思路**：过点作直线的垂线，求垂足，再用距离公式。
（向量法更简洁，见第 24 章。）

## 18.3 圆：到定点距离相等的轨迹

### 标准方程

圆心 \\((a, b)\\)，半径 \\(r\\)：
\\[ (x-a)^2 + (y-b)^2 = r^2 \\]

### 一般方程

\\[ x^2 + y^2 + Dx + Ey + F = 0 \\]

配方可化为标准形。**存在条件**：\\(D^2 + E^2 - 4F > 0\\)。

圆心 \\(\left(-\frac{D}{2}, -\frac{E}{2}\right)\\)，半径 \\(r = \frac{\sqrt{D^2+E^2-4F}}{2}\\)。

### 直线与圆的位置关系

设圆心到直线距离为 \\(d\\)，半径为 \\(r\\)：
- \\(d > r\\)：相离
- \\(d = r\\)：相切
- \\(d < r\\)：相交（弦长 \\(2\sqrt{r^2-d^2}\\)）

```python
import math
def line_circle(A, B, C, cx, cy, r):
    """判断直线Ax+By+C=0与圆(x-cx)²+(y-cy)²=r²的位置关系"""
    d = abs(A*cx + B*cy + C) / math.sqrt(A*A + B*B)
    if abs(d - r) < 1e-9:
        return f"相切 (d={d:.3f})"
    elif d < r:
        chord = 2 * math.sqrt(r*r - d*d)
        return f"相交，弦长={chord:.3f} (d={d:.3f})"
    else:
        return f"相离 (d={d:.3f})"

print(line_circle(1, 0, -1, 0, 0, 2))  # x=1与圆x²+y²=4
# 相交，弦长=3.464 (d=1.000)
```

> 🌟 **拉马努金角**
> 拉马努金研究过"圆内格点问题"（高斯圆问题）：
> 半径为 \\(r\\) 的圆内有多少个整数坐标点？
> \\[ N(r) = \#\{(m,n) \in \mathbb{Z}^2 : m^2 + n^2 \le r^2\} \\]
> 高斯证明 \\(N(r) = \pi r^2 + O(r)\\)，拉马努金改进了误差项估计！
> 这个问题至今未完全解决（猜想误差是 \\(O(r^{1/2+\epsilon})\\)），
> 与黎曼猜想有深刻联系。

## 18.4 圆锥曲线：椭圆、双曲线、抛物线

### 统一定义（离心率）

到定点（焦点）距离与到定直线（准线）距离之比为常数 \\(e\\)：

\\[ \frac{\text{到焦点距离}}{\text{到准线距离}} = e \\]

- \\(0 < e < 1\\)：**椭圆**
- \\(e = 1\\)：**抛物线**
- \\(e > 1\\)：**双曲线**

### 椭圆

标准方程（焦点在 x 轴）：
\\[ \frac{x^2}{a^2} + \frac{y^2}{b^2} = 1 \quad (a > b > 0) \\]

- 长轴 \\(2a\\)，短轴 \\(2b\\)
- 焦距 \\(2c\\)，\\(c^2 = a^2 - b^2\\)
- 离心率 \\(e = \frac{c}{a}\\)
- **定义**：到两焦点距离之和为定值 \\(2a\\)

### 双曲线

\\[ \frac{x^2}{a^2} - \frac{y^2}{b^2} = 1 \\]

- \\(c^2 = a^2 + b^2\\)，\\(e = \frac{c}{a} > 1\\)
- 渐近线：\\(y = \pm\frac{b}{a}x\\)
- **定义**：到两焦点距离之差的绝对值为定值 \\(2a\\)

### 抛物线

\\[ y^2 = 2px \quad (p > 0) \\]

- 焦点 \\(\left(\frac{p}{2}, 0\right)\\)，准线 \\(x = -\frac{p}{2}\\)
- **定义**：到焦点与准线距离相等
- **光学性质**：平行于轴的光线经抛物面反射后汇聚于焦点（卫星天线！）

```python
# 绘制圆锥曲线示意（文本版）
def ellipse_points(a, b, n=12):
    import math
    pts = []
    for i in range(n):
        t = 2 * math.pi * i / n
        pts.append((a*math.cos(t), b*math.sin(t)))
    return pts

pts = ellipse_points(5, 3, 8)
for x, y in pts:
    print(f"({x:6.2f}, {y:6.2f})")
```

## 18.5 坐标法：几何问题的代数化

### 方法论

1. **建系**：选择合适的坐标系（原点、对称轴）
2. **设方程**：把几何条件翻译成方程
3. **解方程**：代数运算
4. **回几何**：把代数结果翻译回几何结论

### 例：证明三角形三条中线交于一点（重心）

**建系**：设 \\(A(0,0)\\)，\\(B(c,0)\\)，\\(C\\) 在某处。
用向量法（第 24 章）更简洁，这里用坐标：

设 \\(A(x_1,y_1)\\)，\\(B(x_2,y_2)\\)，\\(C(x_3,y_3)\\)。
BC 中点 \\(D\left(\frac{x_2+x_3}{2}, \frac{y_2+y_3}{2}\right)\\)。
中线 AD 的参数方程，找交点……

**向量速解**：重心 \\(G = \frac{A+B+C}{3}\\)（位置向量平均），
三条中线都过此点。∎

> 💡 **坐标法的威力**：把"显然"的几何事实变成可计算的代数。
> 但要注意：**好的建系是成功的一半**！

## ✅ 习题解答

### 题 18.1 解答
点斜式：\\[ y - 3 = -1(x - 2) \\]
即 \\[ x + y - 5 = 0 \\] ∎

### 题 18.2 解答
圆心 \\((0,0)\\)，\\(r=5\\)。
\\[ d = \frac{|3\cdot0+4\cdot0-5|}{\sqrt{9+16}} = \frac{5}{5} = 1 < 5 \\]
所以**相交**。弦长 \\(= 2\sqrt{25-1} = 4\sqrt{6}\\)。∎

### 题 18.3 解答
\\[ (x^2-4x+4) + (y^2+6y+9) = 3+4+9 \\]
\\[ (x-2)^2 + (y+3)^2 = 16 \\]
圆心 \\((2, -3)\\)，半径 \\(4\\)。∎

### 题 18.4 解答
\\(a^2=25\\)，\\(b^2=9\\)，所以 \\(a=5\\)，\\(b=3\\)。
\\(c = \sqrt{25-9} = 4\\)。
长轴 \\(2a=10\\)，短轴 \\(2b=6\\)，焦距 \\(2c=8\\)，离心率 \\(e = 4/5\\)。∎

### 题 18.5 解答
设焦点 \\(F(p/2, 0)\\)，准线 \\(x = -p/2\\)。
点 \\(P(x,y)\\) 在抛物线上 ⟺ \\(|PF| =\\) 到准线距离：
\\[ \sqrt{(x-p/2)^2+y^2} = |x+p/2| \\]
平方：\\((x-p/2)^2+y^2 = (x+p/2)^2\\)，
展开：\\(x^2-px+p^2/4+y^2 = x^2+px+p^2/4\\)，
化简：\\(y^2 = 2px\\)。∎

### 题 18.6 思路
每颗卫星给出"我在以卫星为球心、距离为半径的球面上"。
- 1 颗：球面
- 2 颗：两球面交线 = 圆
- 3 颗：圆与第三球面交 = 2 个点
- 4 颗：排除其中一个（不在地球表面），唯一确定位置。
**从圆到球面，是解析几何从二维到三维的自然推广。**
