## 20.1 为什么需要极限？—— 从芝诺悖论说起

### 阿基里斯追乌龟

公元前 5 世纪，芝诺提出了一个"证明"运动不可能的悖论：

> 阿基里斯（古希腊飞毛腿）追一只乌龟。乌龟先爬 100 米。
> 当阿基里斯跑到乌龟的起点时，乌龟又爬了 10 米；
> 当他跑到 10 米处，乌龟又爬了 1 米……
> 这样永远追不上！

**错在哪里？** 无穷多个步骤，不代表需要无穷时间。关键要看**时间总和是否收敛**：

设阿基里斯速度 \\(v_1 = 10\\) m/s，乌龟 \\(v_2 = 1\\) m/s，初始差距 \\(d = 100\\) m。

追上所需时间：\\[ T = \frac{d}{v_1 - v_2} = \frac{100}{9} \approx 11.11 \text{ s} \\]

芝诺的无穷步骤对应的时间是几何级数：
\\[ T = \frac{100}{10} + \frac{10}{10} + \frac{1}{10} + \cdots = 10\left(1 + \frac{1}{10} + \frac{1}{100} + \cdots\right) = 10 \cdot \frac{1}{1 - 1/10} = \frac{100}{9} \\]

无穷项相加，结果有限——这就是**极限**的威力。

### 直观的极限

\\[ \lim_{x \to 2} \frac{x^2 - 4}{x - 2} = ? \\]

\\(x = 2\\) 时分母为 0，但 \\(x \neq 2\\) 时：
\\[ \frac{x^2-4}{x-2} = \frac{(x-2)(x+2)}{x-2} = x + 2 \to 4 \\]

**极限回答的是"趋势"，不是"取值"**。函数在某点可以没有定义，但极限可以存在。

### Python：数值逼近

```python
def f(x):
    return (x**2 - 4) / (x - 2) if x != 2 else None

print("x 趋近于 2 时 f(x) 的值：")
for delta in [0.1, 0.01, 0.001, 0.0001, -0.1, -0.01, -0.001]:
    x = 2 + delta
    print(f"  x = {x:.4f}, f(x) = {f(x):.6f}")
# 无论从左还是从右，f(x) 都趋近于 4
```

## 20.2 ε-δ 语言 —— 把"无限接近"说清楚

### 魏尔斯特拉斯的革命

19 世纪之前，"无限小"是个含糊的概念（贝克莱主教嘲讽它是"消失量的幽灵"）。
1821 年柯西给出雏形，1872 年**魏尔斯特拉斯**用 ε-δ 语言彻底严格化。

**定义**（函数极限）：
\\[ \lim_{x \to a} f(x) = L \\]
当且仅当：对任意 \\(\varepsilon > 0\\)，存在 \\(\delta > 0\\)，
使得当 \\(0 < |x - a| < \delta\\) 时，有 \\(|f(x) - L| < \varepsilon\\)。

**人话翻译**：
> "你想让 \\(f(x)\\) 离 \\(L\\) 多近（\\(\varepsilon\\) 任意小），
> 我总能找到一个 \\(x\\) 的范围（\\(\delta\\)），让它实现。"

### 例：证明 \\(\lim_{x \to 3}(2x+1) = 7\\)

**证明**：对任意 \\(\varepsilon > 0\\)，要 \\(|(2x+1) - 7| < \varepsilon\\)，
即 \\(|2x - 6| < \varepsilon\\)，即 \\(|x - 3| < \varepsilon/2\\)。
取 \\(\delta = \varepsilon/2\\)，则 \\(0 < |x-3| < \delta\\) 时成立。∎

### 例：证明 \\(\lim_{x \to 2} x^2 = 4\\)

**证明**：\\(|x^2 - 4| = |x-2||x+2|\\)。
先限制 \\(|x - 2| < 1\\)，则 \\(1 < x < 3\\)，故 \\(|x+2| < 5\\)。
于是 \\(|x^2-4| < 5|x-2|\\)。
对任意 \\(\varepsilon > 0\\)，取 \\(\delta = \min(1, \varepsilon/5)\\)，
则 \\(|x-2| < \delta\\) 时 \\(|x^2-4| < \varepsilon\\)。∎

> 💡 **技巧**：先用 \\(\delta \leq 1\\) 把 \\(|x+2|\\) 控制住，
> 再让 \\(|x-2|\\) 足够小。这是 ε-δ 证明的常用套路。

### 数列极限

\\[ \lim_{n \to \infty} a_n = L \iff \forall \varepsilon > 0, \exists N, \forall n > N: |a_n - L| < \varepsilon \\]

**例**：\\(\lim_{n\to\infty} \frac{1}{n} = 0\\)。
证明：对 \\(\varepsilon > 0\\)，取 \\(N = 1/\varepsilon\\)，
则 \\(n > N\\) 时 \\(|1/n - 0| = 1/n < \varepsilon\\)。∎

## 20.3 极限运算法则

**定理**：若 \\(\lim f = A\\)，\\(\lim g = B\\)，则：
1. \\(\lim (f \pm g) = A \pm B\\)
2. \\(\lim (f \cdot g) = A \cdot B\\)
3. \\(\lim (f/g) = A/B\\)（\\(B \neq 0\\)）
4. \\(\lim f(g(x)) = f(\lim g(x))\\)（\\(f\\) 连续时，见 20.4）

### 两个重要极限

**（一）** \\[ \lim_{x \to 0} \frac{\sin x}{x} = 1 \\]

**（二）** \\[ \lim_{x \to \infty} \left(1 + \frac{1}{x}\right)^x = e \\]
其中 \\(e \approx 2.71828\\) 是自然对数的底。

**\\(e\\) 的由来**：\\(1\\) 元本金，年利率 \\(100\%\\)，
若 \\(n\\) 等分复利，年末本息为 \\((1+1/n)^n\\)。
\\(n \to \infty\\)（连续复利）时 → \\(e\\)。

### Python：数值验证两个重要极限

```python
import math

print("验证 sin(x)/x → 1：")
for x in [0.1, 0.01, 0.001, 0.0001]:
    print(f"  x={x}: sin(x)/x = {math.sin(x)/x:.10f}")

print("\n验证 (1+1/n)^n → e：")
for n in [10, 100, 1000, 10000, 100000]:
    print(f"  n={n}: {(1+1/n)**n:.10f}")
print(f"  e = {math.e:.10f}")
```

### 夹逼定理

若 \\(g(x) \leq f(x) \leq h(x)\\)，且 \\(\lim g = \lim h = L\\)，
则 \\(\lim f = L\\)。

**应用**：证明 \\(\lim_{x\to 0} \frac{\sin x}{x} = 1\\) 就用夹逼：
\\(0 < x < \pi/2\\) 时，\\(\sin x < x < \tan x\\)，
得 \\(\cos x < \frac{\sin x}{x} < 1\\)，令 \\(x \to 0\\) 即得。

## 20.4 连续性 —— 没有"跳跃"的函数

### 定义

\\(f\\) 在 \\(x = a\\) **连续**，当且仅当：
\\[ \lim_{x \to a} f(x) = f(a) \\]

即三条件：\\(f(a)\\) 有定义、极限存在、两者相等。

### 间断点分类

| 类型 | 特征 | 例子 |
|---|---|---|
| 可去间断 | 极限存在但 \\(\neq f(a)\\) 或无定义 | \\(\frac{x^2-4}{x-2}\\) 在 \\(x=2\\) |
| 跳跃间断 | 左右极限存在但不等 | 符号函数在 \\(x=0\\) |
| 无穷间断 | 极限为无穷 | \\(1/x\\) 在 \\(x=0\\) |
| 振荡间断 | 极限不存在也不无穷 | \\(\sin(1/x)\\) 在 \\(x=0\\) |

### 介值定理（IVT）

**定理**：若 \\(f\\) 在 \\([a,b]\\) 连续，且 \\(f(a) < d < f(b)\\)（或反之），
则存在 \\(c \in (a,b)\\) 使 \\(f(c) = d\\)。

**人话**：连续函数取遍中间的每一个值——画线不抬笔，必然经过。

**应用**：证明 \\(x^3 - 2 = 0\\) 有实根。
\\(f(1) = -1 < 0\\)，\\(f(2) = 6 > 0\\)，\\(f\\) 连续，
故存在 \\(c \in (1,2)\\) 使 \\(f(c) = 0\\)，即 \\(c = \sqrt[3]{2}\\)。∎

### Python：二分法找根（介值定理的算法化）

```python
def bisection(f, a, b, tol=1e-10):
    """二分法求根：要求 f(a)*f(b) < 0"""
    assert f(a) * f(b) < 0, "端点函数值必须异号"
    while (b - a) / 2 > tol:
        c = (a + b) / 2
        if f(c) == 0:
            return c
        if f(a) * f(c) < 0:
            b = c
        else:
            a = c
    return (a + b) / 2

root = bisection(lambda x: x**3 - 2, 1, 2)
print(f"³√2 ≈ {root:.10f}")
print(f"验证：{root**3:.10f}")
print(f"math库：{2**(1/3):.10f}")
```

> 🌟 **拉马努金角**
> 拉马努金对"连续性"有超越时代的直觉。他在笔记本中写下：
> \\[ \lim_{n \to \infty} \left[ \frac{1}{n+1} + \frac{1}{n+2} + \cdots + \frac{1}{2n} \right] = \ln 2 \\]
> 这本质上是黎曼和取极限：
> \\[ \sum_{k=1}^{n} \frac{1}{n+k} = \frac{1}{n}\sum_{k=1}^{n}\frac{1}{1+k/n} \to \int_0^1 \frac{dx}{1+x} = \ln 2 \\]
> 他没有学过严格的 ε-δ 语言，却能凭直觉正确处理极限——
> 哈代说："他的直觉像是一种直接的视觉。"

## 📝 本章习题

**题 20.1** 用 ε-δ 定义证明 \\(\lim_{x \to 1}(3x - 2) = 1\\)。

**题 20.2** 求 \\(\lim_{x \to 0} \frac{1 - \cos x}{x^2}\\)。
提示：\\(1 - \cos x = 2\sin^2(x/2)\\)。

**题 20.3** 证明 \\(\lim_{n \to \infty} \frac{n}{n+1} = 1\\)（用数列极限定义）。

**题 20.4** 判断 \\(f(x) = \begin{cases} x^2 & x \neq 2 \\\\ 5 & x = 2 \end{cases}\\) 在 \\(x=2\\) 是否连续？是什么间断点？

**题 20.5** 用介值定理证明：方程 \\(x^5 + x - 1 = 0\\) 在 \\((0,1)\\) 内有且仅有一个实根。

**题 20.6**（思考）\\(\lim_{x \to 0} \sin(1/x)\\) 是否存在？用 ε-δ 语言说明理由。

## ✅ 习题解答

### 题 20.1
对任意 \\(\varepsilon > 0\\)，要 \\(|(3x-2) - 1| < \varepsilon\\)，
即 \\(|3x - 3| = 3|x-1| < \varepsilon\\)，即 \\(|x-1| < \varepsilon/3\\)。
取 \\(\delta = \varepsilon/3\\) 即可。∎

### 题 20.2
\\[ \frac{1-\cos x}{x^2} = \frac{2\sin^2(x/2)}{x^2} = \frac{1}{2}\left(\frac{\sin(x/2)}{x/2}\right)^2 \\]
当 \\(x \to 0\\) 时 \\(x/2 \to 0\\)，由重要极限 \\(\frac{\sin t}{t} \to 1\\)，
得原式 \\(\to \frac{1}{2} \times 1^2 = \frac{1}{2}\\)。∎

### 题 20.3
\\(\left|\frac{n}{n+1} - 1\right| = \frac{1}{n+1} < \varepsilon \iff n > \frac{1}{\varepsilon} - 1\\)。
取 \\(N = 1/\varepsilon\\)，则 \\(n > N\\) 时成立。∎

### 题 20.4
\\(\lim_{x \to 2} f(x) = \lim_{x \to 2} x^2 = 4 \neq 5 = f(2)\\)。
极限存在但不等于函数值 → **可去间断点**。
（把 \\(f(2)\\) 改为 4 就连续了——"可去"即此意。）

### 题 20.5
设 \\(f(x) = x^5 + x - 1\\)，连续。
\\(f(0) = -1 < 0\\)，\\(f(1) = 1 > 0\\)。
由介值定理，存在 \\(c \in (0,1)\\) 使 \\(f(c) = 0\\)。
唯一性：\\(f'(x) = 5x^4 + 1 > 0\\) 恒成立（第21章），
\\(f\\) 严格单调递增，故至多一个零点。∎

### 题 20.6
**不存在**。取 \\(x_n = \frac{1}{2n\pi + \pi/2}\\)，则 \\(\sin(1/x_n) = 1\\)；
取 \\(y_n = \frac{1}{2n\pi - \pi/2}\\)，则 \\(\sin(1/y_n) = -1\\)。
\\(x_n, y_n \to 0\\) 但函数值分别 →1 和 -1，
故极限不存在（振荡间断）。
