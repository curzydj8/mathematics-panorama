# R6 拉马努金与现代数学：百年之后，他仍在前面

> *"拉马努金留下的不是答案，而是一百年的研究议程。"*

## R6.1 时间线：他的公式如何一步步变成现代数学

| 年份 | 事件 |
|---|---|
| 1916 | τ 函数论文发表，提出拉马努金猜想 |
| 1920 | 去世前一年写下 mock theta 函数，附在给哈代的最后一封信里 |
| 1936 | Watson 证明 mock theta 函数的变换公式 |
| 1937 | Rademacher 用 circle method 给出分拆数 p(n) 的精确公式 |
| 1974 | Deligne 证明拉马努金猜想（Weil 猜想的推论） |

拉马努金去世时 32 岁。他的工作在身后一百年里，每隔一二十年就"复活"一次，变成一个新领域。

## R6.2 Mock Theta 的复活：从"古怪的 q 级数"到黑洞

### 2002 年：Zwegers 的答案

拉马努金 1920 年说：mock theta 函数"像 theta 函数，但又不完全是"。他给不出定义。

2002 年，荷兰数学家 **Zwegers** 在博士论文中证明：mock theta 函数是**调和 Maass 形式**（一种非全纯模形式）的全纯部分。补上一个特定的非全纯"影子"（shadow），它就变成真正的模形式。

80 年的谜，一句话解开。

### 2006–2010 年：Bringmann 与 Ono

Bringmann 和 Ono 用 Zwegers 的框架：

- 证明了 Dyson 在 1944 年提出的关于分拆"秩"（rank）的猜想
- 给出 mock theta 函数系数的精确公式
- 把拉马努金的 17 个例子全部纳入统一理论

### 2012 年：黑洞熵

Dabholkar、Murthy、Zagier 发现：某些黑洞的微观态数目由 mock modular 形式计数。拉马努金 1920 年在病床上写下的 q 级数，出现在了量子引力的计算里。

**公式库对照**：mock theta 的 17 个例子与现代定义见 ramanujan-formulas 仓库 M08。

## R6.3 分拆同余式：Ono 的推广

### 拉马努金的三个同余式（1919）

\\[ p(5n+4) \equiv 0 \pmod 5, \quad p(7n+5) \equiv 0 \pmod 7, \quad p(11n+6) \equiv 0 \pmod{11} \\]

### Ono（2000）的定理

**对每一个素数 \\( m \ge 5 \\)，都存在无穷多个分拆同余式** \\( p(An+B) \equiv 0 \pmod m \\)。

拉马努金只看到了 5、7、11 三个例子，Ono 证明了这是一个普遍现象。证明工具是模形式理论——又是拉马努金播下的种子。

### Rademacher 精确公式（1937）

\\[ p(n) = \frac{1}{\pi\sqrt{2}}\sum_{k=1}^{\infty} A_k(n)\sqrt{k}\,\frac{d}{dn}\left(\frac{\sinh\left(\frac{\pi}{k}\sqrt{\frac{2}{3}\left(n-\frac{1}{24}\right)}\right)}{\sqrt{n-\frac{1}{24}}}\right) \\]

这是 Hardy–Ramanujan 渐近公式的精确版：无穷级数收敛到精确的整数值。Circle method 从 1918 年的论文出发，至今仍是解析数论的主力工具。

## R6.4 1/π：从笔记本到超级计算机

拉马努金 1914 年的 1/π 级数（R4 已讲）沉睡 70 年，1985 年 Gosper 用它算到 1750 万位，打破世界纪录。此后：

| 年份 | 人物/方法 | π 的位数 |
|---|---|---|
| 1985 | Gosper（拉马努金公式） | 1750 万 |
| 1988 | Chudnovsky 兄弟 | 10 亿量级 |
| 2024 | Chudnovsky（云计算） | 202 万亿 |

Chudnovsky 公式本质上就是拉马努金公式的推广（用 \\( \mathbb{Q}(\sqrt{-163}) \\) 的类数 1 性质）。今天每一次 π 的世界纪录，背后都是 1914 年的那张纸。

## R6.5 Rogers–Ramanujan 与统计物理

### 恒等式

\\[ \sum_{n=0}^{\infty}\frac{q^{n^2}}{(q;q)_n} = \prod_{n=1}^{\infty}\frac{1}{(1-q^{5n-1})(1-q^{5n-4})} \\]

### Baxter 的硬六边形模型

1980 年代，统计物理学家 Baxter 发现：二维晶格上"硬六边形"模型的配分函数，正好由 Rogers–Ramanujan 恒等式给出。拉马努金 1913 年的恒等式，成了统计力学可解模型的钥匙。

此后，Rogers–Ramanujan 恒等式又出现在共形场论、量子群表示论中。纯数学的恒等式，屡次在物理学里"恰好"出现。

## R6.6 未解之谜：留给 21 世纪的作业

### Lehmer 猜想

\\( \tau(n) \ne 0 \\) 对一切 \\( n \\) 成立（R5 已讲）。计算机验证到很大的 \\( n \\) 仍无反例，证明遥遥无期。

### Mock Theta 的完整分类

17 个例子已纳入理论，但拉马努金的失落笔记里还有更多"类 mock theta"的级数尚未完全分类。Andrews–Berndt 五卷本（2005–2018）整理出的 600+ 条公式中，仍有未被现代理论消化的部分。

### 出租车数（Taxicab 数）

\\( 1729 = 1^3 + 12^3 = 9^3 + 10^3 \\) 是最小的"两种方式表为两个立方和"的数（Taxicab(2)）。已知：

| Taxicab(n) | 值 | 发现 |
|---|---|---|
| Taxicab(2) | 1729 | 拉马努金，1918 |
| Taxicab(3) | 87539319 | 1957 |
| Taxicab(4) | 6963472309248 | 1991 |
| Taxicab(5) | 48988659276962496 | 2008 |
| Taxicab(6) | ？ | 仍未找到 |

一个病房里的闲聊，变成百年计算难题。

### Sato–Tate 与 τ 的分布

τ(p)/2p^{11/2} 的分布服从 Sato–Tate 律（半圆分布），这是 Barnet-Lamb、Geraghty、Harris、Taylor 在 2011 年证明的——拉马努金猜想的"统计版"。

## R6.7 拉马努金留给我们的启示

1. **公式先于理论**：他先写下正确的结果，理论在一百年里慢慢追赶。直觉与严格证明是数学的两条腿。
2. **跨越领域的种子**：一个 q 级数可以同时属于数论、物理、群论——数学本是一体的。
3. **笔记的价值**：3,254 条结果 + 600+ 条失落笔记公式，至今仍是研究课题的富矿。Berndt 花了 20 多年整理，Andrews–Berndt 又花 13 年。
4. **热爱超越出身**：没上过大学的职员，凭一本笔记本改写了数学史。

> *"请记住：数学不是少数天才的专利。拉马努金证明了，一个人、一支笔、一颗好奇的心，就足以触摸宇宙的结构。"*

## 📝 本章习题

**题 R6.1** 用 Rademacher 公式的思想解释：为什么 Hardy–Ramanujan 渐近公式 \\( p(n) \sim e^{\pi\sqrt{2n/3}}/(4n\sqrt{3}) \\) 的主项里出现 \\( \sqrt{2n/3} \\)（提示：circle method 中模形式的极点位置）。

**题 R6.2** 验证 \\( 87539319 \\) 可用两种方式表为两个立方和（Taxicab(3) 的定义）。

**题 R6.3** 查阅 M08：三阶 mock theta 函数 \\( f(q) \\) 的两种写法为什么等价（提示：\\( (-q;q)_n \\) 的展开）。

**题 R6.4** 结合本卷 R1–R6，写一段话回答：拉马努金的 3,254 条结果中，为什么"有公式无证明"反而成了优势？

---

## ✅ 习题解答

### 题 R6.1 解答

Circle method 把生成函数在单位圆附近展开，主导贡献来自 \\( q = 1 \\) 附近的奇点。模变换把 \\( q \to 1 \\) 的行为换成 \\( q \to 0 \\) 的行为，指数中出现 \\( \pi\sqrt{2n/3} \\)——系数 \\( \sqrt{2/3} \\) 来自 \\( \Delta \\) 的权 12 与分拆生成函数的模变换因子。本题重在理解"渐近公式的常数来自模形式的变换律"，不要求完整推导。∎

### 题 R6.2 解答

\\( 87539319 = 167^3 + 436^3 = 228^3 + 423^3 \\)。

验算：\\( 167^3 = 4657463 \\)，\\( 436^3 = 82881856 \\)，和为 87539319；\\( 228^3 = 11852352 \\)，\\( 423^3 = 75686967 \\)，和亦为 87539319。∎

### 题 R6.3 解答

\\( (-q;q)_n = (1+q)(1+q^2)\cdots(1+q^n) \\)，故 \\( (-q;q)_n^2 = (1+q)^2\cdots(1+q^n)^2 \\)。两种写法分母相同；又 \\( n = 0 \\) 项为 1，提出后求和从 \\( n = 1 \\) 开始。∎

### 题 R6.4 解答

要点（言之成理即可）：① 没有证明束缚了形式——他按"感觉对"写下公式，跳过了当时理论到不了的地方；② 后人为了补证明，发展出整套新理论（模形式、Maass 形式、circle method）；③ 公式本身成了"路标"，指引研究方向——Berndt 五卷本就是沿着路标逐条补证明的历史。若他只写自己能证明的，数学会少掉一百年的议程。∎
