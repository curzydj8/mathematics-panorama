## 5.1 小数的意义：位值制的延伸

### 从整数到小数

还记得位值制吗？\\[ 345 = 3 \\times 10^2 + 4 \\times 10^1 + 5 \\times 10^0 \\]

小数就是把位值制**向右延伸**：
\\[ 3.14 = 3 \\times 10^0 + 1 \\times 10^{-1} + 4 \\times 10^{-2} \\]
\\[ = 3 + \\frac{1}{10} + \\frac{4}{100} \\]

**小数点**：整数部分和小数部分的分界线。
小数点后第 1 位是"十分位"，第 2 位是"百分位"，第 3 位是"千分位"……

### 小数与分数的互化

**有限小数 → 分数**：
\\[ 0.75 = \\frac{75}{100} = \\frac{3}{4} \\]

**分数 → 小数**（除法）：
\\[ \\frac{1}{4} = 1 \\div 4 = 0.25 \\quad \\text{（除得尽）} \\]
\\[ \\frac{1}{3} = 1 \\div 3 = 0.333\\ldots \\quad \\text{（除不尽！）} \\]

**无限循环小数**：\\(0.333\\ldots\\) 记作 \\(0.\\dot{3}\\)，
\\(0.123123\\ldots\\) 记作 \\(0.\\dot{1}2\\dot{3}\\)。

**重要定理**：每个有理数都可以表示为**有限小数或无限循环小数**，
反之亦然。（证明见习题 5.5）

```python
from fractions import Fraction
from decimal import Decimal, getcontext

getcontext().prec = 30  # 30位精度

# 分数转小数
for frac in [Fraction(1,4), Fraction(1,3), Fraction(1,7), Fraction(1,11)]:
    d = Decimal(frac.numerator) / Decimal(frac.denominator)
    print(f"{frac} = {d}")

# 1/7 = 0.142857142857...（6位循环！）
# 1/11 = 0.090909...（2位循环）
```

## 5.2 小数四则运算

### 加减法：小数点对齐

\\[ \\begin{aligned}
3.14 + 2.5 &= \\\\
3.14 + 2.50 &= 5.64
\\end{aligned} \\]

**为什么对齐？** 因为只有**相同数位**才能相加：
十分位 + 十分位，百分位 + 百分位——和整数的"个位对个位"一个道理。

### 乘法：先不看小数点

\\[ 2.5 \\times 1.2 \\]

1. 不看小数点：\\(25 \\times 12 = 300\\)
2. 数小数位数：\\(2.5\\) 有 1 位，\\(1.2\\) 有 1 位，共 2 位
3. 点上小数点：\\(3.00 = 3\\)

**原理**：\\[ 2.5 \\times 1.2 = \\frac{25}{10} \\times \\frac{12}{10} = \\frac{300}{100} = 3 \\]

### 除法：化为整数除法

\\[ 6.25 \\div 2.5 = 62.5 \\div 25 = 2.5 \\]

被除数和除数**同时扩大相同倍数**，商不变（分数基本性质！）。

```python
# 小数运算的精度陷阱！
print(0.1 + 0.2)  # 0.30000000000000004（不是0.3！）

# 为什么？因为 0.1 在二进制中是无限循环小数
# 就像十进制的 1/3 = 0.333... 一样

from decimal import Decimal
print(Decimal('0.1') + Decimal('0.2'))  # 0.3（精确！）

# 金融计算必须用 Decimal，不能用 float！
price = Decimal('19.99')
qty = 3
print(f"总价：{price * qty}")  # 59.97（精确）
```

> 💡 **计算机为什么算不对 0.1+0.2？**
> 因为计算机用二进制，而 \\(0.1\\) 在二进制中是无限循环小数
> \\(0.0001100110011\\ldots\\)，只能近似存储。
> 这不是 bug，是**进制的本质限制**——就像十进制写不出 \\(\\frac{1}{3}\\) 的精确值。
> 银行系统都用 Decimal 类型，就是为了避开这个坑。

## 5.3 百分数：生活中的数学

### 定义

**百分数**：分母是 100 的分数的特殊写法。
\\[ 35\\% = \\frac{35}{100} = 0.35 \\]

**三者互化**：
\\[ 0.35 = 35\\% = \\frac{7}{20} \\]

### 为什么用百分数？

因为**直观**！"增长 35%"比"增长 \\(\\frac{7}{20}\\)"好理解多了。
百分数把一切都统一到"满分 100"的尺度上——就像考试分数。

### 增长率

\\[ \\text{增长率} = \\frac{\\text{新值} - \\text{旧值}}{\\text{旧值}} \\times 100\\% \\]

**例子**：去年工资 5000，今年 6000：
\\[ \\frac{6000-5000}{5000} \\times 100\\% = 20\\% \\]

**注意**：从 100 涨到 150 是 +50%，再从 150 跌回 100 是 \\(-33.3\\%\\)，
不是 -50%！**涨跌的基数不同**——这是商家的常用伎俩。

```python
def growth_rate(old, new):
    return (new - old) / old * 100

# 先涨50%再跌50%，回到原点吗？
price = 100
price *= 1.5   # 涨50% → 150
price *= 0.5   # 跌50% → 75（不是100！）
print(f"先涨50%再跌50%：100 → {price}")
print(f"实际亏损：{growth_rate(100, price):.1f}%")

# 要涨回100，需要涨多少？
print(f"从75涨回100需要：{growth_rate(75, 100):.1f}%")  # 33.3%
```

> 🌟 **拉马努金角：\\(\\pi\\) 的百分数逼近**
>
> 拉马努金给出了 \\(\\pi\\) 的多个**有理逼近**，精度惊人：
> \\[ \\pi \\approx \\frac{22}{7} = 3.142857\\ldots \\quad (\\text{误差 } 0.04\\%) \\]
> \\[ \\pi \\approx \\frac{355}{113} = 3.1415929\\ldots \\quad (\\text{误差 } 0.000008\\%) \\]
>
> \\(\\frac{355}{113}\\) 是祖冲之在 1500 年前发现的！
> 它是 \\(\\pi\\) 的**连分数**截断——连分数能给出"最优"的有理逼近。
>
> 拉马努金更进一步，他发现了**无穷级数**：
> \\[ \\frac{1}{\\pi} = \\frac{2\\sqrt{2}}{9801} \\sum_{n=0}^{\\infty} \\frac{(4n)!(1103+26390n)}{(n!)^4 396^{4n}} \\]
> 这个级数**每算一项，\\(\\pi\\) 的精度增加 8 位小数**！
> 1985 年，Gosper 用它算出了 \\(\\pi\\) 的 1700 万位，打破世界纪录。
>
> ```python
> import math

## 5.4 折扣、利率、税率：真实世界应用

### 折扣

"打 8 折" = 按原价的 \\(80\\%\\) 付款。
\\[ \\text{现价} = \\text{原价} \\times 80\\% \\]

**陷阱**："满 200 减 50" vs "打 75 折"，哪个划算？
- 200 元商品：满减后 150，折扣后 150——一样！
- 199 元商品：满减不适用（199），折扣后 149.25——折扣划算！
- 300 元商品：满减后 250（83折），折扣后 225——折扣划算！

### 单利 vs 复利

**单利**：只对本金计息。
\\[ \\text{本息} = P(1 + rt) \\]

**复利**：利息也生利息（"利滚利"）。
\\[ \\text{本息} = P(1 + r)^t \\]

**例子**：10000 元，年利率 5%，存 10 年：
- 单利：\\(10000 \\times (1 + 0.05 \\times 10) = 15000\\)
- 复利：\\(10000 \\times 1.05^{10} \\approx 16289\\)

复利多赚 1289 元！时间越长，差距越大——这就是**指数增长**的威力。

```python
def compound(principal, rate, years):
    """复利计算"""
    return principal * (1 + rate) ** years

P, r = 10000, 0.05
print(f"{'年份':<6} {'单利':<12} {'复利':<12} {'差距':<10}")
for t in [1, 5, 10, 20, 30]:
    simple = P * (1 + r * t)
    comp = compound(P, r, t)
    print(f"{t:<6} {simple:<12.0f} {comp:<12.0f} {comp-simple:<10.0f}")

# 30年后：单利25000，复利43219，差距18219！
# 爱因斯坦（据传）："复利是世界第八大奇迹。"
```

### 税率

"个人所得税起征点 5000，超过部分按 3% 缴税"：
月薪 8000，应纳税所得 \\(= 8000 - 5000 = 3000\\)，
应缴税 \\(= 3000 \\times 3\\% = 90\\) 元。

## ✅ 习题解答

### 题 5.1
\\(\\frac{3}{8} = 3 \\div 8 = 0.375\\)。
\\(0.125 = \\frac{125}{1000} = \\frac{1}{8}\\)。

### 题 5.2
\\[ 3.6 \\times 2.5 = \\frac{36 \\times 25}{100} = \\frac{900}{100} = 9 \\]
\\[ 7.2 \\div 0.8 = 72 \\div 8 = 9 \\]

### 题 5.3
\\(299 \\times 70\\% = 299 \\times 0.7 = 209.3\\) 元。

### 题 5.4
设原价 \\(P\\)：
涨价后 \\(P \\times 1.2\\)，再降价 \\(P \\times 1.2 \\times 0.8 = 0.96P\\)。
现价是原价的 \\(96\\%\\)，**跌了 4%**！

**教训**：涨跌的基数不同，\\(+20\\%\\) 再 \\(-20\\%\\) 不等于原价。

### 题 5.5
**证明** \\(0.\\dot{3} = \\frac{1}{3}\\)：
设 \\(x = 0.333\\ldots\\)，则 \\(10x = 3.333\\ldots\\)，
\\(10x - x = 3\\)，\\(9x = 3\\)，\\(x = \\frac{1}{3}\\)。∎

**证明** \\(0.\\dot{1}2\\dot{3} = \\frac{41}{333}\\)：
设 \\(x = 0.123123\\ldots\\)，循环节 3 位，则 \\(1000x = 123.123\\ldots\\)，
\\(1000x - x = 123\\)，\\(999x = 123\\)，\\(x = \\frac{123}{999} = \\frac{41}{333}\\)。∎

**一般证明**：设循环节长度为 \\(k\\)，\\(x = 0.\\overline{a_1\\ldots a_k}\\)，
则 \\(10^k x - x =\\) 整数 \\(N\\)（循环部分抵消），
\\(x = \\frac{N}{10^k - 1}\\) 是有理数。∎

### 题 5.6
月利率 \\(= 0.06/12 = 0.005\\)，
实际年利率 \\(= (1.005)^{12} - 1 \\approx 0.06168 = 6.168\\%\\)。
比名义的 6% 高出 0.168%！复利次数越多，实际利率越高，
极限是 \\(e^{0.06} - 1 \\approx 6.184\\%\\)（连续复利，\\(e\\) 见第 21 章）。
