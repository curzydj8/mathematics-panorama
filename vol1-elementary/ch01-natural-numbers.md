## 1.1 数数：人类最古老的数学

### 从羊到数字

想象你是 8000 年前的牧羊人。每天早上把羊赶出圈，晚上数着回来——少了一只，就是大事。

最早的"数数"就是这样开始的：
- 在骨头上刻痕（伊尚戈骨，约 20000 年前）
- 用手指计数（10 进制的起源——因为我们有 10 根手指！）
- 结绳记事（中国、印加帝国都用过）

**关键洞察**：数字是**抽象**的。3 只羊、3 块石头、3 颗星星——"3"本身不依赖于具体的东西。这种抽象能力，是数学的起点。

### 自然数的定义

**自然数**（Natural Numbers）：\\[ \mathbb{N} = \\{1, 2, 3, 4, 5, \\ldots\\} \\]

（注：有些教材把 0 也算入自然数，本书采用 1 开始的版本，0 在 1.4 节单独介绍）

**皮亚诺公理**（1889年，朱塞佩·皮亚诺）——用 5 条规则定义"什么是自然数"：

1. 1 是自然数
2. 每个自然数 \\(n\\) 都有一个"后继" \\(S(n)\\)（就是 \\(n+1\\)）
3. 1 不是任何自然数的后继（1 是起点）
4. 不同的自然数有不同的后继（\\(S(a) = S(b) \\Rightarrow a = b\\)）
5. **归纳公理**：如果一个性质对 1 成立，且"对 \\(n\\) 成立则对 \\(S(n)\\) 成立"，那么它对所有自然数成立

> 💡 **为什么公理重要？**
> 公理就像游戏规则。我们不证明公理，而是从公理出发证明一切。
> 第 5 条（数学归纳法）是整个数学证明的基石，高中会深入学习。

### Python 验证：生成自然数

```python
def natural_numbers(n):
    """生成前 n 个自然数"""
    return list(range(1, n + 1))

def successor(n):
    """皮亚诺后继函数 S(n) = n+1"""
    return n + 1

# 验证：S(S(S(1))) = 4
result = successor(successor(successor(1)))
print(f"S(S(S(1))) = {result}")  # 输出：4
assert result == 4

# 生成前 20 个自然数
print(natural_numbers(20))
```

## 1.2 位值制：最伟大的发明之一

### 为什么 10 进制？

因为人类有 10 根手指。但这不是唯一选择：
- **2 进制**：计算机用（只有 0 和 1）
- **12 进制**：古巴比伦用（12 个月、12 小时、1 打=12 个）
- **60 进制**：巴比伦，用于角度和时间（60 秒、60 分、360°）

### 位值制的威力

数字 `345` 的真正含义是：
\\[ 345 = 3 \\times 100 + 4 \\times 10 + 5 \\times 1 = 3 \\times 10^2 + 4 \\times 10^1 + 5 \\times 10^0 \\]

**一般形式**：一个 \\(k\\) 位数 \\(d_{k-1}d_{k-2}\\ldots d_1d_0\\) 表示：
\\[ N = d_{k-1} \\times 10^{k-1} + d_{k-2} \\times 10^{k-2} + \\cdots + d_1 \\times 10^1 + d_0 \\times 10^0 \\]

> 🌟 **拉马努金角**
> 拉马努金对数字的"位值"有惊人直觉。他曾说 1729 是"很有趣的数"——
> \\[ 1729 = 1^3 + 12^3 = 9^3 + 10^3 \\]
> 这是能用两种不同方式表示为两立方和的最小数（"哈代-拉马努金数"）。
> 数字的十进制表示下，隐藏着无穷奥秘。

### Python：数字分解

```python
def decompose(n):
    """把数字按位值分解"""
    digits = []
    temp = n
    position = 0
    while temp > 0:
        d = temp % 10
        digits.append((d, position, d * (10 ** position)))
        temp //= 10
        position += 1
    return digits

for d, pos, val in decompose(345):
    print(f"数字 {d} 在 10^{pos} 位上，贡献 {val}")

# 输出：
# 数字 5 在 10^0 位上，贡献 5
# 数字 4 在 10^1 位上，贡献 40
# 数字 3 在 10^2 位上，贡献 300
```

## 1.3 数的比较与排序

### 基本符号

- \\(a < b\\)：a 小于 b
- \\(a > b\\)：a 大于 b
- \\(a = b\\)：a 等于 b

**三歧性**：对任意两个自然数 \\(a, b\\)，恰有一个成立：\\(a < b\\)，\\(a = b\\)，\\(a > b\\)。

### 传递性（重要的逻辑）

如果 \\(a < b\\) 且 \\(b < c\\)，那么 \\(a < c\\)。

**证明**（用皮亚诺公理的直观版）：
从 \\(a\\) 数到 \\(b\\) 需要 \\(m\\) 步，从 \\(b\\) 数到 \\(c\\) 需要 \\(n\\) 步，
那么从 \\(a\\) 数到 \\(c\\) 需要 \\(m+n\\) 步，所以 \\(a < c\\)。∎

## 1.4 零的发明：从"没有"到"占位符"

0 的发明是数学史上的革命（印度，约公元 5 世纪）：

1. **作为"没有"**：3 - 3 = 0
2. **作为"占位符"**：205 中的 0 表示"十位上没有"，没有它就分不清 25 和 205！

\\[ 205 = 2 \\times 10^2 + 0 \\times 10^1 + 5 \\times 10^0 \\]

如果没有 0，我们就写不出 205、1000、1000000……

## 1.5 大数：从万到无穷

中国的大数单位：十、百、千、**万**、亿、兆……

\\[ 1\\text{亿} = 10^8 = 100,000,000 \\]

**感受大数**：
- 1 秒数 1 个数，不吃不睡，数到 1 亿需要约 **3.17 年**
- 一张纸对折 42 次，厚度超过**地球到月球的距离**（\\(2^{42}\\) 增长）

```python
# 一张纸对折：厚度指数增长
thickness_mm = 0.1  # 0.1毫米
for i in range(1, 43):
    thickness_mm *= 2
    if i in [10, 20, 30, 42]:
        print(f"对折 {i} 次：{thickness_mm/1000:.1f} 米")
# 对折42次：439804.7 公里（地月距离约38万公里）
```

## ✅ 习题解答

### 题 1.1 解答
\\[ 5 = S(S(S(S(1)))) \\]
即对 1 连续取 4 次后继：1→2→3→4→5。

### 题 1.2 解答
\\[ 2026 = 2 \\times 10^3 + 0 \\times 10^2 + 2 \\times 10^1 + 6 \\times 10^0 \\]
\\[ = 2000 + 0 + 20 + 6 \\]

### 题 1.3 解答
9876 > 9867。
**步骤**：从最高位比起，千位都是 9，百位都是 8，十位 7 > 6，所以 9876 更大。

### 题 1.4 解答
**证明**：根据皮亚诺公理 2，\\(S(n)\\) 是 \\(n\\) 的后继。
"后继"的定义就是"数数时的下一个"，所以 \\(S(n)\\) 比 \\(n\\) 大 1。
因此 \\(n < S(n)\\)，即 \\(n < n+1\\)。∎

> 💡 这是数学归纳法的基础：每一步都比上一步大 1，
> 所以自然数是无穷的——永远有"下一个"。

### 题 1.5 解答
**答案**：65 是能用两种不同方式表示为两平方和的最小数。

**证明思路**：
1. 先验证：\\(65 = 64 + 1 = 8^2 + 1^2\\)，且 \\(65 = 49 + 16 = 7^2 + 4^2\\)。✓
2. 证明最小性：设 \\(n < 65\\) 能表示为 \\(a^2 + b^2 = c^2 + d^2\\)（两组不同）。
   - \\(n\\) 必须是合数（素数 \\(p \\equiv 3 \\pmod 4\\) 不能表示为两平方和——这是费马定理，后面章节会证）
   - 逐个检查 \\(n < 65\\) 的合数：25=\\(5^2\\)（只有一种：\\(3^2+4^2\\)），50=\\(1^2+7^2=5^2+5^2\\)……
   
   用 Python 穷举验证：

```python
def two_square_ways(n):
    """找出 n 的所有两平方和表示"""
    ways = []
    i = 0
    while i * i <= n:
        j2 = n - i * i
        j = int(j2 ** 0.5)
        if j * j == j2 and i <= j:  # i<=j 避免重复
            ways.append((i, j))
        i += 1
    return ways

for n in range(1, 66):
    ways = two_square_ways(n)
    if len(ways) >= 2:
        print(f"{n} = {' = '.join(f'{a}²+{b}²' for a, b in ways)}")
        break
# 输出：65 = 1²+8² = 4²+7²
```

运行结果确认 65 是第一个有两个表示的数。∎

> 🌟 **拉马努金注**：拉马努金对这类"多种表示"的数极度敏感。
> 1729（两立方和两种表示）就是他在病床上脱口而出的。
> 这种对数字的"感觉"，来自他对整数无与伦比的熟悉。

### 题 1.6 思路提示
8 进制下只有数字 0-7。\\(7_8 + 1_8 = 10_8\\)（即十进制的 8）。
"七七表"：\\(2_8 \\times 3_8 = 6_8\\)，\\(3_8 \\times 3_8 = 11_8\\)（十进制 9 = 8+1）。
试着完整写出来，你会发现乘法表的结构和 10 进制完全一样——
**进制只是"衣服"，数学结构才是"身体"**。
