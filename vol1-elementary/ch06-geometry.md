## 6.1 点、线、面：几何的基本元素

### 三个基本概念

- **点**：没有大小，只有位置。记作 \\(A\\)、\\(B\\)。
- **线**：由无数个点组成。直线向两端无限延伸，线段有两个端点。
- **面**：由无数条线组成。平面向四周无限延伸。

**维度**：
- 点是 0 维（没有方向可走）
- 线是 1 维（前后）
- 面是 2 维（前后+左右）
- 体是 3 维（+上下）——我们生活的空间！

> 💡 **点真的"没有大小"吗？**
> 这是理想化。现实中的"点"（如笔尖）都有大小，
> 但数学把大小忽略，只保留"位置"——**抽象** again！
> 这种"抓大放小"的能力，是数学建模的核心（第 30 章）。

### 角：旋转的度量

**角**：两条射线从同一点出发形成的图形。

**度数**：把圆周 360 等分，每份是 \\(1^\\circ\\)（1 度）。

| 角度 | 名称 | 例子 |
|---|---|---|
| \\(0^\\circ\\) | 零角 | 时针分针重合 |
| \\(90^\\circ\\) | 直角 | 桌角 |
| \\(180^\\circ\\) | 平角 | 直线 |
| \\(360^\\circ\\) | 周角 | 转一圈 |

**为什么 360°？** 古巴比伦的 60 进制：\\(360 = 6 \\times 60\\)。
而且 360 有 24 个因数（1,2,3,4,5,6,8,9,10,12,…），非常"好分"！

```python
import math

def angle_type(deg):
    """判断角的类型"""
    deg = deg % 360
    if deg == 0: return "零角/周角"
    if deg < 90: return "锐角"
    if deg == 90: return "直角"
    if deg < 180: return "钝角"
    if deg == 180: return "平角"
    return "优角"

for d in [30, 90, 120, 180, 270]:
    print(f"{d}° 是{angle_type(d)}")

# 弧度预告（高中）：180° = π 弧度
print(f"90° = {math.pi/2:.4f} 弧度")
```

## 6.2 周长：绕一圈有多长

### 多边形周长

**周长** = 所有边长之和。

- 正方形（边长 \\(a\\)）：\\[ C = 4a \\]
- 长方形（长 \\(l\\)，宽 \\(w\\)）：\\[ C = 2(l + w) \\]
- 三角形（三边 \\(a,b,c\\)）：\\[ C = a + b + c \\]

### 圆的周长：\\(\\pi\\) 登场

\\[ C = 2\\pi r = \\pi d \\]

其中 \\(r\\) 是半径，\\(d\\) 是直径，\\(\\pi \\approx 3.14159\\)。

**\\(\\pi\\) 是什么？** 任何圆的"周长 ÷ 直径"都是同一个数——
这个神奇的常数就是 \\(\\pi\\)。它不是有理数（1761年兰伯特证明），
甚至不是代数数（1882年林德曼证明）——它是**超越数**！

**估算 \\(\\pi\\)**（阿基米德，公元前 3 世纪）：
用圆内接正多边形和外切正多边形夹逼：
\\[ 3.1408 < \\pi < 3.1429 \\]
（阿基米德算到 96 边形！）

```python
import math

def archimedes_pi(n_sides):
    """用内接正n边形逼近π"""
    # 内接正n边形周长 / 直径
    side = 2 * math.sin(math.pi / n_sides)  # 边长（直径=2）
    return n_sides * side / 2

for n in [6, 12, 24, 48, 96, 1000]:
    print(f"{n:>4}边形：π ≈ {archimedes_pi(n):.8f}")
print(f"真实值：π = {math.pi:.8f}")
# 边数越多，越接近！
```

## 6.3 面积：平面有多大

### 基本图形面积

| 图形 | 面积公式 | 说明 |
|---|---|---|
| 正方形 | \\(S = a^2\\) | 边长的平方 |
| 长方形 | \\(S = lw\\) | 长 × 宽 |
| 三角形 | \\(S = \\frac{1}{2}bh\\) | 底 × 高 ÷ 2 |
| 平行四边形 | \\(S = bh\\) | 底 × 高 |
| 梯形 | \\(S = \\frac{(a+b)h}{2}\\) | (上底+下底)×高÷2 |
| 圆 | \\(S = \\pi r^2\\) | 半径的平方 × π |

### 为什么三角形面积是 \\(\\frac{1}{2}bh\\)？

两个完全相同的三角形可以拼成一个平行四边形！
\\[ 2 \\times S_{\\triangle} = S_{\\text{平行四边形}} = bh \\]
\\[ \\therefore S_{\\triangle} = \\frac{1}{2}bh \\]

**割补法**：几何证明的核心思想——"剪开重拼，面积不变"。
从小学的图形拼接到大学的积分，都是这个思想！

### 圆的面积：化圆为方

把圆切成无数个小扇形，拼成近似长方形：
- 长 ≈ 圆周的一半 \\(= \\pi r\\)
- 宽 ≈ 半径 \\(= r\\)
- 面积 \\(= \\pi r \\times r = \\pi r^2\\)

```python
import math

def circle_area(r):
    return math.pi * r**2

#  practical problems
# 1. 半径5cm的圆面积？
print(f"r=5cm: S = {circle_area(5):.2f} cm²")  # 78.54

# 2. 圆形花坛周长31.4m，面积？
r = 31.4 / (2 * math.pi)
print(f"周长31.4m: r={r:.1f}m, S={circle_area(r):.1f} m²")  # 78.5

# 3. 圆环面积（外圆减内圆）
def annulus(R, r):
    return math.pi * (R**2 - r**2)
print(f"外径10内径6的圆环：{annulus(10, 6):.2f}")  # 201.06
```

> 🌟 **拉马努金角：椭圆周长的近似**
>
> 圆的周长有精确公式 \\(2\\pi r\\)，但**椭圆**呢？
> 椭圆周长没有初等闭式——必须用**椭圆积分**（第 29 章）！
>
> 拉马努金给出了惊人精确的**近似公式**。
> 设椭圆半长轴 \\(a\\)，半短轴 \\(b\\)，令 \\(h = \\left(\\frac{a-b}{a+b}\\right)^2\\)：
> \\[ C \\approx \\pi (a+b) \\left(1 + \\frac{3h}{10 + \\sqrt{4 - 3h}}\\right) \\]
>
> 这个公式的相对误差**小于 \\(10^{-7}\\)**！拉马努金在笔记本中写下它时，
> 没有计算机、没有数值分析——纯靠直觉。
>
> ```python
> import math
> def ramanujan_ellipse(a, b):
>     """拉马努金椭圆周长近似"""
>     h = ((a - b) / (a + b)) ** 2
>     return math.pi * (a + b) * (1 + 3*h / (10 + math.sqrt(4 - 3*h)))
>
> # 对比：a=5, b=3
> # 数值积分"真实值"约 25.527
> print(f"拉马努金近似：{ramanujan_ellipse(5, 3):.6f}")
> # 用 scipy 数值积分验证（如果可用）
> try:
>     from scipy import integrate
>     f = lambda t: math.sqrt(25*math.sin(t)**2 + 9*math.cos(t)**2)
>     true, _ = integrate.quad(f, 0, 2*math.pi)
>     print(f"数值积分真实值：{true:.6f}")
>     print(f"误差：{abs(ramanujan_ellipse(5,3)-true)/true:.2e}")
> except ImportError:
>     print("（安装 scipy 可验证精度）")
> ```

## 6.4 体积：立体有多大

### 基本立体体积

| 立体 | 体积公式 |
|---|---|
| 正方体 | \\(V = a^3\\) |
| 长方体 | \\(V = lwh\\) |
| 圆柱 | \\(V = \\pi r^2 h\\) |
| 圆锥 | \\(V = \\frac{1}{3}\\pi r^2 h\\) |
| 球 | \\(V = \\frac{4}{3}\\pi r^3\\) |

### 为什么圆锥是圆柱的 \\(\\frac{1}{3}\\)？

**实验**：用同底等高的圆锥和圆柱各装一次水，
把圆锥的水倒入圆柱——恰好倒 3 次装满！

**祖暅原理**（中国，5 世纪，比卡瓦列里早 1000 年）：
> "幂势既同，则积不容异。"
> （等高处截面积相等，则体积相等。）

用这个原理可以证明：等底等高的锥体体积都是柱体的 \\(\\frac{1}{3}\\)。

```python
import math

def volumes(r, h):
    cyl = math.pi * r**2 * h
    cone = cyl / 3
    sphere = 4/3 * math.pi * r**3
    return cyl, cone, sphere

cyl, cone, sph = volumes(3, 5)
print(f"圆柱( r=3,h=5 ): V = {cyl:.2f}")
print(f"圆锥(同底等高): V = {cone:.2f} (= 圆柱/3)")
print(f"球( r=3 ): V = {sph:.2f}")

# 趣题：球的体积 vs 外切圆柱？
# 球 r，外切圆柱底半径 r、高 2r
# V球 = 4/3πr³, V柱 = πr²·2r = 2πr³
# V球/V柱 = 2/3 —— 阿基米德最得意的发现，刻在了他的墓碑上！
print(f"\n球 : 外切圆柱 = {4/3*math.pi:.4f} : {2*math.pi:.4f} = 2 : 3")
```

## ✅ 习题解答

### 题 6.1
\\[ C = 2(12+8) = 40 \\text{ cm}, \\quad S = 12 \\times 8 = 96 \\text{ cm}^2 \\]

### 题 6.2
\\[ C = 2 \\times \\frac{22}{7} \\times 7 = 44 \\text{ cm} \\]
\\[ S = \\frac{22}{7} \\times 7^2 = 154 \\text{ cm}^2 \\]
（取 \\(\\pi = 22/7\\) 时，\\(r=7\\) 的计算特别简洁——古人特意选的！）

### 题 6.3
\\[ V = \\pi \\times 4^2 \\times 10 = 160\\pi \\approx 502.65 \\text{ cm}^3 \\]

### 题 6.4
**证明**：
两个完全相同的梯形（上底 \\(a\\)，下底 \\(b\\)，高 \\(h\\)），
把其中一个旋转 \\(180^\\circ\\)，拼成一个平行四边形：
- 底 \\(= a + b\\)
- 高 \\(= h\\)
- 面积 \\(= (a+b)h\\)

这是两个梯形的面积，所以一个梯形 \\(S = \\frac{(a+b)h}{2}\\)。∎

### 题 6.5
扇形面积 \\(= \\pi \\times 9^2 \\times \\frac{120}{360} = 81\\pi \\times \\frac{1}{3} = 27\\pi \\approx 84.82\\) cm²。
弧长 \\(= 2\\pi \\times 9 \\times \\frac{1}{3} = 6\\pi \\approx 18.85\\) cm。

### 题 6.6
设周长为 \\(C\\)：
- 正方形：边长 \\(a = C/4\\)，面积 \\(S_{\\text{方}} = C^2/16\\)
- 圆：\\(2\\pi r = C\\)，\\(r = C/(2\\pi)\\)，面积 \\(S_{\\text{圆}} = \\pi r^2 = C^2/(4\\pi)\\)

比较：\\[ \\frac{S_{\\text{圆}}}{S_{\\text{方}}} = \\frac{C^2/(4\\pi)}{C^2/16} = \\frac{4}{\\pi} \\approx 1.273 > 1 \\]
**圆的面积大**！

**深层含义**：在所有周长相等的平面图形中，**圆的面积最大**。
这就是"等周不等式"：\\[ 4\\pi S \\le C^2 \\]
等号仅当图形为圆时成立。这是变分法的经典问题（第 34 章）。
