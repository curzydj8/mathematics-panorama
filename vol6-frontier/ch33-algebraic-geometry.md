## 33.1 从方程到图形：仿射簇

### 基本对应

多项式方程 \\(f(x, y) = 0\\) 的解集是平面上的**曲线**：
- \\(y - x^2 = 0\\)：抛物线
- \\(x^2 + y^2 - 1 = 0\\)：单位圆
- \\(y^2 - x^3 - x = 0\\)：椭圆曲线（！）

**仿射簇**：\\(\\mathbb{A}^n\\) 中一批多项式的公共零点集
\\[ V(S) = \\{P \\in \\mathbb{A}^n : f(P) = 0, \\forall f \\in S\\} \\]

### 理想与簇的词典

| 代数（理想） | 几何（簇） |
|---|---|
| 理想 \\(I \\subset k[x_1,\\ldots,x_n]\\) | 簇 \\(V(I)\\) |
| 根理想 \\(\\sqrt{I}\\) | 同一个簇（去掉"重数"） |
| 素理想 | 不可约簇 |
| 极大理想 | 点（\\(\\mathbb{A}^n\\) 的点 ⟷ \\((x_1-a_1,\\ldots,x_n-a_n)\\)） |

### Python：绘制实代数曲线

```python
import numpy as np

def plot_implicit(f, x_range=(-3, 3), y_range=(-3, 3), n=400):
    """绘制 f(x,y)=0 的近似图像 (ASCII 版)"""
    xs = np.linspace(*x_range, n)
    ys = np.linspace(*y_range, n)
    rows = []
    for y in ys[::-1]:  # 从上往下
        row = ""
        for x in xs:
            if abs(f(x, y)) < 0.08:
                row += "*"
            else:
                row += " "
        rows.append(row)
    return "\n".join(rows)

# 椭圆曲线 y^2 = x^3 - x
print(plot_implicit(lambda x, y: y**2 - (x**3 - x)))
```

## 33.2 希尔伯特零点定理：词典的基石

### 弱零点定理

> 设 \\(k\\) 代数闭域，\\(I \\subsetneq k[x_1,\\ldots,x_n]\\) 为真理想，
> 则 \\(V(I) \\neq \\varnothing\\)（必有公共零点）。

**含义**：代数（理想不等于全环）⟹ 几何（有解）。
"方程组无解" ⟺ "1 在理想中"（即理想是全环）。

### 强零点定理

\\[ I(V(I)) = \\sqrt{I} \\]

**解读**：
- \\(V(I)\\): 从理想到簇（求零点）
- \\(I(V(I))\\): 从簇回到理想（找消失的多项式）
- 来回一趟，得到的是**根理想**——"去掉幂次"后的理想

**例子**：\\(I = (x^2) \\subset k[x]\\)。
\\(V(I) = \\{0\\}\\)，\\(I(V(I)) = (x) = \\sqrt{(x^2)}\\)。
\\(x^2\\) 和 \\(x\\) 定义同一个点，但理想不同——
根理想 \\(\\sqrt{I}\\) 才是几何的"真实"对应物。

### 推论：极大理想 ⟷ 点

\\(k\\) 代数闭时：
\\[ \\mathbb{A}^n \\text{ 的点 } \\longleftrightarrow k[x_1,\\ldots,x_n] \\text{ 的极大理想} \\]
\\[ (a_1, \\ldots, a_n) \\longleftrightarrow (x_1 - a_1, \\ldots, x_n - a_n) \\]

**这就是"词典"**：几何问题 ⟷ 代数问题，可以双向翻译！

## 33.3 椭圆曲线：数论与几何的交汇点

### 定义

**椭圆曲线**：由 Weierstrass 方程定义的非奇异射影曲线
\\[ y^2 = x^3 + ax + b, \\quad 4a^3 + 27b^2 \\neq 0 \\]
（判别式非零 ⟹ 光滑无奇点）

**注意**：不是椭圆！叫"椭圆曲线"是因为研究椭圆弧长时出现。

### 群结构（奇迹！）

椭圆曲线上的点构成**阿贝尔群**：
- 单位元：无穷远点 \\(\\mathcal{O}\\)
- 加法：\\(P + Q + R = \\mathcal{O}\\) 若 \\(P, Q, R\\) 共线（弦切法则）

**例子**：\\(E: y^2 = x^3 - x\\)，\\(P = (0, 0)\\)，\\(Q = (1, 0)\\)。
过 \\(P, Q\\) 的直线是 \\(y = 0\\)，交 \\(E\\) 于 \\(P, Q, (-1, 0)\\)，
故 \\(P + Q + (-1,0) = \\mathcal{O}\\)，即 \\(P + Q = (1, 0) + (0,0) + \\cdots\\)

（具体计算略，Python 可验证）

### BSD 猜想（千禧难题之一！）

> **Birch & Swinnerton-Dyer 猜想**：
> 椭圆曲线 \\(E/\\mathbb{Q}\\) 的**秩**（有理点群的自由部分）
> = \\(L(E, s)\\) 在 \\(s = 1\\) 处零点的**阶**。

**含义**：\\(L\\) 函数的分析性质（零点阶数）⟺ 算术性质（有理点多少）。
这是"解析数论 ⟺ 代数几何"的终极对话之一。

**例子**：\\(E: y^2 = x^3 - x\\)，秩为 0（只有有限个有理点），
\\(L(E, 1) \\neq 0\\)（零点阶数为 0）。✓ 符合猜想。

### Python：椭圆曲线点加法

```python
def ec_add(P, Q, a, b):
    """椭圆曲线 y^2 = x^3 + ax + b 上的点加法 (仿射点)"""
    if P is None: return Q
    if Q is None: return P
    x1, y1 = P; x2, y2 = Q
    if x1 == x2:
        if y1 == -y2: return None  # 无穷远点
        # 切线斜率: (3x^2 + a) / 2y
        lam = (3*x1*x1 + a) / (2*y1) if y1 != 0 else 0
    else:
        lam = (y2 - y1) / (x2 - x1)
    x3 = lam*lam - x1 - x2
    y3 = lam*(x1 - x3) - y1
    return (x3, y3)

# E: y^2 = x^3 - x, P=(0,0), Q=(1,0)
# P+Q: 过(0,0),(1,0)的直线 y=0, 第三交点 (-1,0), 故 P+Q = -(-1,0) = (-1, 0)
# (因为 (-1,0) 是二阶点, 其逆元是自己)
P, Q = (0, 0), (1, 0)
R = ec_add(P, Q, -1, 0)
print(f"P + Q = {R}")
```

## ✅ 习题解答

### 题 33.1 解答
联立：\\(x = y\\) 代入圆方程：\\(2x^2 = 1\\)，\\(x = \\pm\\frac{1}{\\sqrt{2}}\\)。
\\[ V = \\left\\{\\left(\\frac{1}{\\sqrt{2}}, \\frac{1}{\\sqrt{2}}\\right), \\left(-\\frac{1}{\\sqrt{2}}, -\\frac{1}{\\sqrt{2}}\\right)\\right\\} \\]
对应根理想：\\(\\sqrt{(x^2+y^2-1, x-y)} = (x^2 - \\frac{1}{2}, x - y)\\)
（两个极大理想的交）。∎

### 题 33.2 解答
\\(x \\notin (x^2, xy)\\)（\\(x\\) 不能写成 \\(x^2, xy\\) 的组合），
但 \\(x^2 \\in (x^2, xy)\\)，故 \\(x \\in \\sqrt{(x^2, xy)}\\)，
理想不是根理想。
\\[ \\sqrt{(x^2, xy)} = (x) \\]
因为 \\((x)\\) 素理想且 \\((x^2, xy) \\subset (x)\\)，而 \\(\\sqrt{(x^2,xy)} \\subset (x)\\)，
反向：\\(x \\in \\sqrt{}\\) 故 \\((x) \\subset \\sqrt{}\\)。
**几何**：\\(V(x^2, xy) = V(x)\\) = \\(y\\) 轴。
理想 \\((x^2, xy)\\) 给 \\(y\\) 轴带上了"\\(x\\) 方向的重数/幂零元"——
这是**概形**（scheme）比簇更精细的地方！∎

### 题 33.3 解答
验证：\\(5^2 = 25\\)，\\(3^3 - 2 = 25\\) ✓。
\\(2P\\)：切线斜率 \\(\\lambda = \\frac{3 \\cdot 9 + 0}{2 \\cdot 5} = \\frac{27}{10} = 2.7\\)
\\[ x_{2P} = \\lambda^2 - 2 \\cdot 3 = 7.29 - 6 = 1.29 = \\frac{129}{100} \\]
\\[ y_{2P} = \\lambda(3 - x_{2P}) - 5 = 2.7 \\times 1.71 - 5 = -0.383 \\]

```python

R = ec_add(P, P, 0, -2)
print(f"2P = ({R[0]:.4f}, {R[1]:.4f})")
# 2P = (1.2900, -0.3830)
# 精确值: (129/100, -383/1000)
```

### 题 33.4 解答
\\(y^2 = x^3\\) 即 \\(y^2 - x^3 = 0\\)。求偏导：
\\(\\frac{\\partial f}{\\partial x} = -3x^2\\)，\\(\\frac{\\partial f}{\\partial y} = 2y\\)。
在原点 \\((0,0)\\)：两偏导都为 0 ⟹ **奇点**（尖点 cusp）。
Weierstrass 形 \\(y^2 = x^3 + ax + b\\) 要求判别式
\\(\\Delta = -16(4a^3 + 27b^2) \\neq 0\\)。
此处 \\(a = b = 0\\)，\\(\\Delta = 0\\)，故不是椭圆曲线。∎

> 💡 尖点 \\(y^2 = x^3\\) 在原点处"折回来"，没有良好定义的切线。
> 椭圆曲线的群 law 在奇点处会失效——光滑性至关重要。

### 题 33.5 思路提示
**贝祖定理**：射影平面上 \\(m\\) 次与 \\(n\\) 次曲线（无公共分支）交于 \\(mn\\) 个点（计重数）。

代数翻译：设 \\(C_1 = V(F)\\)，\\(C_2 = V(G)\\)，\\(\\deg F = \\deg G = 3\\)。
交点对应齐次坐标环 \\(k[x,y,z]/(F, G)\\) 的"某种"维数。
\\(\\dim_k\\)（某个分次片）\\(= 9\\) —— 这是**希尔伯特多项式**的计算！

更深：9 个交点中 8 个决定第 9 个（凯莱-巴赫拉赫定理），
这正是椭圆曲线群 law 结合律的几何证明。代数 ⟺ 几何 ⟺ 数论，
三者在椭圆曲线上完美统一。
