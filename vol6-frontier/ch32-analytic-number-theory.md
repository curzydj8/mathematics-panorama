## 32.1 黎曼 ζ 函数：连接求和与乘积的桥梁

### 定义

\\[ \\zeta(s) = \\sum_{n=1}^{\\infty} \\frac{1}{n^s}, \\quad \\Re(s) > 1 \\]

### 欧拉乘积公式（1737）

\\[ \\zeta(s) = \\prod_{p \\text{ 素数}} \\frac{1}{1 - p^{-s}} \\]

**证明思路**：\\(\\frac{1}{1-p^{-s}} = 1 + p^{-s} + p^{-2s} + \\cdots\\)，
所有素数的这类几何级数相乘，按算术基本定理，
恰给出 \\(\\sum n^{-s}\\) 的每一项。∎

**意义**：左边的"和"（分析）= 右边的"积"（算术）。
这是解析数论的**创世纪**——分析与数论在此交汇。

### 特殊值

\\[ \\zeta(2) = \\frac{\\pi^2}{6} \\quad \\text{（巴塞尔问题，欧拉 1734）} \\]
\\[ \\zeta(4) = \\frac{\\pi^4}{90}, \\quad \\zeta(-1) = -\\frac{1}{12} \\]

最后一个就是第 2 章提到的 \\(1 + 2 + 3 + \\cdots = -\\frac{1}{12}\\)！

### Python：数值验证巴塞尔问题

```python
def zeta2(N):
    return sum(1/n**2 for n in range(1, N+1))

import math
for N in [100, 1000, 10000]:
    print(f"N={N}: {zeta2(N):.8f} (π²/6 = {math.pi**2/6:.8f})")
# N=10000: 1.64483407 (π²/6 = 1.64493407)
# 收敛很慢! 需要加速技巧 (欧拉变换)
```

> 🌟 **拉马努金角**
> 拉马努金给出了 \\(\\zeta\\) 函数在**奇数点**的惊人公式。
> \\(\\zeta(3), \\zeta(5), \\ldots\\) 是否为 \\(\\pi\\) 的有理倍数？
> ——**至今未知**！（阿佩里 1978 年证 \\(\\zeta(3)\\) 无理，但 \\(\\zeta(5)\\) 仍是谜）
>
> 拉马努金在笔记本中写道：
> \\[ \\zeta(3) = \\frac{7\\pi^3}{180} - 2\\sum_{n=1}^{\\infty} \\frac{1}{n^3(e^{2\\pi n} - 1)} \\]
> 这个公式把 \\(\\zeta(3)\\) 和指数衰减级数联系起来，
> 是研究奇数 zeta 值的起点。他比阿佩里早了 60 年！

## 32.2 素数定理：素数的"密度"

### π(x)：素数计数函数

\\(\\pi(x)\\) = 不超过 \\(x\\) 的素数个数。

\\(\\pi(10) = 4\\)（2, 3, 5, 7），\\(\\pi(100) = 25\\)。

### 素数定理（1896，阿达马 & 瓦莱-普桑）

\\[ \\pi(x) \\sim \\frac{x}{\\ln x} \\quad (x \\to \\infty) \\]

**含义**：\\(x\\) 附近随机取一个整数，是素数的概率约 \\(\\frac{1}{\\ln x}\\)。

**例子**：\\(10^{100}\\) 附近，素数密度约 \\(\\frac{1}{230}\\)。
RSA 找大素数：随机试 230 个数，期望找到一个素数！

### 证明思路（极简版）

1. 素数定理 ⟺ \\(\\vartheta(x) = \\sum_{p \\le x} \\ln p \\sim x\\)
2. \\(\\vartheta(x)\\) 与 \\(\\zeta\\) 的零点有关（显式公式）
3. 关键：\\(\\zeta(s)\\) 在 \\(\\Re(s) = 1\\) 上**无零点**
   （阿达马、瓦莱-普桑 1896 年独立证明）
4. 无零点 ⟹ \\(\\vartheta(x) \\sim x\\) ⟹ 素数定理

**黎曼猜想**说：所有非平凡零点都在 \\(\\Re(s) = \\frac{1}{2}\\) 上。
若成立，素数定理的误差项从 \\(O(x e^{-c\\sqrt{\\ln x}})\\) 改进到 \\(O(\\sqrt{x}\\ln x)\\)！

### Python：验证素数定理

```python
def pi_approx(x):
    """素数定理近似"""
    import math
    return x / math.log(x)

def sieve(n):
    is_p = [True]*(n+1)
    is_p[0]=is_p[1]=False
    for i in range(2,int(n**0.5)+1):
        if is_p[i]:
            for j in range(i*i,n+1,i): is_p[j]=False
    return sum(is_p)

for x in [1000, 10000, 100000]:
    actual = sieve(x)
    approx = pi_approx(x)
    print(f"x={x}: π(x)={actual}, x/ln x={approx:.0f}, 比值={actual/approx:.3f}")
# x=100000: π(x)=9592, x/ln x=8686, 比值=1.104
# 比值趋于 1, 但收敛慢 (这就是解析数论的难!)
```

## 32.3 拉马努金 τ 函数：模形式的皇后

### 定义

\\[ \\Delta(z) = q \\prod_{n=1}^{\\infty} (1 - q^n)^{24} = \\sum_{n=1}^{\\infty} \\tau(n) q^n \\]
其中 \\(q = e^{2\\pi i z}\\)，\\(\\Delta\\) 是权 12 的**模形式**。

前几项：\\(\\tau(1) = 1, \\tau(2) = -24, \\tau(3) = 252, \\tau(4) = -1472, \\ldots\\)

### 拉马努金猜想（1916）

1. **乘性**：\\(\\tau(mn) = \\tau(m)\\tau(n)\\)（\\(\\gcd(m,n)=1\\)）
2. **递推**：\\(\\tau(p^{k+1}) = \\tau(p)\\tau(p^k) - p^{11}\\tau(p^{k-1})\\)
3. **界**：\\(|\\tau(p)| \\le 2p^{11/2}\\)

**历史**：
- (1)(2) 由 Mordell 于 1917 年证明（Hecke 算子的功劳）
- (3) 即**拉马努金-彼得森猜想**，由 Deligne 于 1974 年证明
  （用代数几何的 Weil 猜想，获 1978 年菲尔兹奖！）

从猜想到证明：58 年，横跨模形式、代数几何、表示论。

### Python：计算 τ(n)

```python
def tau_list(N):
    """用乘积展开计算 tau(n), n<=N"""
    # q * prod_{n>=1} (1-q^n)^24, 截断到 N 项
    # 用形式幂级数乘法
    max_n = N
    # 先算 prod (1-q^n)^24 的系数
    coeffs = [0]*(max_n+1)
    coeffs[0] = 1
    for n in range(1, max_n+1):
        # 乘以 (1 - q^n)^24 = sum_{k=0}^{24} C(24,k)(-1)^k q^{nk}
        new = [0]*(max_n+1)
        from math import comb
        for k in range(25):
            c = comb(24,k)*((-1)**k)
            for j in range(max_n+1 - n*k):
                if coeffs[j]:
                    new[j + n*k] += coeffs[j]*c
        coeffs = new
    # 乘以 q: tau(n) = coeffs[n-1]
    return [0] + [coeffs[n-1] for n in range(1, max_n+1)]

tau = tau_list(10)
print(f"τ(1..10) = {tau[1:]}")
# τ(1..10) = [1, -24, 252, -1472, 4830, -6048, -16744, 84480, -113643, -115920]
# 与已知值一致 ✓

# 验证 |τ(p)| ≤ 2p^{11/2} (p=2)
import math
print(f"|τ(2)| = 24 ≤ 2·2^5.5 = {2*2**5.5:.1f} ✓")
```

> 🌟 **拉马努金角（本章核心）**
> 1916 年，拉马努金在论文《On certain arithmetical functions》中
> 定义了 \\(\\tau(n)\\) 并提出了上述三个猜想。
>
> 他是**怎么发现**的？看这个恒等式：
> \\[ \\sum_{n=1}^{\\infty} \\tau(n) q^n = q\\prod_{n=1}^{\\infty}(1-q^n)^{24} \\]
> 右边是 \\(\\Delta\\) 函数——椭圆曲线判别式的 24 次方根！
> 拉马努金研究的是**分拆函数** \\(p(n)\\) 的生成函数时，
> 注意到 \\(\\prod (1-q^n)^{-1}\\)，进而发现了 \\(\\prod (1-q^n)^{24}\\) 的美妙性质。
>
> **未解之谜**：Lehmer 猜想（1947）——\\(\\tau(n) \\neq 0\\) 对一切 \\(n\\)？
> 已验证到 \\(n < 10^{23}\\)，但无人能证明。这是拉马努金留给 21 世纪的礼物。

## ✅ 习题解答

### 题 32.1 解答
假设素数只有 \\(p_1, \\ldots, p_k\\)。
欧拉乘积：\\(\\zeta(s) = \\prod_{i=1}^{k} \\frac{1}{1 - p_i^{-s}}\\)。
令 \\(s \\to 1^+\\)，右边是**有限**个有限因子的乘积，故有界。
但左边 \\(\\zeta(s) \\ge \\sum_{n=1}^{N} \\frac{1}{n} \\to \\infty\\)（调和级数发散），
矛盾。故素数无穷。∎

> 💡 这是欧几里得证明的"分析版"，展现了 \\(\\zeta\\) 函数的威力。

### 题 32.2 解答
\\(x = 10^{50}\\)，\\(\\ln x = 50 \\ln 10 \\approx 115.1\\)。
概率约 \\(\\frac{1}{115}\\)，即随机试 115 个数期望找到一个素数。

RSA-2048：模数约 \\(2^{2048}\\)，素数约 \\(2^{1024}\\)。
\\(\\ln(2^{1024}) = 1024 \\ln 2 \\approx 709.8\\)。
需试约 710 次。实际中还要筛掉小因子，效率更高。

```python
import math
print(f"10^50 附近: 需试约 {50*math.log(10):.0f} 次")
print(f"RSA-2048: 需试约 {1024*math.log(2):.0f} 次")
```

### 题 32.4 解答
**思路**（von Koch, 1901）：
显式公式：\\(\\psi(x) = x - \\sum_{\\rho} \\frac{x^{\\rho}}{\\rho} + \\cdots\\)
其中 \\(\\rho\\) 跑遍 \\(\\zeta\\) 非平凡零点。
若 RH 成立，\\(\\Re(\\rho) = \\frac{1}{2}\\)，则
\\(\\left|\\frac{x^{\\rho}}{\\rho}\\right| = \\frac{\\sqrt{x}}{|\\rho|}\\)，
求和得误差 \\(O(\\sqrt{x} \\ln^2 x)\\)（精细估计得 \\(O(\\sqrt{x}\\ln x)\\)）。
**核心思想**：零点越靠近 \\(\\Re(s)=1\\)，误差越大；
RH 把零点推到最左侧 \\(\\Re(s)=\\frac{1}{2}\\)，误差最小。∎

### 题 32.5 思路提示
偶数 zeta 值：\\(\\zeta(2n) = (-1)^{n+1} \\frac{B_{2n} (2\\pi)^{2n}}{2(2n)!}\\)
（伯努利数公式）——是 \\(\\pi^{2n}\\) 的有理倍数，有"封闭形式"。

奇数 zeta 值：**没有**类似公式。\\(\\zeta(3)\\) 被证明无理（阿佩里，1978），
但不知道它和 \\(\\pi^3\\) 是否线性无关。
\\(\\zeta(5), \\zeta(7), \\ldots\\) 几乎一无所知。

**为什么难？** 偶数情形来自 \\(\\zeta\\) 的函数方程 + 伯努利数；
奇数情形没有这样的代数结构。拉马努金的公式
\\(\\zeta(3) = \\frac{7\\pi^3}{180} - 2\\sum \\frac{1}{n^3(e^{2\\pi n}-1)}\\)
暗示奇数 zeta 值与**模形式**有关——这是 21 世纪的前沿
（多重 zeta 值、动机理论）。
