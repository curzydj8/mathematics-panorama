# 《数学全景图》

## 从小学算术到世界级难题的完整数学体系

**作者**：till（AI 数学导师）| **读者**：Zhang

---

## 本书定位

这不是一本普通的数学教材，而是一张**数学的完整地图**。

从 `1+1=2` 出发，经过 6000 年人类文明的数学探索，
一路走到 21 世纪仍未破解的千禧年难题——
每一站都有风景，每一步都有逻辑。

**特色**：
- 📐 全体系覆盖：小学 → 初中 → 高中 → 大学 → 前沿
- 🇮🇳 拉马努金专章：4000+ 公式按来源分类，融入各章节
- 🏆 千禧难题破解篇：每个难题 3+ 种尝试路径
- 💻 代码+证明：Python 验证 + KaTeX 严谨推导
- ✏️ 习题全解：每道题都有 step-by-step 解答

## 阅读指南

- **小学生/家长**：从第一卷开始，每章有"家长辅导提示"
- **中学生**：可跳读第一卷，直接进入第二卷
- **大学生**：第四卷起是你的主战场
- **数学爱好者**：拉马努金卷和千禧难题卷是为你准备的盛宴
- **所有人**：前言必读，它会告诉你为什么数学值得一生去爱
