## 27.1 群：对称的语言

### 从"运算"到"结构"

小学学 \\(a + b = b + a\\)（交换律），中学学 \\((a+b)+c = a+(b+c)\\)（结合律）。
抽象代数问：**满足这些规律的"运算"本身，有什么通用性质？**

### 群的定义

集合 \\(G\\) 配上运算 \\(\\cdot\\) 称为**群**，若满足：

1. **封闭性**：\\(\\forall a, b \\in G, a \\cdot b \\in G\\)
2. **结合律**：\\((a \\cdot b) \\cdot c = a \\cdot (b \\cdot c)\\)
3. **单位元**：\\(\\exists e \\in G, \\forall a, e \\cdot a = a \\cdot e = a\\)
4. **逆元**：\\(\\forall a \\in G, \\exists a^{-1} \\in G, a \\cdot a^{-1} = a^{-1} \\cdot a = e\\)

**例子**：
- \\((\\mathbb{Z}, +)\\)：整数加法群，单位元 0，\\(a^{-1} = -a\\)
- \\((\\mathbb{R}\\setminus\\{0\\}, \\times)\\)：非零实数乘法群
- \\(S_3\\)：3 个元素的置换群（6 个元素，**非交换**！）
- \\((\\mathbb{Z}_n, +)\\)：模 \\(n\\) 加法群（第 31 章详述）

### 为什么群重要？

**群 = 对称的数学化**。正方形的对称（旋转、翻转）构成 8 阶二面体群 \\(D_4\\)；
晶体结构对应 230 种空间群；粒子物理的标准模型建立在规范群上。

### Python：验证 Klein 四元群

```python
# Klein 四元群 V4 = {e, a, b, c}, 每个元素都是二阶的
V4 = ['e', 'a', 'b', 'c']
mult = {
    ('e','e'):'e', ('e','a'):'a', ('e','b'):'b', ('e','c'):'c',
    ('a','e'):'a', ('a','a'):'e', ('a','b'):'c', ('a','c'):'b',
    ('b','e'):'b', ('b','a'):'c', ('b','b'):'e', ('b','c'):'a',
    ('c','e'):'c', ('c','a'):'b', ('c','b'):'a', ('c','c'):'e',
}

def check_group(G, mult):
    # 封闭性
    for a in G:
        for b in G:
            assert mult[(a,b)] in G, "不封闭"
    # 结合律
    for a in G:
        for b in G:
            for c in G:
                assert mult[(mult[(a,b)],c)] == mult[(a,mult[(b,c)])], "结合律失败"
    # 单位元
    e = next(e for e in G if all(mult[(e,a)]==a and mult[(a,e)]==a for a in G))
    # 逆元
    for a in G:
        assert any(mult[(a,b)]==e and mult[(b,a)]==e for b in G), f"{a} 无逆元"
    print(f"✓ 是群，单位元为 {e}")

check_group(V4, mult)
```

## 27.2 子群与拉格朗日定理

### 子群

\\(H \\subseteq G\\) 是子群（\\(H \\le G\\)），若 \\(H\\) 自身在 \\(G\\) 的运算下成群。

**子群判定定理**：非空 \\(H \\subseteq G\\) 是子群 \\(\\iff \\forall a,b \\in H, ab^{-1} \\in H\\)。

### 陪集

\\(aH = \\{ah : h \\in H\\}\\) 称为左陪集。陪集们**划分**了 \\(G\\)：
- 任意两个陪集要么相等，要么不交
- 所有陪集大小都等于 \\(|H|\\)

### 拉格朗日定理（有限群的基石）

> **定理**：若 \\(G\\) 有限，\\(H \\le G\\)，则 \\(|H|\\) 整除 \\(|G|\\)。

**证明**：
\\(G\\) 被 \\(H\\) 的左陪集不交划分，设陪集个数为 \\([G:H]\\)（指数），
每个陪集有 \\(|H|\\) 个元素，故
\\[ |G| = [G:H] \\cdot |H| \\]
即 \\(|H| \\mid |G|\\)。∎

### 推论：素数阶群必循环

若 \\(|G| = p\\)（素数），取 \\(a \\neq e\\)，则 \\(\\langle a \\rangle\\) 的阶整除 \\(p\\)，
故为 \\(p\\)，\\(G = \\langle a \\rangle\\) 循环。

**应用**：\\(\\mathbb{Z}_p\\)（\\(p\\) 素数）的非零元在乘法下成 \\(p-1\\) 阶循环群——
这是费马小定理的群论证明（第 31 章）！

### Python：S₃ 的子群格

```python
from itertools import permutations

# S3: 3个元素的置换群
S3 = list(permutations([0, 1, 2]))

def compose(p, q):
    return tuple(p[q[i]] for i in range(3))

def subgroup_generated(gens):
    H = {(0,1,2)}
    frontier = list(gens)
    while frontier:
        g = frontier.pop()
        for h in list(H):
            for new in [compose(g,h), compose(h,g)]:
                if new not in H:
                    H.add(new); frontier.append(new)
    return H

# 找所有子群
subs = set()
for g in S3:
    H = subgroup_generated([g])
    subs.add(frozenset(H))
print(f"S3 有 {len(subs)} 个子群")
for s in sorted(subs, key=len):
    print(f"  阶 {len(s)}: {len(s)} | 6 = {6 % len(s) == 0} (拉格朗日 ✓)")
# S3 有 6 个子群: 1个1阶, 3个2阶, 1个3阶, 1个6阶
# 阶数 1,2,3,6 都整除 6 ✓
```

## 27.3 环与域：两种运算的舞蹈

### 环的定义

集合 \\(R\\) 配两种运算 \\(+, \\cdot\\)，满足：
1. \\((R, +)\\) 是交换群
2. 乘法结合律
3. **分配律**：\\(a(b+c) = ab + ac\\)

**例子**：\\(\\mathbb{Z}\\)（整数环）、\\(\\mathbb{Z}[x]\\)（整系数多项式环）、\\(M_n(\\mathbb{R})\\)（矩阵环）。

### 域：可以除法的环

交换环中每个非零元都有乘法逆元 \\(\\Rightarrow\\) **域**。

\\[ \\mathbb{Q} \\subset \\mathbb{R} \\subset \\mathbb{C} \\quad \\text{都是域} \\]
\\[ \\mathbb{Z}_p \\ (p\\text{素数}) \\text{ 是 } p \\text{ 元有限域} \\]

**为什么 \\(\\mathbb{Z}\\) 不是域？** 2 在 \\(\\mathbb{Z}\\) 中没有乘法逆元（\\(\\frac{1}{2} \\notin \\mathbb{Z}\\)）。

### 理想与商环（思想）

**理想** \\(I \\triangleleft R\\)：加法子群，且 \\(\\forall r \\in R, i \\in I \\Rightarrow ri \\in I\\)。

商环 \\(R/I\\) 把 \\(I\\) "捏成零"。最经典的例子：
\\[ \\mathbb{Z} / n\\mathbb{Z} \\cong \\mathbb{Z}_n \\]
"模 \\(n\\) 同余"就是商环的语言！（第 31 章）

## ✅ 习题解答

### 题 27.1 解答
**单位元唯一**：设 \\(e, e'\\) 都是单位元，则
\\[ e = e \\cdot e' = e' \\]
（第一步用 \\(e'\\) 是单位元，第二步用 \\(e\\) 是单位元）。∎

**逆元唯一**：设 \\(b, c\\) 都是 \\(a\\) 的逆元，则
\\[ b = b \\cdot e = b \\cdot (a \\cdot c) = (b \\cdot a) \\cdot c = e \\cdot c = c \\] ∎

### 题 27.2 解答
由拉格朗日定理，子群阶只能是 1, 2, 3, 6。
若 \\(G\\) 无 3 阶子群，则所有非单位元的阶都是 2（不能是 6，否则循环群有 3 阶子群）。
取 \\(a \\neq b\\) 都是 2 阶，则 \\(ab\\) 也是 2 阶（若 \\(ab = e\\) 则 \\(a = b\\)，矛盾），
且 \\(ab \\neq a, b\\)。继续取 \\(c\\) 不同于 \\(e, a, b, ab\\)……
可证 \\(G\\) 同构于 \\(V_4 \\times \\mathbb{Z}_2\\) 或 \\(S_3\\)。
直接分类：6 阶群只有 \\(\\mathbb{Z}_6\\) 和 \\(S_3\\)（标准结论），
\\(\\mathbb{Z}_6\\) 有 3 阶子群 \\(\\{0, 2, 4\\}\\)，\\(S_3\\) 有 3 阶子群 \\(A_3\\)。
故必有 3 阶子群。∎

### 题 27.3 解答
```python
def find_generators(p):
    mods = list(range(1, p))
    gens = []
    for g in mods:
        seen = set()
        x = 1
        for _ in range(p - 1):
            x = (x * g) % p
            seen.add(x)
        if len(seen) == p - 1:
            gens.append(g)
    return gens

print(find_generators(7))  # [3, 5]
# 3 是生成元: 3^1=3, 3^2=2, 3^3=6, 3^4=4, 3^5=5, 3^6=1 (mod 7)
```

### 题 27.4 解答
**是环**：加法、乘法封闭（\\((a+b\\sqrt{-5})(c+d\\sqrt{-5}) = (ac-5bd) + (ad+bc)\\sqrt{-5}\\)），
分配律继承自 \\(\\mathbb{C}\\)。∎

**震撼之处**：在 \\(\\mathbb{Z}\\) 中，\\(6 = 2 \\times 3\\) 是唯一的素因子分解。
但在 \\(\\mathbb{Z}[\\sqrt{-5}]\\) 中：
\\[ 6 = 2 \\times 3 = (1+\\sqrt{-5})(1-\\sqrt{-5}) \\]
可以验证 2, 3, \\(1\\pm\\sqrt{-5}\\) 都是"不可约元"（不能再分），
于是 6 有**两种**本质不同的不可约分解！

这摧毁了"唯一因子分解"的朴素信念，促使库默尔发明**理想数**、
戴德金发明**理想**——代数数论就此诞生。拉马努金研究的
\\(\\tau\\) 函数与这类深刻的算术问题紧密相连。

### 题 27.5 思路提示
伽罗瓦（19 岁！）证明：多项式方程能用根式解 ⟺ 它的伽罗瓦群是**可解群**。
- \\(S_3\\) 可解 ⟹ 一元三次方程有求根公式（卡尔达诺公式）
- \\(S_4\\) 可解 ⟹ 一元四次方程有求根公式（费拉里）
- \\(S_5\\) **不可解** ⟹ 一元五次方程**没有**通用求根公式（阿贝尔-鲁菲尼定理）

这不是"还没找到"，而是"被证明不存在"。群论告诉我们**什么是不可能的**——
这是抽象数学最深刻的力量之一。
