## 26.1 确界原理：实数的"完备性"

### 为什么需要实数？

有理数 \\(\\mathbb{Q}\\) 看似稠密——任意两个有理数之间还有无穷多个有理数。
但它有**洞**：\\(\\sqrt{2}\\) 不是有理数（经典反证法，见第 31 章）。

在数轴上，\\(\\sqrt{2}\\) 本该在的位置是个"空洞"。实数 \\(\\mathbb{R}\\)
就是把所有空洞填满后的数系。

### 上确界与下确界

设 \\(A \\subset \\mathbb{R}\\) 非空。

- **上界**：若存在 \\(M\\) 使 \\(\\forall a \\in A, a \\le M\\)，称 \\(M\\) 为 \\(A\\) 的上界
- **上确界** \\(\\sup A\\)：最小的上界
- **下确界** \\(\\inf A\\)：最大的下界

**确界原理（实数完备性公理）**：
> 非空有上界的实数集必有上确界；非空有下界的实数集必有下确界。

**例子**：\\(A = \\{x \\in \\mathbb{Q} : x^2 < 2\\}\\)
- 在 \\(\\mathbb{Q}\\) 中，\\(A\\) 有上界（如 2）但**无上确界**（\\(\\sqrt{2} \\notin \\mathbb{Q}\\)）
- 在 \\(\\mathbb{R}\\) 中，\\(\\sup A = \\sqrt{2}\\)

这正是实数比有理数"更完备"的精确含义。

### Python：二分法逼近上确界

```python
def sup_sqrt2(eps=1e-12):
    """二分法求 {x : x^2 < 2} 的上确界"""
    lo, hi = 1.0, 2.0
    while hi - lo > eps:
        mid = (lo + hi) / 2
        if mid * mid < 2:
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2

print(f"sup = {sup_sqrt2():.12f}")
print(f"真实√2 = {2**0.5:.12f}")
# sup = 1.414213562373
# 真实√2 = 1.414213562373
```

> 其渐近分数 \\(1, \\frac{3}{2}, \\frac{7}{5}, \\frac{17}{12}, \\ldots\\)

## 26.2 连续与一致连续：两种"不断裂"

### 逐点连续

\\(f\\) 在 \\(x_0\\) 连续：\\[ \\forall \\varepsilon > 0, \\exists \\delta > 0, |x - x_0| < \\delta \\Rightarrow |f(x) - f(x_0)| < \\varepsilon \\]

注意：\\(\\delta\\) 可以**依赖**于 \\(x_0\\) 和 \\(\\varepsilon\\)。

### 一致连续（更强！）

\\(f\\) 在区间 \\(I\\) 上一致连续：\\[ \\forall \\varepsilon > 0, \\exists \\delta > 0, \\forall x_1, x_2 \\in I, |x_1 - x_2| < \\delta \\Rightarrow |f(x_1) - f(x_2)| < \\varepsilon \\]

关键区别：\\(\\delta\\) **只依赖** \\(\\varepsilon\\)，**不依赖** \\(x\\) 的位置。
同一个 \\(\\delta\\) 对全区间管用。

### 经典反例：\\(f(x) = x^2\\) 在 \\(\\mathbb{R}\\) 上

\\(f(x) = x^2\\) 在每一点都连续，但在 \\(\\mathbb{R}\\) 上**不一致连续**。

**证明**：取 \\(\\varepsilon_0 = 1\\)。对任意 \\(\\delta > 0\\)，
取 \\(x_1 = \\frac{1}{\\delta}\\)，\\(x_2 = x_1 + \\frac{\\delta}{2}\\)，
则 \\(|x_1 - x_2| = \\frac{\\delta}{2} < \\delta\\)，但
\\[ |f(x_1) - f(x_2)| = |x_1^2 - x_2^2| = |x_1 - x_2||x_1 + x_2| = \\frac{\\delta}{2}\\left(\\frac{2}{\\delta} + \\frac{\\delta}{2}\\right) > 1 = \\varepsilon_0 \\]
故不一致连续。∎

**直观**：\\(x^2\\) 在远处"长得太陡"，固定步长 \\(\\delta\\) 下的函数值差可以任意大。

### 康托尔定理

> 闭区间 \\([a, b]\\) 上的连续函数必一致连续。

**意义**：紧致性（第 28 章）+ 连续 = 一致连续。这是实分析中最常用的定理之一。

### Python：可视化"不一致连续"

```python
import math

def check_uniform(f, delta, trials=2000):
    """检验: 步长<delta 时, 函数值差的最大值"""
    max_diff = 0.0
    worst = None
    x = 0.1
    for _ in range(trials):
        x1, x2 = x, x + delta * 0.9
        d = abs(f(x1) - f(x2))
        if d > max_diff:
            max_diff, worst = d, (x1, x2)
        x += 0.5
    return max_diff, worst

f = lambda x: x ** 2
for delta in [0.1, 0.01]:
    md, w = check_uniform(f, delta)
    print(f"delta={delta}: 最大函数值差 {md:.2f} (在 x≈{w[0]:.1f} 处)")
# delta=0.1: x 越大, 同样步长下函数值差越大 -> 不一致连续
```

## 26.3 函数列的一致收敛

### 逐点收敛 vs 一致收敛

函数列 \\(\\{f_n\\}\\)：
- **逐点收敛**到 \\(f\\)：\\(\\forall x, f_n(x) \\to f(x)\\)
- **一致收敛**到 \\(f\\)：\\[ \\forall \\varepsilon > 0, \\exists N, \\forall n > N, \\forall x, |f_n(x) - f(x)| < \\varepsilon \\]

"一致"二字：\\(N\\) 不依赖 \\(x\\)，收敛速度全区间统一。

### 灾难例子：连续函数列逐点收敛到不连续函数

\\[ f_n(x) = x^n, \\quad x \\in [0, 1] \\]

- 逐点极限：\\(f(x) = 0\\)（\\(x < 1\\)），\\(f(1) = 1\\) —— **不连续！**
- 每个 \\(f_n\\) 都连续，但极限不连续

**教训**：逐点收敛太弱，保持不了连续性。一致收敛才能：

> **定理**：若 \\(f_n\\) 连续且 \\(f_n \\rightrightarrows f\\)（一致收敛），则 \\(f\\) 连续。
> 且 \\(\\int \\lim f_n = \\lim \\int f_n\\)（积分与极限可交换）。

### 魏尔斯特拉斯 M 判别法（实用判据）

若 \\(|f_n(x)| \\le M_n\\) 且 \\(\\sum M_n\\) 收敛，则 \\(\\sum f_n\\) 一致收敛。

**应用**：证明 \\(\\sum_{n=1}^{\\infty} \\frac{\\sin(nx)}{n^2}\\) 一致收敛——
取 \\(M_n = \\frac{1}{n^2}\\)，\\(\\sum \\frac{1}{n^2} = \\frac{\\pi^2}{6}\\) 收敛。∎

### Python：观察 x^n 的"塌缩"

```python
def fn(n, x):
    return x ** n

# 在 x=0.99 处, 需要多大的 n 才能让 f_n < 0.01?
x = 0.99
for n in [10, 50, 100, 500, 1000]:
    print(f"n={n}: f_n({x}) = {fn(n, x):.6f}")
# n 越大, 在接近 1 处"塌缩"得越晚 -> 收敛速度依赖 x -> 不一致收敛
```

> 🌟 **拉马努金角**
> 拉马努金是"形式幂级数"的大师，经常写下
> \\[ 1 + 2x + 3x^2 + 4x^3 + \\cdots = \\frac{1}{(1-x)^2}, \\quad |x| < 1 \\]
> 这类恒等式。他不太关心"一致收敛"的严格条件——
> 哈代花了很大力气把他的结果"严格化"。
> 本章的 M 判别法，正是给拉马努金式级数"上保险"的工具。

## 📝 本章习题

**题 26.1** 求集合 \\(A = \\{1 - \\frac{1}{n} : n \\in \\mathbb{N}\\}\\) 的上确界，并证明。

**题 26.2** 证明 \\(f(x) = \\sqrt{x}\\) 在 \\([0, 1]\\) 上一致连续（提示：用康托尔定理，或直接估计 \\(|\\sqrt{x_1} - \\sqrt{x_2}| \\le \\sqrt{|x_1 - x_2|}\\)）。

**题 26.3** 判断 \\(f_n(x) = \\frac{x}{1 + nx^2}\\) 在 \\(\\mathbb{R}\\) 上是否一致收敛到 0。

**题 26.5**（思考）构造一个函数列 \\(f_n\\)，在 \\([0,1]\\) 上逐点收敛到 0，
但 \\(\\int_0^1 f_n \\to 1\\)（即积分与极限不可交换）。这说明了什么？

## ✅ 习题解答

### 题 26.1 解答
**答案**：\\(\\sup A = 1\\)。

**证明**：
1. \\(1\\) 是上界：\\(1 - \\frac{1}{n} < 1\\) 对一切 \\(n\\) 成立。
2. \\(1\\) 是最小上界：设 \\(M < 1\\) 是上界。取 \\(n > \\frac{1}{1-M}\\)，
   则 \\(1 - \\frac{1}{n} > 1 - (1 - M) = M\\)，与 \\(M\\) 是上界矛盾。
   故任何 \\(M < 1\\) 都不是上界，\\(\\sup A = 1\\)。∎

### 题 26.2 解答
**方法一**（康托尔定理）：\\(\\sqrt{x}\\) 在闭区间 \\([0,1]\\) 上连续，
由康托尔定理，直接得一致连续。∎

**方法二**（直接估计）：
\\[ |\\sqrt{x_1} - \\sqrt{x_2}|^2 = |x_1 - x_2| \\cdot \\frac{|\\sqrt{x_1} - \\sqrt{x_2}|}{\\sqrt{x_1} + \\sqrt{x_2}} \\le |x_1 - x_2| \\]
（因为 \\(\\frac{|\\sqrt{x_1}-\\sqrt{x_2}|}{\\sqrt{x_1}+\\sqrt{x_2}} \\le 1\\)）
故 \\(|\\sqrt{x_1} - \\sqrt{x_2}| \\le \\sqrt{|x_1 - x_2|}\\)。
给定 \\(\\varepsilon > 0\\)，取 \\(\\delta = \\varepsilon^2\\)，
则 \\(|x_1-x_2| < \\delta \\Rightarrow |\\sqrt{x_1}-\\sqrt{x_2}| < \\varepsilon\\)。
\\(\\delta\\) 与 \\(x\\) 无关，故一致连续。∎

### 题 26.3 解答
**答案**：一致收敛到 0。

**证明**：\\(\\forall x\\)，\\(f_n(x) = \\frac{x}{1+nx^2} \\to 0\\)（分母 \\(\\to \\infty\\)）。
求最大值：\\(f_n'(x) = \\frac{1 + nx^2 - 2nx^2}{(1+nx^2)^2} = \\frac{1-nx^2}{(1+nx^2)^2}\\)，
驻点 \\(x = \\pm\\frac{1}{\\sqrt{n}}\\)，最大值为
\\[ \\left|f_n\\left(\\frac{1}{\\sqrt{n}}\\right)\\right| = \\frac{1/\\sqrt{n}}{2} = \\frac{1}{2\\sqrt{n}} \\to 0 \\]
故 \\(\\sup_x |f_n(x)| \\to 0\\)，一致收敛。∎

### 题 26.4 解答
\\(|\\frac{\\cos(nx)}{n^3}| \\le \\frac{1}{n^3} = M_n\\)，\\(\\sum M_n = \\zeta(3)\\) 收敛
（\\(p\\)-级数，\\(p=3>1\\)）。
由 M 判别法，级数在 \\(\\mathbb{R}\\) 上一致收敛。
每项连续 + 一致收敛 \\(\\Rightarrow\\) 和函数连续。∎

### 题 26.5 解答
**构造**：\\(f_n\\) 是底为 \\(\\frac{2}{n}\\)、高为 \\(n\\) 的"尖峰"，
中心在 \\(x = \\frac{1}{n}\\)：
\\[ f_n(x) = \\begin{cases} n - n^3\\left|x - \\frac{1}{n}\\right|, & \\left|x - \\frac{1}{n}\\right| < \\frac{1}{n^2} \\\\ 0, & \\text{其他} \\end{cases} \\]
- 逐点：\\(\\forall x\\)，当 \\(n\\) 充分大时 \\(f_n(x) = 0\\)，故 \\(f_n \\to 0\\)。
- 积分：\\(\\int_0^1 f_n = \\frac{1}{2} \\cdot \\frac{2}{n^2} \\cdot n = \\frac{1}{n} \\to 0\\)……

这个例子积分也趋于 0。**更好的例子**（"滑动鼓包"）：
\\(f_n\\) 是高为 \\(n\\)、宽为 \\(\\frac{1}{n}\\) 的矩形，放在 \\([\\frac{1}{n+1}, \\frac{1}{n}]\\) 上滑动。
逐点收敛到 0（每个 \\(x\\) 最终被"滑过"），但 \\(\\int f_n = 1\\) 恒成立！

**说明**：没有一致收敛（或控制收敛定理的条件），
积分与极限**不能**随意交换。这是实分析严格性的价值所在。
