## 29.1 全纯函数：强得离谱的"可导"

### 复可导

\\(f: \\mathbb{C} \\to \\mathbb{C}\\) 在 \\(z_0\\) **复可导**，若极限
\\[ f'(z_0) = \\lim_{h \\to 0} \\frac{f(z_0 + h) - f(z_0)}{h} \\]
存在（\\(h\\) 从**复平面任意方向**趋于 0）。

"任意方向"是关键！实函数 \\(f(x) = |x|\\) 在 0 处左右导数不等故不可导；
复函数要求**所有方向**的导数一致——这是极强的限制。

### 柯西-黎曼方程

设 \\(f(z) = u(x,y) + iv(x,y)\\)（\\(z = x + iy\\)），则 \\(f\\) 全纯 \\(\\iff\\)
\\[ \\frac{\\partial u}{\\partial x} = \\frac{\\partial v}{\\partial y}, \\quad \\frac{\\partial u}{\\partial y} = -\\frac{\\partial v}{\\partial x} \\]

**例子**：\\(f(z) = z^2 = (x^2 - y^2) + i(2xy)\\)
\\(u_x = 2x = v_y\\) ✓，\\(u_y = -2y = -v_x\\) ✓ —— 全纯。

**反例**：\\(f(z) = \\bar{z} = x - iy\\)
\\(u_x = 1 \\neq -1 = v_y\\) —— **处处不可导**！共轭不是全纯函数。

### 全纯 ⟹ 解析（奇迹定理）

> **定理**：若 \\(f\\) 在区域 \\(D\\) 全纯，则 \\(f\\) 在 \\(D\\) 内**解析**
> （每点邻域内可展成幂级数），从而**无穷次可导**。

实分析中：可导一次 ≠ 可导两次（\\(f(x) = x^2\\sin(1/x)\\)）。
复分析中：可导一次 = 可导无穷次 = 解析。**这就是复平面的魔力。**

### Python：验证柯西-黎曼方程

```python
import cmath

def check_cr(f, z, h=1e-7):
    """数值验证柯西-黎曼方程"""
    # u_x, v_x (沿实轴)
    fz, fz_h = f(z), f(z + h)
    ux = (fz_h.real - fz.real) / h
    vx = (fz_h.imag - fz.imag) / h
    # u_y, v_y (沿虚轴)
    fz_ih = f(z + 1j*h)
    uy = (fz_ih.real - fz.real) / h
    vy = (fz_ih.imag - fz.imag) / h
    cr1 = abs(ux - vy) < 1e-4
    cr2 = abs(uy + vx) < 1e-4
    return cr1 and cr2

print("z² 全纯:", check_cr(lambda z: z**2, 1+1j))
print("共轭 全纯:", check_cr(lambda z: z.conjugate(), 1+1j))
print("e^z 全纯:", check_cr(cmath.exp, 1+1j))
# z² 全纯: True
# 共轭 全纯: False
# e^z 全纯: True
```

> 🌟 **拉马努金角**
> 拉马努金的笔记本里充满了形如
> \\[ \\sum_{n=-\\infty}^{\\infty} \\frac{1}{(n+z)^2} = \\frac{\\pi^2}{\\sin^2(\\pi z)} \\]
> 的恒等式。左边是亚纯函数（除极点外全纯），右边也是。
> 两边在复平面上有相同的极点和留数——由**刘维尔定理**
> （有界整函数必常数），两边只能相差一个常数！
> 这是复分析证明拉马努金恒等式的标准套路：
> **"极点 + 留数 + 增长性 = 函数唯一确定"**。

## 29.2 柯西积分定理与公式

### 柯西定理

> **定理**：若 \\(f\\) 在单连通区域 \\(D\\) 全纯，则对 \\(D\\) 内任意闭曲线 \\(\\gamma\\)，
> \\[ \\oint_\\gamma f(z)\\,dz = 0 \\]

**直观**：全纯函数的积分"与路径无关"——复平面上没有"漩涡"。

### 柯西积分公式（分析学的皇冠）

\\[ f(a) = \\frac{1}{2\\pi i} \\oint_{|z-a|=r} \\frac{f(z)}{z - a}\\,dz \\]

**震撼之处**：\\(f\\) 在**圆周**上的值，决定了 \\(f\\) 在**圆心**的值！
全纯函数是"刚性"的——局部决定整体。

**推论**：\\(f^{(n)}(a) = \\frac{n!}{2\\pi i} \\oint \\frac{f(z)}{(z-a)^{n+1}} dz\\)
——直接推出"可导一次 ⟹ 无穷次可导"。

### Python：数值验证柯西公式

```python
import cmath, math

def cauchy_verify(f, a, r, N=10000):
    """数值验证柯西积分公式"""
    total = 0j
    for k in range(N):
        theta = 2 * math.pi * k / N
        z = a + r * cmath.exp(1j * theta)
        dz = 1j * r * cmath.exp(1j * theta) * (2 * math.pi / N)
        total += f(z) / (z - a) * dz
    return total / (2j * math.pi)

f = lambda z: z**3 + 2*z
a = 0.5 + 0.3j
print(f"公式值: {cauchy_verify(f, a, 1.0):.6f}")
print(f"真实值: {f(a):.6f}")
# 两者吻合到 1e-4
```

## 29.3 留数定理：计算积分的"作弊器"

### 留数

\\(f\\) 在孤立奇点 \\(z_0\\) 的**留数**：
\\[ \\operatorname{Res}(f, z_0) = \\frac{1}{2\\pi i} \\oint_{|z-z_0|=\\varepsilon} f(z)\\,dz \\]
即洛朗展开中 \\((z - z_0)^{-1}\\) 项的系数。

### 留数定理

\\[ \\oint_\\gamma f(z)\\,dz = 2\\pi i \\sum_{\\text{内部奇点}} \\operatorname{Res}(f, z_k) \\]

**应用**：计算 \\(\\int_{-\\infty}^{\\infty} \\frac{dx}{1+x^2}\\)。

考虑 \\(f(z) = \\frac{1}{1+z^2}\\)，在上半平面有单极点 \\(z = i\\)，
\\[ \\operatorname{Res}(f, i) = \\lim_{z \\to i} \\frac{z - i}{(z-i)(z+i)} = \\frac{1}{2i} \\]
取大半圆围道，\\(R \\to \\infty\\) 时圆弧积分 \\(\\to 0\\)，故
\\[ \\int_{-\\infty}^{\\infty} \\frac{dx}{1+x^2} = 2\\pi i \\cdot \\frac{1}{2i} = \\pi \\]

**实积分用复方法秒杀**——这就是留数定理的威力。

### Python：留数计算实积分

```python
import mpmath

# 用留数定理算 ∫₀^∞ dx/(1+x⁴)
# 极点: e^{iπ/4}, e^{i3π/4} (上半平面)
# Res 之和 = ...
# 结果: π/(2√2)
val = mpmath.quad(lambda x: 1/(1+x**4), [0, mpmath.inf])
print(f"数值积分: {val:.10f}")
print(f"留数定理: {mpmath.pi/(2*mpmath.sqrt(2)):.10f}")
# 数值积分: 1.1107207345
# 留数定理: 1.1107207345
```

> 🌟 **拉马努金角（核心）**
> 拉马努金的 **1/π 公式**：
> \\[ \\frac{1}{\\pi} = \\frac{2\\sqrt{2}}{9801} \\sum_{n=0}^{\\infty} \\frac{(4n)!(1103 + 26390n)}{(n!)^4 \\cdot 396^{4n}} \\]
> 每算一项，π 的精度增加约 **8 位**！
>
> **现代证明思路**（Borwein 兄弟，1987）：
> 1. 考虑模函数 \\(j(\\tau)\\) 在 \\(\\tau = i\\) 附近的行为
> 2. 用**留数定理**计算某类围道积分，得到超几何级数
> 3. 代入特定的模方程（如 58 阶），奇迹般地得到 9801 = \\(99^2\\)
> 4. 1103 和 26390 来自类数公式
>
> 拉马努金没有这些工具——他是"看"出来的。
> 复分析给了我们理解天才的眼睛。

## ✅ 习题解答

### 题 29.1 解答
\\(e^z = e^{x+iy} = e^x(\\cos y + i\\sin y)\\)
\\(u = e^x\\cos y\\)，\\(v = e^x\\sin y\\)
\\[ u_x = e^x\\cos y = v_y, \\quad u_y = -e^x\\sin y = -v_x \\]
满足 C-R，故全纯。\\(f'(z) = u_x + iv_x = e^x\\cos y + ie^x\\sin y = e^z\\)。
**\\((e^z)' = e^z\\)**——与实情形一致！∎

### 题 29.2 解答
令 \\(z = e^{i\\theta}\\)，积分化为 \\(\\oint_{|z|=1} \\frac{1}{2 + (z+z^{-1})/2} \\cdot \\frac{dz}{iz}\\)
\\[ = \\oint_{|z|=1} \\frac{2dz}{i(z^2 + 4z + 1)} \\]
分母零点：\\(z = -2 \\pm \\sqrt{3}\\)。\\(|z|=1\\) 内只有 \\(z_0 = -2 + \\sqrt{3}\\)。
\\[ \\operatorname{Res} = \\lim_{z \\to z_0} \\frac{2}{i} \\cdot \\frac{1}{2z + 4} = \\frac{1}{i} \\cdot \\frac{1}{z_0 + 2} = \\frac{1}{i\\sqrt{3}} \\]
故积分 \\(= 2\\pi i \\cdot \\frac{1}{i\\sqrt{3}} = \\frac{2\\pi}{\\sqrt{3}}\\)。∎

### 题 29.3 解答
设 \\(|f(z)| \\le M\\)。对任意 \\(a\\)，由柯西公式：
\\[ f'(a) = \\frac{1}{2\\pi i} \\oint_{|z-a|=R} \\frac{f(z)}{(z-a)^2} dz \\]
估计：
\\[ |f'(a)| \\le \\frac{1}{2\\pi} \\cdot \\frac{M}{R^2} \\cdot 2\\pi R = \\frac{M}{R} \\]
令 \\(R \\to \\infty\\)，得 \\(f'(a) = 0\\)。\\(a\\) 任意，故 \\(f\\) 常数。∎

> 💡 **应用**：代数基本定理（\\(n\\) 次复多项式有 \\(n\\) 个根）
> 可用刘维尔定理漂亮地证明！（若无根则 \\(1/p(z)\\) 有界整函数，必常数，矛盾）

### 题 29.4 解答
- 在 \\(z=0\\)：\\(\\operatorname{Res} = \\lim_{z\\to 0} z \\cdot \\frac{1}{z(z-1)} = -1\\)
- 在 \\(z=1\\)：\\(\\operatorname{Res} = \\lim_{z\\to 1} (z-1) \\cdot \\frac{1}{z(z-1)} = 1\\)
- \\(\\oint_{|z|=2} = 2\\pi i(-1 + 1) = 0\\)。∎
（两个留数抵消——这不是巧合，是"无穷远点留数"的体现）

### 题 29.5 解答
用高阶柯西公式：\\(f^{(n+1)}(a) = \\frac{(n+1)!}{2\\pi i}\\oint \\frac{f(z)}{(z-a)^{n+2}}dz\\)
估计 \\(|f^{(n+1)}(a)| \\le \\frac{(n+1)! M R^n}{R^{n+1}} \\to 0\\)（\\(R \\to \\infty\\)）。
故 \\(f^{(n+1)} \\equiv 0\\)，\\(f\\) 至多 \\(n\\) 次多项式。∎

> 🌟 **拉马努金注**：拉马努金经常断言"这个级数增长得像 \\(e^{\\pi\\sqrt{n}}\\)"之类，
> 却不加证明。哈代说："他的直觉像一条没有路标的高速公路。"
> 本题的"增长性控制函数"思想，正是把拉马努金的直觉严格化的标准工具。
