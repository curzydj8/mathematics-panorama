## 28.1 开集：重新定义"连续"

### 从 \\(\\varepsilon\\)-\\(\\delta\\) 到开集

第 26 章的连续定义依赖"距离" \\(|x - y|\\)。但"连续"的本质是什么？
是"**靠近的点映射到靠近的点**"——"靠近"不一定需要距离！

### 拓扑的定义

集合 \\(X\\) 上的**拓扑** \\(\\tau\\) 是 \\(X\\) 的子集族，满足：
1. \\(\\varnothing, X \\in \\tau\\)
2. 任意并封闭：\\(\\{U_i\\} \\subset \\tau \\Rightarrow \\bigcup_i U_i \\in \\tau\\)
3. 有限交封闭：\\(U_1, U_2 \\in \\tau \\Rightarrow U_1 \\cap U_2 \\in \\tau\\)

\\(\\tau\\) 中的集合称为**开集**。\\((X, \\tau)\\) 称为**拓扑空间**。

**例子**：
- \\(\\mathbb{R}\\) 的标准拓扑：开集 = 开区间的任意并
- **离散拓扑**：所有子集都是开集（"最细"）
- **平凡拓扑**：只有 \\(\\varnothing, X\\) 是开集（"最粗"）

### 连续映射的拓扑定义

\\[ f: X \\to Y \\text{ 连续 } \\iff \\forall V \\subset Y \\text{ 开}, f^{-1}(V) \\subset X \\text{ 开} \\]

**"开集的原像是开集"**——没有 \\(\\varepsilon\\)，没有 \\(\\delta\\)，
只有集合与映射。这是连续最纯粹的形式。

### Python：验证拓扑公理

```python
def is_topology(X, tau):
    """验证 tau 是否为 X 上的拓扑"""
    tau = [set(t) for t in tau]
    X = set(X)
    # 1. 空集和全集
    if set() not in tau or X not in tau:
        return False, "缺少空集或全集"
    # 2. 任意并封闭
    from itertools import combinations
    for r in range(1, len(tau) + 1):
        for combo in combinations(tau, r):
            u = set().union(*combo)
            if u not in tau:
                return False, f"并 {u} 不在 tau 中"
    # 3. 有限交封闭
    for a in tau:
        for b in tau:
            if (a & b) not in tau:
                return False, f"交 {a & b} 不在 tau 中"
    return True, "是拓扑 ✓"

X = {1, 2, 3}
tau = [set(), {1}, {1,2}, {1,2,3}]
print(is_topology(X, tau))
# (True, '是拓扑 ✓')
```

## 28.2 紧致性：有限覆盖的魔力

### 定义

\\(K \\subset X\\) **紧致**，若 \\(K\\) 的任意开覆盖都有**有限子覆盖**：
\\[ K \\subset \\bigcup_{i \\in I} U_i \\Rightarrow \\exists i_1, \\ldots, i_n, K \\subset \\bigcup_{k=1}^{n} U_{i_k} \\]

**直观**："紧致 = 有限"。无穷被有限驯服。

### 海涅-博雷尔定理（\\(\\mathbb{R}^n\\) 的福音）

> \\(K \\subset \\mathbb{R}^n\\) 紧致 \\(\\iff K\\) 有界闭。

所以 \\([0,1]\\) 紧致，\\((0,1)\\) 不紧致（不闭），\\(\\mathbb{R}\\) 不紧致（无界）。

### 紧致的威力：极值定理

> **定理**：紧致集上的连续函数必取到最大值和最小值。

**证明思路**：\\(f(K)\\) 紧致（连续像是紧致），\\(\\mathbb{R}\\) 中紧致 = 有界闭，
故 \\(\\sup f(K) \\in f(K)\\)。∎

这就是第 26 章康托尔定理的"拓扑灵魂"：
闭区间紧致 ⟹ 连续函数一致连续（ Lebesgue 数引理）。

### Python：有限子覆盖演示

```python
def finite_subcover_demo():
    """[0,1] 被开区间覆盖, 必有有限子覆盖"""
    # 构造开覆盖: U_n = (-0.1, 1/n) ∪ (1-1/n, 1.1), n>=2
    # 加上中间的区间
    import math
    # 实际演示: 用贪心找有限子覆盖
    covered = [False] * 101  # 离散化 [0,1] 为 101 个点
    chosen = []
    # 开区间族
    intervals = [(-0.1, 0.6), (0.4, 1.1), (0.2, 0.5)]
    for idx, (a, b) in enumerate(intervals):
        new_cover = False
        for i in range(101):
            x = i / 100
            if not covered[i] and a < x < b:
                covered[i] = True
                new_cover = True
        if new_cover:
            chosen.append(idx)
    print(f"选中区间 {chosen}, 覆盖全部: {all(covered)}")

finite_subcover_demo()
```

## 28.3 连通性：一块还是两块？

### 定义

\\(X\\) **不连通**，若 \\(X = A \\cup B\\)，\\(A, B\\) 非空、不交、都是开集。
否则称 \\(X\\) **连通**。

**直观**：连通 = "一整块"，不能分成两个不相交的开部分。

### 关键定理

1. **\\(\\mathbb{R}\\) 的连通子集恰为区间**（包括单点、空集）
2. **连续像是连通**：\\(X\\) 连通，\\(f\\) 连续 \\(\\Rightarrow f(X)\\) 连通
3. **介值定理**是推论：\\([a,b]\\) 连通，\\(f([a,b])\\) 是区间，故取遍中间值！

**漂亮吧？** 中学学过的介值定理，原来是"连通性"的化身。

### 同胚：拓扑眼中的"相等"

\\(f: X \\to Y\\) 是**同胚**，若 \\(f\\) 双射且 \\(f, f^{-1}\\) 都连续。

同胚的空间有相同的拓扑性质（紧致、连通都保持）。

**经典**：
- 咖啡杯 ☕ 同胚于甜甜圈 🍩（都有一个"洞"）
- 球面不同胚于环面（洞数不同——"洞数"是拓扑不变量）

> 💡 **欧拉公式** \\(V - E + F = 2\\)（凸多面体）
> 其实是拓扑定理：球面的欧拉示性数 \\(\\chi = 2\\)。
> 环面 \\(\\chi = 0\\)。\\(\\chi\\) 在同胚下不变！

## ✅ 习题解答

### 题 28.1 解答
1. \\(\\varnothing \\in \\tau\\)（定义），\\(\\mathbb{R} \\in \\tau\\)（余集空，有限）。✓
2. 任意并：设 \\(\\{U_i\\} \\subset \\tau\\)，若有 \\(U_i = \\varnothing\\) 跳过。
   \\(\\mathbb{R} \\setminus \\bigcup_i U_i = \\bigcap_i (\\mathbb{R} \\setminus U_i)\\)
   是有限集的交，故有限（空交约定为 \\(\\mathbb{R}\\)？需小心：若全是空集并为空集 ∈ τ）。
   有限集的任意交仍有限，故并 ∈ τ。✓
3. 有限交：\\(\\mathbb{R} \\setminus (U_1 \\cap U_2) = (\\mathbb{R}\\setminus U_1) \\cup (\\mathbb{R}\\setminus U_2)\\)
   有限集的有限并仍有限，故交 ∈ τ。✓ ∎

### 题 28.2 解答
\\(f(x) = \\tan\\left(\\pi\\left(x - \\frac{1}{2}\\right)\\right)\\)：
- 当 \\(x \\to 0^+\\)，\\(\\pi(x-\\frac{1}{2}) \\to -\\frac{\\pi}{2}^+\\)，\\(\\tan \\to -\\infty\\)
- 当 \\(x \\to 1^-\\)，\\(\\tan \\to +\\infty\\)
- \\(f\\) 在 \\((0,1)\\) 上连续、严格递增，故是到 \\(\\mathbb{R}\\) 的双射
- 逆函数 \\(f^{-1}(y) = \\frac{1}{2} + \\frac{1}{\\pi}\\arctan y\\) 连续
故 \\(f\\) 是同胚。∎

> 💡 有限区间 \\((0,1)\\) 与无限直线 \\(\\mathbb{R}\\) "一样大"（拓扑意义下）！
> 拓扑不在乎"大小"，只在乎"形状"。

### 题 28.3 解答
\\([a,b]\\) 连通（区间），\\(f\\) 连续，故 \\(f([a,b])\\) 连通。
\\(\\mathbb{R}\\) 的连通子集是区间，而 \\(f(a), f(b) \\in f([a,b])\\)，
故 \\([f(a), f(b)] \\subset f([a,b])\\)。
\\(c \\in [f(a), f(b)]\\)，故 \\(c \\in f([a,b])\\)，
即 \\(\\exists \\xi, f(\\xi) = c\\)。∎

### 题 28.4 解答
- **\\(S^1\\) 去一点**：同胚于开区间 \\((0,1)\\)，**连通**。
  （圆剪开一个口，变成一条线段，仍是一整块）
- **\\(S^2\\) 去一点**：同胚于 \\(\\mathbb{R}^2\\)（球极投影），**连通**。

**差异**：\\(S^1\\) 去**两**点就不连通了（变成两段弧），
而 \\(S^2\\) 去两点仍连通。这反映了维数的本质差异——
"切一刀能否分开"与维数有关（若尔当曲线定理的影子）。

### 题 28.5 思路提示
**Lebesgue 数引理**：紧致度量空间的开覆盖，有统一的"Lebesgue 数" \\(\\delta > 0\\)，
使每个直径 \\(< \\delta\\) 的子集都被某个覆盖元包含。

**直观**：紧致 = "有限"，有限个局部 \\(\\delta_x\\) 取最小值得统一 \\(\\delta\\)。
没有紧致（如开区间 \\((0,1)\\)），\\(\\delta_x\\) 可能在边界处趋于 0，
取不到正的最小值——一致连续就失效了（如 \\(f(x) = 1/x\\) 在 \\((0,1)\\) 上）。
