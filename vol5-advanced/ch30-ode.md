## 30.1 从问题到方程

### 什么是微分方程？

含未知函数及其导数的方程。**阶** = 最高导数的阶数。

- \\(y' = ky\\)：一阶（人口增长、放射性衰变）
- \\(y'' + y = 0\\)：二阶（简谐振动）
- \\(\\frac{\\partial u}{\\partial t} = \\alpha \\frac{\\partial^2 u}{\\partial x^2}\\)：偏微分（热传导）

### 建模三步曲

1. **找变量**：谁随谁变？（如 \\(y(t)\\) = 时刻 \\(t\\) 的细菌数）
2. **找关系**："增长率正比于当前量" ⟹ \\(\\frac{dy}{dt} = ky\\)
3. **定初值**：\\(y(0) = y_0\\)（没有初值，解不唯一！）

**例子**：细菌每 20 分钟翻倍，初始 1000 个。
\\[ \\frac{dy}{dt} = ky, \\quad y(0) = 1000, \\quad y(20) = 2000 \\]
由 \\(y(20) = 1000e^{20k} = 2000\\) 得 \\(k = \\frac{\\ln 2}{20}\\)，
故 \\(y(t) = 1000 \\cdot 2^{t/20}\\)。

### Python：欧拉法数值解

```python
def euler(f, y0, t0, t1, n):
    """欧拉法解 y' = f(t,y), y(t0) = y0"""
    h = (t1 - t0) / n
    t, y = t0, y0
    ts, ys = [t], [y]
    for _ in range(n):
        y = y + h * f(t, y)  # 切线前进一步
        t = t + h
        ts.append(t); ys.append(y)
    return ts, ys

# y' = y, y(0) = 1, 真解 y = e^t
import math
f = lambda t, y: y
ts, ys = euler(f, 1, 0, 1, 100)
print(f"欧拉法 y(1) ≈ {ys[-1]:.6f}")
print(f"真实值 e   = {math.e:.6f}")
print(f"误差: {abs(ys[-1] - math.e):.6f}")
# 步长越小越准 (一阶精度 O(h))
```

> 🌟 **拉马努金角**
> 拉马努金的 **mock theta 函数**（1920 年临终发现）：
> \\[ f(q) = \\sum_{n=0}^{\\infty} \\frac{q^{n^2}}{(-q;q)_n^2} \\]
> 满足某种"近似"的模变换性质。80 年后，Zwegers（2002）发现：
> 补上一个**非全纯**的修正项后，它满足**调和 Maass 形式**的微分方程！
> 微分方程成了理解拉马努金最后谜题的钥匙。

## 30.2 可分离变量：一阶 ODE 的瑞士军刀

### 方法

若 \\(\\frac{dy}{dx} = g(x)h(y)\\)，则分离：
\\[ \\frac{dy}{h(y)} = g(x)\\,dx \\]
两边积分：
\\[ \\int \\frac{dy}{h(y)} = \\int g(x)\\,dx + C \\]

### 例题：\\(\\frac{dy}{dx} = \\frac{x}{y}\\), \\(y(0) = 2\\)

分离：\\(y\\,dy = x\\,dx\\)
积分：\\(\\frac{y^2}{2} = \\frac{x^2}{2} + C\\)
初值 \\(y(0) = 2\\)：\\(2 = 0 + C \\Rightarrow C = 2\\)
\\[ y^2 = x^2 + 4 \\Rightarrow y = \\sqrt{x^2 + 4} \\]
（取正支，因 \\(y(0) = 2 > 0\\)）

### Python：符号验证

```python
import sympy as sp

x = sp.Symbol('x')
y = sp.Function('y')
ode = sp.Eq(y(x).diff(x), x / y(x))
sol = sp.dsolve(ode, ics={y(0): 2})
print(sol)
# Eq(y(x), sqrt(x**2 + 4))
```

## 30.3 一阶线性 ODE：积分因子法

### 标准形

\\[ y' + P(x)y = Q(x) \\]

### 积分因子

令 \\(\\mu(x) = e^{\\int P(x)\\,dx}\\)，乘两边：
\\[ \\mu y' + \\mu P y = \\mu Q \\]
左边恰为 \\((\\mu y)'\\)（因为 \\(\\mu' = \\mu P\\)）！
故
\\[ \\mu y = \\int \\mu Q\\,dx + C, \\quad y = \\frac{1}{\\mu}\\left(\\int \\mu Q\\,dx + C\\right) \\]

### 例题：\\(y' + 2xy = x\\)

\\(P(x) = 2x\\)，\\(\\mu = e^{\\int 2x\\,dx} = e^{x^2}\\)
\\[ e^{x^2} y = \\int x e^{x^2} dx + C = \\frac{1}{2}e^{x^2} + C \\]
\\[ y = \\frac{1}{2} + Ce^{-x^2} \\]

**检验**：\\(y' = -2xCe^{-x^2}\\)，\\(y' + 2xy = -2xCe^{-x^2} + 2x(\\frac{1}{2} + Ce^{-x^2}) = x\\) ✓

### Python：完整求解流程

```python
import sympy as sp

x = sp.Symbol('x')
y = sp.Function('y')

# y' + 2xy = x
ode = sp.Eq(y(x).diff(x) + 2*x*y(x), x)
sol = sp.dsolve(ode)
print(f"通解: {sol}")

# 初值问题 y(0) = 1
sol_ivp = sp.dsolve(ode, ics={y(0): 1})
print(f"特解: {sol_ivp}")
# 特解: y = 1/2 + exp(-x^2)/2
```

## 30.4 存在唯一性：解一定存在且唯一吗？

### 皮卡-林德勒夫定理

> 若 \\(f(t, y)\\) 在 \\((t_0, y_0)\\) 附近连续且对 \\(y\\) **利普希茨连续**
> （\\(|f(t,y_1) - f(t,y_2)| \\le L|y_1 - y_2|\\)），
> 则初值问题 \\(y' = f(t,y), y(t_0) = y_0\\)
> 在某区间内**存在唯一解**。

### 反例：不唯一！

\\[ y' = \\sqrt{|y|}, \\quad y(0) = 0 \\]

\\(f(y) = \\sqrt{|y|}\\) 在 0 处**不**利普希茨（导数爆破），
解不唯一：
- \\(y \\equiv 0\\)
- \\(y = \\begin{cases} x^2/4, & x \\ge 0 \\\\ 0, & x < 0 \\end{cases}\\)
- 无穷多个"分叉"解！

### 证明思想（压缩映射）

把 ODE 化为积分方程：
\\[ y(t) = y_0 + \\int_{t_0}^{t} f(s, y(s))\\,ds \\]
定义算子 \\((Ty)(t) = y_0 + \\int_{t_0}^t f(s, y(s))\\,ds\\)。
利普希茨条件 ⟹ \\(T\\) 是压缩映射 ⟹ 巴拿赫不动点定理 ⟹ 唯一不动点 = 唯一解。

**这串逻辑链**：压缩映射（泛函分析）→ ODE 存在唯一性，
是"抽象理论解决具体问题"的典范。

### Python：观察不唯一性

```python
def euler_sqrt(y0, n=500):
    """y' = sqrt(|y|), 看不同初值的行为"""
    h = 0.01
    y = y0
    for _ in range(n):
        import math
        y = y + h * math.sqrt(abs(y))
    return y

# 从 y0=0 出发, 欧拉法给出 y=0 (一个解)
# 但理论上有无穷多解!
print(f"y0=0: {euler_sqrt(0):.4f}")
print(f"y0=0.001: {euler_sqrt(0.001):.4f}")
# 数值方法只能找到"一个"解, 唯一性失效时数值解不可靠!
```

## ✅ 习题解答

### 题 30.1 解答
\\(\\frac{dy}{dx} = e^x \\cdot e^{-y}\\)，分离：\\(e^y\\,dy = e^x\\,dx\\)
积分：\\(e^y = e^x + C\\)
初值 \\(y(0) = 0\\)：\\(1 = 1 + C \\Rightarrow C = 0\\)
\\[ e^y = e^x \\Rightarrow y = x \\]
**检验**：\\(y' = 1\\)，\\(e^{x-y} = e^{x-x} = 1\\) ✓

### 题 30.2 解答
化为标准形：\\(y' + \\frac{1}{x}y = x\\)
\\(P(x) = \\frac{1}{x}\\)，\\(\\mu = e^{\\int \\frac{dx}{x}} = e^{\\ln x} = x\\)
\\[ xy = \\int x \\cdot x\\,dx + C = \\frac{x^3}{3} + C \\]
\\[ y = \\frac{x^2}{3} + \\frac{C}{x} \\] ∎

### 题 30.3 解答
\\(y(t) = 100e^{kt}\\)，\\(y(1) = 300\\)：
\\[ 100e^{k} = 300 \\Rightarrow k = \\ln 3 \\approx 1.0986 \\]
\\(y(3) = 100e^{3\\ln 3} = 100 \\cdot 27 = 2700\\)。

```python
import math
k = math.log(3)
print(f"k = {k:.4f}")
print(f"3小时后: {100 * math.exp(3*k):.0f} 个")
# k = 1.0986, 3小时后: 2700 个
```

### 题 30.4 解答
- \\(y \\equiv 0\\)：\\(y' = 0 = \\sqrt{0}\\) ✓
- \\(y = x^2/4\\)（\\(x \\ge 0\\)）：\\(y' = x/2\\)，\\(\\sqrt{|y|} = \\sqrt{x^2/4} = |x|/2 = x/2\\)（\\(x\\ge0\\)）✓

**皮卡条件不满足**：\\(f(y) = \\sqrt{|y|}\\)，\\(\\frac{|f(y_1) - f(y_2)|}{|y_1 - y_2|}\\)
在 \\(y_1, y_2 \\to 0\\) 时无界（\\(f'(y) = \\frac{1}{2\\sqrt{|y|}} \\to \\infty\\)），
故不满足利普希茨条件，唯一性无保障。∎

### 题 30.5 思路提示
二阶 ODE 降为一阶方程组：
\\[ \\begin{cases} y_1' = y_2 \\\\ y_2' = -y_1 \\end{cases}, \\quad y_1 = y, y_2 = y' \\]
这是 2 维系统的初值问题，需要 \\((y_1(0), y_2(0)) = (y(0), y'(0))\\)——
**2 个条件定 2 维状态**。一般地，\\(n\\) 阶 ODE 等价于 \\(n\\) 维一阶系统，
需要 \\(n\\) 个初值条件。这是"相空间"思想的萌芽（动力系统理论）。
