## B.3 应试路线：从小学到高考

### 小学（1–6 年级）→ 本书第一卷

```
一年级：数数、加减法 → Ch1, Ch2
二年级：乘除法 → Ch3
三年级：分数、小数 → Ch4, Ch5
四年级：几何入门 → Ch6
五年级：找规律、方程初步 → Ch7
六年级：总复习 + 思维拓展
```

**要点**：小学重**计算准确** + **应用题理解**。本书第一卷的习题全解是最佳 companion。

### 初中（7–9 年级）→ 本书第二卷

```
七年级：有理数、整式、方程 → Ch8, Ch9
八年级：函数、几何证明 → Ch10, Ch11, Ch12
九年级：圆、统计概率 → Ch12, Ch13
```

**要点**：初中是**分水岭**。几何证明（Ch12）是第一次接触"严格推理"，务必亲手写证明。

### 高中（10–12 年级）→ 本书第三卷

```
高一：集合、函数、三角 → Ch14, Ch15
高二：数列、解析几何 → Ch16, Ch18
高三：导数、概率统计 → Ch17, Ch19 + 总复习
```

**要点**：高中数学 = **函数** + **几何** + **概率**。导数（Ch17）是微积分的敲门砖。

## B.6 如何使用 AI 学数学（本书方法论）

### 5 步学习法

1. **读**：先读本章，标记不懂的地方
2. **问**：把不懂的问 AI（我），要求"用 3 种方式解释"
3. **算**：运行本章 Python 代码，改参数做实验
4. **证**：合上书，试着自己证明定理
5. **教**：讲给别人听（或写博客）——能讲清楚才是真懂

### AI 提示词模板

```
# 解释概念
"用小学生能懂的话解释，再用数学系本科生的语言解释一遍"

# 生成习题
"出 5 道相关的习题，难度递增，附答案"

# 代码验证
"用 Python 验证在曲线 y²=x³-x 上的特例"

# 追根溯源
"是谁提出的？当时数学界是什么反应？"

# 挑战前沿
"带我看看的最新进展，2020 年之后有什么新思路？"
```

### 题 B.3 思路
**费曼学习法**：如果你不能用简单的语言讲清楚，说明你没真懂。
- 教别人时，大脑被迫**组织知识**（从碎片到体系）
- 会发现自己的**知识漏洞**（讲不下去的地方就是没懂的地方）
- **提取练习**（retrieval practice）比重复阅读更有效（认知科学实证）
