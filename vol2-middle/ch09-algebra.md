## 9.1 从算术到代数：字母的魔力

### 一个思想实验

算术题："3 个苹果加 2 个苹果是几个？"——答案是 5 个苹果。

代数题："\\(a\\) 个苹果加 \\(b\\) 个苹果是几个？"——答案是 \\((a+b)\\) 个苹果。

**区别**：算术算的是**具体的数**，代数算的是**一般的规律**。
字母 \\(a, b\\) 可以代表**任何数**——这就是抽象的力量。

### 代数式的定义

用字母表示数，字母和数用运算符号连接的式子叫**代数式**：
- \\(3x + 2\\)
- \\(a^2 + b^2\\)
- \\(\frac{n(n+1)}{2}\\)（高斯公式本身就是代数式！）

**书写规范**：
- \\(3 \\times x\\) 写成 \\(3x\\)（省略乘号，数字在前）
- \\(1 \\times x\\) 写成 \\(x\\)
- \\(-1 \\times x\\) 写成 \\(-x\\)
- \\(a \\div b\\) 写成 \\(\frac{a}{b}\\)

### 单项式与多项式

- **单项式**：数与字母的乘积，如 \\(5x\\), \\(-3ab^2\\), \\(7\\)
  - **系数**：\\(-3ab^2\\) 的系数是 \\(-3\\)
  - **次数**：所有字母指数之和，\\(-3ab^2\\) 是 3 次
- **多项式**：几个单项式的和，如 \\(2x^2 + 3x - 5\\)
  - **项**：\\(2x^2\\), \\(3x\\), \\(-5\\)
  - **次数**：最高项的次数（这里是 2 次）

```python
# 用 sympy 做符号运算（代数式的"计算器"）
try:
    import sympy as sp
    x, a, b = sp.symbols('x a b')
    expr = 3*x**2 + 2*x - 5
    print(f"代数式: {expr}")
    print(f"x=2 时的值: {expr.subs(x, 2)}")  # 3*4+4-5=11
    print(f"展开 (a+b)^2: {sp.expand((a+b)**2)}")  # a^2+2ab+b^2
    print(f"因式分解 x^2-1: {sp.factor(x**2-1)}")  # (x-1)(x+1)
except ImportError:
    print("提示: pip install sympy 可运行符号运算")
```

## 9.2 合并同类项：代数的"整理术"

### 同类项

**所含字母相同、相同字母指数也相同**的项：
- \\(3x\\) 与 \\(-5x\\) 是同类项
- \\(2ab^2\\) 与 \\(7ab^2\\) 是同类项
- \\(3x\\) 与 \\(3x^2\\) **不是**同类项（指数不同）

### 合并法则

\\[ ax + bx = (a+b)x \\]

这是**分配律**的逆用！

例：\\[ 3x + 5x - 2x = (3+5-2)x = 6x \\]

**步骤**：
1. 找同类项（用不同记号标记）
2. 系数相加减，字母部分不变

```python
def combine_like_terms_demo():
    """演示合并同类项"""
    # 3x + 5x - 2x + 4y - y
    # x的系数: 3+5-2=6, y的系数: 4-1=3
    terms_x = [3, 5, -2]
    terms_y = [4, -1]
    print(f"3x+5x-2x = {sum(terms_x)}x = 6x")
    print(f"4y-y = {sum(terms_y)}y = 3y")
    print(f"结果: 6x + 3y")

combine_like_terms_demo()
```

> 🌟 **拉马努金角**
> 拉马努金是**恒等式大师**。他 notebooks 里有数千个代数恒等式，
> 比如这个优美的：
> \\[ (3t^2 + 5t + 1)^2 + (4t^2 + 2t + 1)^2 = (5t^2 + 3t + 1)^2 + (2t^2 + 6t)^2 \\]
> 对**所有** \\(t\\) 成立！这本质上是"合并同类项"的极致运用——
> 把两边展开，\\(t^4, t^3, t^2, t\\) 的系数分别相等。
> 他能"看"出这种恒等式，如同我们看到 \\(3x+5x=8x\\) 一样自然。

## 9.3 一元一次方程： \\(ax + b = 0\\)

### 什么是方程？

含未知数的**等式**。\\(2x + 3 = 11\\) 是方程，\\(2x + 3\\) 只是代数式。

**方程的解**：使等式成立的未知数的值。
\\(x = 4\\) 是 \\(2x + 3 = 11\\) 的解，因为 \\(2 \\times 4 + 3 = 11\\) ✓

### 等式两大性质（解方程的尚方宝剑）

1. **等式两边同时加（减）同一个数，等式仍成立**：
   \\[ a = b \Rightarrow a + c = b + c \\]
2. **等式两边同时乘（除以）同一个非零数，等式仍成立**：
   \\[ a = b \Rightarrow ac = bc \quad (c \neq 0) \\]

### 解方程五步法

解 \\(3x - 7 = 2x + 5\\)：

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1. 移项 | \\(3x - 2x = 5 + 7\\) | 把含 \\(x\\) 的放左边，常数放右边 |
| 2. 合并 | \\(x = 12\\) | |
| 3. 系数化 1 | 已是 1，跳过 | |
| 4. 检验 | \\(3(12)-7=29\\), \\(2(12)+5=29\\) ✓ | 左 = 右 |

**移项的本质**：等式性质 1 的快捷方式。
\\(a + b = c \Rightarrow a = c - b\\)（\\(+b\\) 移过去变 \\(-b\\)）

### 去括号与去分母

解 \\(\frac{2x-1}{3} - \frac{x+2}{4} = 1\\)：

1. **去分母**（两边 × 12）：\\(4(2x-1) - 3(x+2) = 12\\)
2. **去括号**：\\(8x - 4 - 3x - 6 = 12\\)
3. **移项合并**：\\(5x = 22\\)
4. **系数化 1**：\\(x = \frac{22}{5}\\)

```python
from fractions import Fraction

def solve_linear(a, b):
    """解 ax + b = 0，返回精确分数解"""
    if a == 0:
        return "无解" if b != 0 else "无穷多解"
    return Fraction(-b, a)

# 3x - 7 = 2x + 5  =>  x - 12 = 0
print(f"x = {solve_linear(1, -12)}")  # 12
# (2x-1)/3 - (x+2)/4 = 1  => 5x-22=0  =>  x=22/5
print(f"x = {solve_linear(5, -22)}")  # 22/5

# 验证
x = Fraction(22, 5)
lhs = (2*x - 1)/3 - (x + 2)/4
print(f"代入检验: 左边 = {lhs}, 右边 = 1, 成立: {lhs == 1}")
```

## 9.4 二元一次方程组：两个未知数的舞蹈

### 什么是方程组？

\\[ \begin{cases} x + y = 10 \\\\ 2x - y = 5 \end{cases} \\]

两个方程，两个未知数。解是**同时满足两个方程**的 \\((x, y)\\)。

### 代入消元法

从第一个方程得 \\(y = 10 - x\\)，代入第二个：
\\[ 2x - (10 - x) = 5 \\]
\\[ 3x = 15 \\Rightarrow x = 5, \quad y = 5 \\]

### 加减消元法（更优雅）

两式相加，\\(y\\) 直接消掉：
\\[ (x + y) + (2x - y) = 10 + 5 \\]
\\[ 3x = 15 \Rightarrow x = 5 \\]

**核心思想**：**消元**——把二元变一元。这是整个代数学的核心策略之一！

### 解的几何意义（预告第 11 章）

每个二元一次方程代表一条直线，方程组的解就是**两直线的交点**。
- 一解：两直线相交
- 无解：两直线平行
- 无穷解：两直线重合

```python
import numpy as np

def solve_system(a1, b1, c1, a2, b2, c2):
    """
    解方程组：
    a1*x + b1*y = c1
    a2*x + b2*y = c2
    用克拉默法则
    """
    D = a1*b2 - a2*b1  # 系数行列式
    if D == 0:
        return "无唯一解（平行或重合）"
    Dx = c1*b2 - c2*b1
    Dy = a1*c2 - a2*c1
    return (Dx/D, Dy/D)

# x+y=10, 2x-y=5
print(solve_system(1, 1, 10, 2, -1, 5))  # (5.0, 5.0)

# 无解例子：x+y=1, x+y=2（平行）
print(solve_system(1, 1, 1, 1, 1, 2))
```

> 💡 **为什么叫"元"、"次"？**
> - **元**：未知数的个数（一元、二元……）
> - **次**：最高次数（一次、二次……）
> 中国古代叫未知数为"天元"，方程叫"天元术"——
> 13 世纪朱世杰的《四元玉鉴》已能解四元高次方程组！

### 题 9.1 解答

### 题 9.2 解答

### 题 9.4 解答
用加减消元法。第二个方程 ×2：\\(2x - 2y = 2\\)
与第一个相加：\\(5x = 18\\)，得 \\(x = \frac{18}{5}\\)
代入 \\(x - y = 1\\)：\\(y = \frac{18}{5} - 1 = \frac{13}{5}\\)
解为 \\((\frac{18}{5}, \frac{13}{5})\\)。
检验：\\(3 \times \frac{18}{5} + 2 \times \frac{13}{5} = \frac{54+26}{5} = 16\\) ✓

### 题 9.5 解答

\\[ x + 3 = 10 \\]
\\[ x = 7 \\]
答：这个数是 7。

### 题 9.6 解答
```python
def check_identity(t):
    a = 3*t*t + 5*t + 1
    b = 4*t*t + 2*t + 1
    c = 5*t*t + 3*t + 1
    d = 2*t*t + 6*t
    return a*a + b*b - c*c - d*d

for t in [1, 2, 3, 100, -5]:
    print(f"t={t}: {check_identity(t)}")
# 全部输出 0 ✓
```

**为什么恒成立**：把左边展开，按 \\(t\\) 的幂次合并同类项，
\\(t^4, t^3, t^2, t\\) 的系数都是 0。这是一个**多项式恒等式**——
只要展开后对应系数全相等，就对一切 \\(t\\) 成立。
拉马努金能"一眼看穿"这类恒等式，是因为他对多项式结构有超凡直觉。
