## 12.1 证明的艺术：从"看到"到"确信"

### 为什么需要证明？

量角器量出三角形内角和是 180°——但你量的只是**这几个**三角形。
怎么知道**所有**三角形都这样？

**证明**（proof）就是：从公理出发，用逻辑推理，得出**必然**成立的结论。
一旦证明，全宇宙的三角形都服从它——包括你没见过的。

### 欧几里得五公设（《几何原本》，约公元前 300 年）

1. 两点确定一条直线
2. 线段可无限延长
3. 以任意点为圆心、任意长为半径可作圆
4. 所有直角都相等
5. **平行公设**：过直线外一点，有且只有一条直线与已知直线平行

前 4 条"显然"，第 5 条困扰了人类 2000 年——
最终人们发现：否定它也能得到**自洽的几何**（非欧几何，第 34 章）！

### 证明的结构

**已知** → **求证** → **证明**（每一步都要有依据！）

```python
# 用 Python 验证三角形内角和（数值实验 ≠ 证明，但能增强信心）
import random, math

def triangle_angles():
    """随机生成三角形，返回三个内角（弧度转角度）"""
    # 随机三点
    pts = [(random.random(), random.random()) for _ in range(3)]
    def angle(a, b, c):
        # b处夹角
        v1 = (a[0]-b[0], a[1]-b[1])
        v2 = (c[0]-b[0], c[1]-b[1])
        dot = v1[0]*v2[0] + v1[1]*v2[1]
        n1 = math.hypot(*v1); n2 = math.hypot(*v2)
        return math.degrees(math.acos(max(-1, min(1, dot/(n1*n2)))))
    A, B, C = pts
    return angle(C, A, B) + angle(A, B, C) + angle(B, C, A)

for i in range(5):
    s = triangle_angles()
    print(f"随机三角形{i+1}: 内角和 = {s:.10f}°")
print("数值实验：内角和总是 180°，但这不是证明！")
```

## 12.2 平行线：同位角、内错角、同旁内角

### 三线八角

两条直线被第三条直线所截，形成 8 个角：
- **同位角**：位置相同的角（如 ∠1 和 ∠5）
- **内错角**：内部两侧的角（如 ∠3 和 ∠6）
- **同旁内角**：内部同侧的角（如 ∠3 和 ∠5）

### 平行线的判定与性质（互逆！）

| | 判定（证平行） | 性质（知平行） |
|---|---|---|
| 同位角 | 相等 → 平行 | 平行 → 相等 |
| 内错角 | 相等 → 平行 | 平行 → 相等 |
| 同旁内角 | 互补 → 平行 | 平行 → 互补 |

> 💡 **判定**是"因为角，所以线"；**性质**是"因为线，所以角"。
> 互为逆命题，考试最爱混着考。

### 三角形内角和定理的证明

**定理**：三角形三个内角之和为 \\(180°\\)。

**证明**：
过顶点 \\(A\\) 作 \\(BC\\) 的平行线 \\(DE\\)。
\\[ \angle DAB = \angle ABC \quad \text{（内错角，} DE \parallel BC\text{）} \\]
\\[ \angle EAC = \angle ACB \quad \text{（内错角）} \\]
\\[ \angle DAB + \angle BAC + \angle EAC = 180° \quad \text{（平角）} \\]
故 \\(\angle ABC + \angle BAC + \angle ACB = 180°\\)。∎

**一句话**：把三个角"搬"到一条直线上，拼成平角。

## 12.3 三角形全等：SSS、SAS、ASA、AAS、HL

### 什么是全等？

两个三角形**完全重合**，记作 \\(\triangle ABC \cong \triangle DEF\\)。
对应边相等，对应角相等（6 组等量关系）。

**逆向思维**：要证 6 组相等，其实只需 3 组！
这就是全等判定定理——用最少条件推出全部相等。

### 五大判定

1. **SSS**（边边边）：三边对应相等
2. **SAS**（边角边）：两边及夹角对应相等
3. **ASA**（角边角）：两角及夹边对应相等
4. **AAS**（角角边）：两角及一角对边对应相等
5. **HL**（斜边直角边）：直角三角形中，斜边与一直角边对应相等

> ⚠️ **没有 SSA！** 两边及一边的对角**不能**判定全等（有两解可能）。
> 这是经典陷阱。

### 证明示例：等腰三角形底角相等

**已知**：\\(\triangle ABC\\) 中，\\(AB = AC\\)。
**求证**：\\(\angle B = \angle C\\)。

**证明**：
作 \\(\angle A\\) 的平分线交 \\(BC\\) 于 \\(D\\)。
在 \\(\triangle ABD\\) 与 \\(\triangle ACD\\) 中：
- \\(AB = AC\\)（已知）
- \\(\angle BAD = \angle CAD\\)（角平分线）
- \\(AD = AD\\)（公共边）
∴ \\(\triangle ABD \cong \triangle ACD\\)（SAS）
∴ \\(\angle B = \angle C\\)（全等三角形对应角相等）。∎

```python
# 用坐标验证全等判定 SSS
import math

def dist(p, q):
    return math.hypot(p[0]-q[0], p[1]-q[1])

def check_sss(t1, t2):
    """t1, t2是三顶点坐标，验证三边是否对应相等"""
    s1 = sorted([dist(t1[0],t1[1]), dist(t1[1],t1[2]), dist(t1[2],t1[0])])
    s2 = sorted([dist(t2[0],t2[1]), dist(t2[1],t2[2]), dist(t2[2],t2[0])])
    return all(abs(a-b) < 1e-9 for a, b in zip(s1, s2))

# 两个全等三角形（平移+旋转）
t1 = [(0,0), (3,0), (0,4)]
t2 = [(1,1), (4,1), (1,5)]
print(f"SSS判定全等: {check_sss(t1, t2)}")  # True（都是3-4-5三角形）
```

## 12.4 勾股定理： \\(a^2 + b^2 = c^2\\)

### 定理

直角三角形两直角边为 \\(a, b\\)，斜边为 \\(c\\)，则：
\\[ a^2 + b^2 = c^2 \\]

中国叫**勾股定理**（勾三股四弦五），西方叫毕达哥拉斯定理。

### 赵爽弦图证明（中国，公元 3 世纪）

四个全等的直角三角形 + 一个小正方形 = 一个大正方形。

设直角三角形两直角边为 \\(a, b\\)（\\(a < b\\)），斜边 \\(c\\)。

大正方形面积：\\(c^2\\)
= 4 个三角形面积 + 小正方形面积
\\[ = 4 \times \frac{1}{2}ab + (b-a)^2 \\]
\\[ = 2ab + b^2 - 2ab + a^2 \\]
\\[ = a^2 + b^2 \\]

故 \\(c^2 = a^2 + b^2\\)。∎

**一句话**：用面积的两种算法，算出同一个大正方形。

### 勾股数的参数公式

所有本原勾股数（\\(a, b, c\\) 互质）可表示为：
\\[ a = m^2 - n^2, \quad b = 2mn, \quad c = m^2 + n^2 \\]
其中 \\(m > n\\)，\\(m, n\\) 一奇一偶，互质。

```python
def pythagorean_triples(limit_m=10):
    """用参数公式生成本原勾股数"""
    import math
    triples = []
    for m in range(2, limit_m+1):
        for n in range(1, m):
            if (m - n) % 2 == 1 and math.gcd(m, n) == 1:
                a = m*m - n*n
                b = 2*m*n
                c = m*m + n*n
                triples.append(tuple(sorted([a, b]) + [c]))
    return sorted(set(triples))

triples = pythagorean_triples(8)
for t in triples[:10]:
    a, b, c = t
    assert a*a + b*b == c*c
    print(f"{a}² + {b}² = {c}²  ({a*a}+{b*b}={c*c}) ✓")
```

## ✅ 习题解答

### 题 12.1 解答
设两直线相交，对顶角为 \\(\angle 1\\) 与 \\(\angle 3\\)，邻角为 \\(\angle 2\\)。
\\(\angle 1 + \angle 2 = 180°\\)（平角），\\(\angle 3 + \angle 2 = 180°\\)。
故 \\(\angle 1 = \angle 3\\)。∎

### 题 12.2 解答
\\(\angle C = 180° - 50° - 60° = 70°\\)。（三角形内角和定理）

### 题 12.3 解答
在 \\(\triangle ABC\\) 与 \\(\triangle DEF\\) 中：
- \\(AB = DE\\)（已知）
- \\(\angle B = \angle E\\)（已知）
- \\(BC = EF\\)（已知）
∴ \\(\triangle ABC \cong \triangle DEF\\)（**SAS** 边角边）。∎

### 题 12.4 解答
\\[ c = \sqrt{6^2 + 8^2} = \sqrt{36 + 64} = \sqrt{100} = 10 \\]

### 题 12.5 解答
**已知**：\\(\triangle ABC\\) 中 \\(AB = AC\\)，\\(AD\\) 平分 \\(\angle A\\) 交 \\(BC\\) 于 \\(D\\)。
**求证**：\\(AD \perp BC\\) 且 \\(BD = DC\\)。

**证明**：
由题 12.3 的方法（SAS），\\(\triangle ABD \cong \triangle ACD\\)。
∴ \\(BD = DC\\)（对应边相等）——平分底边 ✓
∴ \\(\angle ADB = \angle ADC\\)（对应角相等）。
又 \\(\angle ADB + \angle ADC = 180°\\)（平角），
故 \\(\angle ADB = \angle ADC = 90°\\)，即 \\(AD \perp BC\\)。∎

> 💡 一箭双雕：一个全等，推出两个结论。
> 这就是几何证明的优雅。

### 题 12.6 解答
```python
import math

def primitive_triples(limit_c=100):
    res = []
    for m in range(2, 20):
        for n in range(1, m):
            if (m-n) % 2 == 1 and math.gcd(m, n) == 1:
                a, b = m*m-n*n, 2*m*n
                c = m*m+n*n
                if c <= limit_c:
                    res.append((min(a,b), max(a,b), c))
    return sorted(set(res))

def is_prime(n):
    if n < 2: return False
    return all(n % i for i in range(2, int(n**0.5)+1))

triples = primitive_triples(100)
print(f"100以内本原勾股数共 {len(triples)} 组")
prime_hyp = [t for t in triples if is_prime(t[2])]
print(f"斜边为素数的: {prime_hyp}")

# 观察斜边特征
for a, b, c in prime_hyp[:8]:
    print(f"  {a}²+{b}²={c}², c={c}, c mod 4 = {c % 4}")
```

**发现**：本原勾股数的斜边 \\(c\\) 若为素数，则必有 \\(c \\equiv 1 \\pmod 4\\)！
（如 5, 13, 17, 29, 37…都是 \\(4k+1\\) 型）
这是**费马平方和定理**：素数 \\(p = x^2 + y^2\\) 当且仅当 \\(p = 2\\) 或 \\(p \\equiv 1 \\pmod 4\\)。
拉马努金对这类"表示问题"有大量深刻结果（第 31 章）。
