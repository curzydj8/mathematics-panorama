## 13.1 数据：从收集到整理

### 统计的三个步骤

1. **收集**：调查、实验、观测
2. **整理**：列表、画图
3. **分析**：算平均数、看趋势、下结论

### 抽样：以小见大

要调查全校 2000 人的身高，不必人人量——**随机抽** 100 人即可。

**关键**：样本必须**随机**且**有代表性**。
- ✓ 从每个年级随机抽
- ✗ 只调查篮球队（偏高！）

这叫**抽样偏差**（sampling bias）——统计学第一大坑。

```python
import random

# 模拟：全校身高正态分布（均值165，标准差8）
population = [random.gauss(165, 8) for _ in range(2000)]

# 随机抽样100人
sample = random.sample(population, 100)

pop_mean = sum(population) / len(population)
sample_mean = sum(sample) / len(sample)

print(f"全校真实均值: {pop_mean:.2f} cm")
print(f"抽样100人均值: {sample_mean:.2f} cm")
print(f"误差: {abs(pop_mean - sample_mean):.2f} cm")
# 多次运行，观察误差通常在2cm以内——这就是抽样的威力
```

## 13.2 平均数、中位数、众数：数据的"代表"

### 三种平均

| 名称 | 定义 | 例子（1,2,3,4,100） |
|---|---|---|
| **平均数**（mean） | \\(\bar{x} = \frac{\sum x_i}{n}\\) | \\(22\\) |
| **中位数**（median） | 排序后中间的数 | \\(3\\) |
| **众数**（mode） | 出现次数最多的数 | 无 |

**什么时候用哪个？**
- 工资水平：用**中位数**（平均数被富豪拉高！）
- 考试成绩：用**平均数**
- 卖鞋码数：用**众数**（进货看哪个码卖最多）

> 💡 平均数 22 完全不能代表 \\(1,2,3,4,100\\) 这组数据——
> 被 100 这个**异常值**带偏了。中位数 3 更靠谱。

### 方差与标准差：数据的"离散程度"

平均数告诉你"中心在哪"，**方差**告诉你"有多散"。

\\[ \text{方差 } s^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2 \\]
\\[ \text{标准差 } s = \sqrt{s^2} \\]

**直观**：每个数到平均数的距离，取平方平均，再开方。
方差越大，数据越"参差不齐"。

```python
import math

def mean(data):
    return sum(data) / len(data)

def variance(data):
    """总体方差"""
    m = mean(data)
    return sum((x - m)**2 for x in data) / len(data)

def std(data):
    return math.sqrt(variance(data))

# 两组平均数相同（都是5），但离散程度迥异
A = [5, 5, 5, 5, 5]          # 整齐划一
B = [1, 3, 5, 7, 9]          # 参差不齐
C = [0, 0, 5, 10, 10]        # 两极分化

for name, data in [('A', A), ('B', B), ('C', C)]:
    print(f"{name}: 均值={mean(data):.1f}, 方差={variance(data):.1f}, 标准差={std(data):.2f}")

# A: 均值=5.0, 方差=0.0, 标准差=0.00
# B: 均值=5.0, 方差=8.0, 标准差=2.83
# C: 均值=5.0, 方差=18.0, 标准差=4.24
```

> 🌟 **拉马努金角**
> 拉马努金研究**素数分布**时，本质上在做统计！
> 素数定理说：不超过 \\(x\\) 的素数个数
> \\[ \pi(x) \sim \frac{x}{\ln x} \\]
> 这像不像"平均数"？——素数在数轴上的"密度"是 \\(1/\ln x\\)。
> 他还研究了**tau 函数** \\(\tau(n)\\) 的统计行为，
> 猜测 \\(|\tau(p)| \leq 2p^{11/2}\\)（\\(p\\) 为素数）——
> 这就是著名的**拉马努金猜想**（后被德利涅证明，成为菲尔兹奖工作的一部分）。
> 从"数数"到"猜分布"，统计思维贯穿数论始终。

## 13.3 概率：不确定性的数学

### 古典概型：等可能事件

**定义**：如果试验有 \\(n\\) 个等可能的基本结果，事件 \\(A\\) 包含 \\(m\\) 个，
则 \\[ P(A) = \frac{m}{n} \\]

**两个条件**：有限个结果 + 等可能。

例：掷骰子，\\(P(\text{点数}>4) = \frac{2}{6} = \frac{1}{3}\\)。

### 概率的性质

1. \\(0 \leq P(A) \leq 1\\)
2. \\(P(\text{必然事件}) = 1\\)，\\(P(\text{不可能事件}) = 0\\)
3. **互斥事件**：\\(P(A \cup B) = P(A) + P(B)\\)（\\(A, B\\) 不能同时发生）
4. **对立事件**：\\(P(\bar{A}) = 1 - P(A)\\)

### 独立事件：互不影响

\\[ P(A \cap B) = P(A) \times P(B) \quad \text{（}A, B\text{独立）} \\]

例：连掷两次硬币都是正面：\\(\frac{1}{2} \times \frac{1}{2} = \frac{1}{4}\\)。

> ⚠️ **赌徒谬误**：连出 5 次正面，下次出反面的概率**还是** \\(1/2\\)！
> 硬币没有记忆。每次试验独立。

```python
import random

def coin_experiment(n):
    """掷n次硬币，统计正面比例"""
    heads = sum(random.choice([0, 1]) for _ in range(n))
    return heads / n

for n in [10, 100, 1000, 10000, 100000]:
    p = coin_experiment(n)
    print(f"掷 {n:>6} 次: 正面比例 = {p:.4f}, 与0.5的差 = {abs(p-0.5):.4f}")

# n越大，比例越接近0.5——这就是"大数定律"（第25章）
```

### 列表法与树状图：不重不漏

**例**：掷两枚骰子，点数之和为 7 的概率？

列表（36 种等可能）：
```
(1,1)(1,2)(1,3)(1,4)(1,5)(1,6)
(2,1)(2,2)(2,3)(2,4)(2,5)(2,6)
...
```
和为 7 的有：\\((1,6),(2,5),(3,4),(4,3),(5,2),(6,1)\\)，共 6 种。
\\[ P = \frac{6}{36} = \frac{1}{6} \\]

```python
from itertools import product

# 穷举两骰子
outcomes = list(product(range(1,7), repeat=2))
fav = [(a,b) for a,b in outcomes if a+b == 7]
print(f"总情况: {len(outcomes)}, 和为7: {len(fav)}, 概率 = {len(fav)}/{len(outcomes)} = {len(fav)/len(outcomes):.4f}")

# 更有趣的：和为几的概率最大？
from collections import Counter
sums = Counter(a+b for a,b in outcomes)
for s in range(2, 13):
    print(f"和={s:>2}: {'█' * sums[s]} ({sums[s]}/36)")
```

## ✅ 习题解答

### 题 13.1 解答
- 平均数：\\(\frac{3+5+7+5+9}{5} = \frac{29}{5} = 5.8\\)
- 中位数：排序 \\(3,5,5,7,9\\)，中间是 \\(5\\)
- 众数：\\(5\\)（出现 2 次，最多）
- 方差：\\(\frac{(3-5.8)^2 + (5-5.8)^2 + (7-5.8)^2 + (5-5.8)^2 + (9-5.8)^2}{5}\\)
  \\(= \frac{7.84 + 0.64 + 1.44 + 0.64 + 10.24}{5} = \frac{20.8}{5} = 4.16\\)

### 题 13.2 解答
- 偶数：\\(\\{2,4,6\\}\\)，\\(P = \frac{3}{6} = \frac{1}{2}\\)
- 不小于 4：\\(\\{4,5,6\\}\\)，\\(P = \frac{3}{6} = \frac{1}{2}\\)

### 题 13.3 解答
- 摸到红球：\\(P = \frac{3}{5}\\)
- 有放回，两次都红：独立事件，\\(P = \frac{3}{5} \\times \\frac{3}{5} = \\frac{9}{25}\\)
- （思考：如果**不放回**呢？\\(P = \\frac{3}{5} \\times \\frac{2}{4} = \\frac{3}{10}\\)，因为第一次摸走后只剩 4 个球 2 红）

### 题 13.4 解答
**不一定**。平均分 75 但分布可能极度偏斜。
例：全班 10 人，9 人考 70 分，1 人考 125 分（加分），
平均 \\(= (9 \\times 70 + 125)/10 = 75.5\\)，中位数是 70。
小明 80 分 > 平均 75，但只比中位数 70 高一点，
且 9 个人都比他低？不——9 人 70 分都比 80 低，
所以小明确实在上游。但换个例子：
5 人 100 分，5 人 50 分，平均 75，中位数 75，
小明 80 分确实在中上游。
**关键**：只知道平均数无法判断排名，需要中位数或分布。
这就是为什么看"平均工资"会误导——要用中位数！

### 题 13.5 解答
```python
import random
from collections import Counter

n = 10000
rolls = [random.randint(1, 6) for _ in range(n)]
cnt = Counter(rolls)
for face in range(1, 7):
    freq = cnt[face] / n
    print(f"点数 {face}: 出现 {cnt[face]} 次, 频率 {freq:.4f}, 理论 0.1667, 偏差 {abs(freq-1/6):.4f}")
# 频率都在0.16~0.17之间，接近1/6 ✓
```

### 题 13.6 解答
```python
import math

def pi_count(x):
    """数x以内的素数个数（试除法）"""
    def is_prime(n):
        if n < 2: return False
        return all(n % i for i in range(2, int(n**0.5)+1))
    return sum(1 for i in range(2, x+1) if is_prime(i))

for x in [100, 1000, 10000]:
    actual = pi_count(x)
    estimate = x / math.log(x)
    err = abs(actual - estimate) / actual * 100
    print(f"x={x:>5}: π(x)={actual:>4}, x/ln x={estimate:>8.1f}, 相对误差 {err:.1f}%")

# x=  100: π(x)=  25, x/ln x=    21.7, 相对误差 13.1%
# x= 1000: π(x)= 168, x/ln x=   144.8, 相对误差 13.8%
# x=10000: π(x)=1229, x/ln x=  1085.7, 相对误差 11.7%
```

**观察**：\\(x\\) 增大时，相对误差**缓慢减小**（13.1% → 11.7%）。
素数定理是**渐近**成立的——\\(x \\to \\infty\\) 时比值趋于 1，
但收敛很慢。拉马努金给出了更精确的估计式，
而黎曼猜想（第 M7 章）若成立，将给出**最优**的误差界！
这就是统计→数论→千禧难题的链条。
