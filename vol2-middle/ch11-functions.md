## 11.1 变量与函数：从静到动

### 变量：会变的数

以前 \\(x\\) 是"未知数"（等着你解出来）。现在 \\(x\\) 是**变量**——
它可以在某个范围内**自由变化**。

例：\\(y = 2x + 1\\) 中，
- \\(x\\) 是**自变量**（independent variable）：你随便取
- \\(y\\) 是**因变量**（dependent variable）：跟着 \\(x\\) 变

\\(x = 1\\) 时 \\(y = 3\\)；\\(x = 2\\) 时 \\(y = 5\\)……

### 函数的定义（初中版）

在一个变化过程中，有两个变量 \\(x\\) 与 \\(y\\)，
如果对于 \\(x\\) 的**每一个**确定的值，\\(y\\) 都有**唯一**确定的值与之对应，
那么 \\(y\\) 是 \\(x\\) 的**函数**，记作 \\(y = f(x)\\)。

**关键词**：每一个 → 唯一。这是函数的灵魂！

- ✓ \\(y = 2x\\) 是函数（一个 \\(x\\) 对应一个 \\(y\\)）
- ✗ \\(x^2 + y^2 = 1\\)（圆）**不是**函数（\\(x=0\\) 对应 \\(y=1\\) 和 \\(y=-1\\) 两个值）

### 定义域与值域

- **定义域**：\\(x\\) 能取的所有值
- **值域**：\\(y\\) 能取的所有值

例：\\(f(x) = \frac{1}{x}\\)，定义域是 \\(x \neq 0\\)（分母不能为零！）

```python
def f(x):
    """函数 y = 2x + 1"""
    return 2*x + 1

# "每一个x对应唯一y"
for x in [-2, -1, 0, 1, 2]:
    print(f"f({x}) = {f(x)}")

# 函数的复合：f(g(x))
def g(x):
    return x**2

def compose(f, g, x):
    """f(g(x))"""
    return f(g(x))

print(f"f(g(3)) = f(9) = {compose(f, g, 3)}")  # 2*9+1=19
```

## 11.2 一次函数： \\(y = kx + b\\)

### 图像是一条直线

\\[ y = kx + b \quad (k \neq 0) \\]

- \\(k\\) 叫**斜率**（slope）：\\(k > 0\\) 上升，\\(k < 0\\) 下降，\\(|k|\\) 越大越陡
- \\(b\\) 叫**截距**：直线与 \\(y\\) 轴交于 \\((0, b)\\)

**为什么是直线？** 证明：
任取两点 \\((x_1, kx_1+b)\\), \\((x_2, kx_2+b)\\)，
斜率 \\(= \frac{(kx_2+b)-(kx_1+b)}{x_2-x_1} = k\\)（常数！）。
任意两点间斜率恒为 \\(k\\)，故为直线。∎

### 斜率的意义：变化率

\\[ k = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1} \\]

\\(k\\) 表示：\\(x\\) 每增加 1，\\(y\\) 增加 \\(k\\)。

这是**导数**（第 17 章）的雏形！导数就是"变化率"的精确化。

### 正比例函数

当 \\(b = 0\\) 时，\\(y = kx\\)，图像过原点。
\\(y\\) 与 \\(x\\) 成**正比**：\\(x\\) 变 2 倍，\\(y\\) 也变 2 倍。

```python
import matplotlib
matplotlib.use('Agg')  # 无显示环境
import matplotlib.pyplot as plt
import numpy as np

x = np.linspace(-5, 5, 100)
plt.figure(figsize=(10, 4))

plt.subplot(1, 2, 1)
for k, b, label in [(2, 1, 'y=2x+1'), (-1, 3, 'y=-x+3'), (0.5, -2, 'y=0.5x-2')]:
    plt.plot(x, k*x + b, label=label)
plt.axhline(0, color='black', linewidth=0.5)
plt.axvline(0, color='black', linewidth=0.5)
plt.legend(); plt.grid(True, alpha=0.3)
plt.title('一次函数：斜率决定倾斜')

plt.subplot(1, 2, 2)
plt.plot(x, 2*x, label='y=2x (正比例)')
plt.axhline(0, color='black', linewidth=0.5)
plt.axvline(0, color='black', linewidth=0.5)
plt.legend(); plt.grid(True, alpha=0.3)
plt.title('正比例函数过原点')

plt.tight_layout()
plt.savefig('/tmp/linear_functions.png', dpi=80)
print("图像已保存到 /tmp/linear_functions.png")
print("观察：k>0上升，k<0下降；b决定与y轴交点")
```

> 🌟 **拉马努金角**
> 拉马努金痴迷于**函数的变换**。他发现了一个惊人的恒等式：
> \\[ \frac{1}{1 + \frac{x}{1 + \frac{x^2}{1 + \cdots}}} \quad\text{（连分数形式的函数）} \\]
> 更著名的是他的**模方程**：如果 \\(y\\) 是 \\(x\\) 的某种"变换"，
> 那么某些特殊函数值之间存在代数关系。
> 例如，设 \\(f(x) = \sum_{n=-\infty}^{\infty} e^{-\pi n^2 x}\\)（theta 函数），
> 则 \\(f(x) = \frac{1}{\sqrt{x}} f(1/x)\\)——
> 这就是**函数方程**（functional equation）的威力：
> 函数在"变换"下保持某种对称性。
> 黎曼ζ函数的函数方程（第 32 章）正是这种思想的巅峰。

## 11.3 反比例函数： \\(y = \frac{k}{x}\\)

### 双曲线

\\[ y = \frac{k}{x} \quad (k \neq 0,\ x \neq 0) \\]

图像是**双曲线**（hyperbola），分两支：
- \\(k > 0\\)：一、三象限
- \\(k < 0\\)：二、四象限

**特点**：
- \\(x\\) 越大，\\(|y|\\) 越小（反比！）
- 永远碰不到坐标轴（\\(x \neq 0\\), \\(y \neq 0\\)）
- 关于原点对称

### 反比例的现实意义

- \\(v = \frac{s}{t}\\)：路程一定，速度与时间成反比
- \\(p = \frac{F}{S}\\)：压力一定，压强与面积成反比

```python
# 反比例函数数值实验
def inverse(k, x):
    return k / x

k = 6
print(f"k={k} 时:")
for x in [1, 2, 3, 6, -1, -2, -3]:
    print(f"  x={x:>3}, y={inverse(k, x):>7.2f}")
# 观察：x翻倍，y减半——这就是"反比"
```

## 11.4 函数图像：用描点法画图

### 三步法

1. **列表**：取一些 \\(x\\)，算 \\(y\\)
2. **描点**：在坐标系中标出 \\((x, y)\\)
3. **连线**：用平滑曲线连接

### 从图像读信息

看到 \\(y = 2x + 1\\) 的图像，你能读出：
- 与 \\(y\\) 轴交于 \\((0, 1)\\)（令 \\(x=0\\)）
- 与 \\(x\\) 轴交于 \\((-0.5, 0)\\)（令 \\(y=0\\)，解 \\(2x+1=0\\)）
- \\(x > -0.5\\) 时 \\(y > 0\\)（图像在 x 轴上方）
- \\(y\\) 随 \\(x\\) 增大而增大（\\(k=2>0\\)）

**函数、方程、不等式的统一**：
- \\(2x + 1 = 0\\) 的解 = 直线与 x 轴交点的横坐标
- \\(2x + 1 > 0\\) 的解集 = 直线在 x 轴上方的部分对应的 \\(x\\)

> 💡 三者本一体：**方程求"点"，不等式求"段"，函数看"整体"**。

## ✅ 习题解答

### 题 11.1 解答
**不是**函数。
当 \\(x = 4\\) 时，\\(y = \pm 2\\)，一个 \\(x\\) 对应两个 \\(y\\) 值，
违反了"唯一对应"的要求。

### 题 11.2 解答
- 与 \\(y\\) 轴：令 \\(x = 0\\)，得 \\(y = 6\\)，交点 \\((0, 6)\\)
- 与 \\(x\\) 轴：令 \\(y = 0\\)，得 \\(-3x + 6 = 0\\)，\\(x = 2\\)，交点 \\((2, 0)\\)

### 题 11.3 解答
设 \\(y = kx\\)，代入 \\(x=2, y=10\\)：\\(10 = 2k\\)，得 \\(k = 5\\)。
关系式：\\(y = 5x\\)。
\\(x = 5\\) 时，\\(y = 25\\)。

### 题 11.4 解答
\\(k = -4 < 0\\)，图像在**二、四象限**。
当 \\(x < 0\\) 时（第二象限分支），\\(y > 0\\)，
\\(x\\) 增大（比如从 -4 到 -1），\\(y = -4/x\\) 从 1 增大到 4，
所以 \\(y\\) 随 \\(x\\) 增大而**增大**。

> 💡 反比例函数在**每一支**上单调，但在整个定义域上不单调！
> 这是常考陷阱。

### 题 11.6 解答
```python
import math

def theta(x, N=10):
    """theta函数 f(x) = sum_{n=-N}^{N} e^{-pi n^2 x}"""
    return sum(math.exp(-math.pi * n*n * x) for n in range(-N, N+1))

for x in [0.5, 1, 2]:
    lhs = theta(x)
    rhs = theta(1/x) / math.sqrt(x)
    print(f"x={x}: f(x)={lhs:.6f}, f(1/x)/√x={rhs:.6f}, 差={abs(lhs-rhs):.2e}")

# 输出示例：
# x=0.5: f(x)=2.000000, f(1/x)/√x=2.000000, 差=1.11e-16
# x=1:   f(x)=1.414214, f(1/x)/√x=1.414214, 差=0.00e+00
# x=2:   f(x)=1.000000, f(1/x)/√x=1.000000, 差=5.55e-17
```

**结论**：在数值精度内，\\(f(x) = \frac{1}{\sqrt{x}} f(1/x)\\) 成立！
这就是拉马努金深爱的**函数方程**——函数在变换 \\(x \leftrightarrow 1/x\\) 下的对称性。
黎曼证明 ζ 函数也有类似的函数方程，这是解析数论的基石（第 32 章）。
